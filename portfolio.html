THE DESKTOP REVIEW BLUEPRINT

Separate judgment from execution.

Each model has a bounded role. Deterministic code owns prices, position math and orders; the desktop review keeps every assumption, decision and approval inspectable.

01 / INGEST

Reconcile the ledger

Use a Python import job to normalize broker CSVs into a local SQLite fill ledger. Store UTC timestamps, fees, FX, corporate actions and raw-file hashes; reconcile partial fills before calculating P&L.

Output: immutable trade IDs and an exceptions queue.
02 / ASTRA + FABLE

Review and challenge

Astra coordinates the Vite desktop review UI and research pipeline. Fable independently challenges thesis labels and look-ahead leakage. Save prompt, model version and evidence IDs with each review.

Output: evidence-linked hypotheses and counterarguments.
03 / OPUS + JEV

Verify the gate

Opus reviews walk-forward tests and failure paths. Jev receives a compact JSON pre-trade state and returns typed probabilities; schema validation, a timeout and deterministic loss limits gate every candidate.

Output: replayable decisions, veto reasons and latency logs.
04 / DEPLOY

Ship in stages

Package the review UI as a signed desktop build with separate read-only, paper and live adapters. Promote only after replay and paper checks; require human approval, daily loss caps, audit logs and a kill switch.

Output: a desktop dashboard and a signed release checklist.

Jev is a typed decision model, not a proven market predictor. Model outputs should never be treated as guaranteed alpha. Jev API · Astra · Fable · Opus
