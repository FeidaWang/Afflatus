# 第 89 章 石刻 · 改稿说明

**星 53 = 新 89 = 旧 145 重写（第九段开头）**；用旧 145:10–13（下坑、灯扫石壁）、20–30（石刻内容，转述）、38–40（切缝、十二枚销一起弹开、推盖板）、71–76（门现，只一版）、95（两只粗瓷海碗两双竹筷）、100（跨门、脚下松软湿土）。新稿 `check.py 89` 字数约 5870。叙述、对白感叹号均 0；高频词全 0；违禁词无；正文无“漂流瓶”“四百年”。

## 时间

接 ch088 章末（三十多米下一道直亮线拐直角）→ 次日再扫六条，四道线围成一面立着的墙 → 穿梭机腹下切割头往下啃，“两天上下” → 第一天：分工、换药、傍晚喝稀汤（干粮“省着二十来天”）、夜里程心坐坑沿、两人一只右手一只左手互缠纱布 → 第二天下午切到墙顶，绞盘下人 → 石刻、刀口换手 → 盖板、十二销、把手 → 门 → 关一帆上去取东西并关舱门 → 跨门 → 坡顶石屋门从里头拉开。约两天半。冻伤第三天起算。

## 随身物（进门时）

- 她：大衣内兜三样（信抄件、青铜钟磁带、寒潭人名存储片“最薄、最凉”）；钥匙在脖子上白尼龙线、贴胸骨；手里拎**穿梭机上那只药箱**（ch086 她以查药箱为由上船那只；此后就是她在小宇宙里用了三百多年的药箱，供 9A）。

- 程心：手套揣兜里。穿梭机留在坑外。

## 新设定

1. 门在墙前两三步处，框比门高宽一点；门里近处一块平地放方桌（不在院里），房子在坡顶。
2. 石刻是两人刻的，中途换手（前者刀口往左偏、后者往右偏）；关一帆认出 AA 的字往右歪。正文没点明哪个名字是谁刻的。
3. 石刻里有一句书上没有的“船上那两位”。
4. 干粮省着够二十来天（进门理由之一，正文不点明）。
