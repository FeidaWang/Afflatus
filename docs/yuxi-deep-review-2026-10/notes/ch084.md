# 第 84 章 土 · 改稿说明

**星 48 = 新 84 = 新写为主；用旧 137:0–14（日志压成他读日志一段，只留第五年、第一百一十七年两处，加一处他拧过的阀）、137:25（四十八岁的手，删“年轻如初”）、138:0–5（关一帆来访，转述）、138:13（捻土）、138:53–56（炖汤，改由白道微做）**。新稿 `check.py 84` 字数约 5940。叙述、对白感叹号均 0；高频词全 0；违禁词无。

## 新伏笔与回收

1. **第一百一十七年那一行**：他标了黄三角，“跟后头那张一样的”；关一帆“你们见过平的”。死线（ch086）与之对照：一个是平的（降维），一个是细的（光速降到零）。
2. **拨钮胶布“降”翘角没粘住**：ch086–088 或小宇宙里若再冬眠/入舱可回收（可选）。
3. **“这儿是她的”**：龙井仍不泡；“到了”在哪儿留给小宇宙（星 55–57）。
4. **关一帆是头一个不认得两人的人**：星 50–52 黑域里可接（他看见两人同时发抖、同时冻伤，第一次知道同契的样子），不必说破。
5. **她认得他、知道他往后跟谁、在哪儿、多久**：锁点“在场、失败、记住”的又一次，不推，手串凉。
6. **“分母是三”**：可在小宇宙种根茎时回响（可选）。
