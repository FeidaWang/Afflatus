# 第 35 章 槐花 · 改稿说明

**新 35 = 旧 37 + 38 + 39**（orig/ch037.md、ch038.md、ch039.md，三章合计约 3.1 万字）。新稿约 4900 字（`check.py 35` 的字数基准是旧第 35 章，不作数）。叙述、对白感叹号均 0；“如同/宛如/仿佛/轻轻/缓缓/微微/彻底/冰冷”等全部 0；比喻只留“像是听了一份报上来的数”一处。违禁词无。

字数压在约 5000 的下沿：大纲只给五个分场，又要删尽回顾、告白、宏论、捷报；补进来的只有日常（老李记排队、东头木盆、井的账），不再往上加。

## 时间

隆庆元年七月（大纲；国槐七八月开花）。旧稿的“四月初”“暮春”“刺槐含苞”按清单 38/60 一并作废：花是国槐的花，黄白、米粒大，雨一来就落；她晒的是还没开的花穗（槐米，止血、染黄）。一天之内：五更他去老李记 → 上午擦雨、吃饼 → 晌午她去东头 → 后半晌算井账、摸茧 → 傍晚雨停槐树下 → 坐到快五更。

## 用到的处方

- 报告第二节：景物只留雨、槐花、炉子、木板；两人对白每场两三句，她追问，他短答。
- 报告第七节：规则前置（排队次序、一炉一盏茶，章末回收）；冷幽默（“一码归一码，这一码是他的”“你数过？”“那就是不好吃”）；微观互动（布巾、茧和疤、药炉搁到她脚边、凉茶）；她的本行（东头木盆数人头：五口，上月三个，这月两个；井账从按户摊改按口摊，四十四口）；他的本行（井账、赊账木板）。
- 圣经第 11 节：身体先于言语。全章不说破、不告白、不接吻；最近的一次是两寸。

## 新伏笔

1. **“排第三”**：第 36 章第二天五更两人一起去，老李头说“又是第三”，回收。
2. **赊账木板最底下没名字的一行**：第 36 章他把那一行的钱结了，老李头擦掉、画个小圈“明天他再来，从这儿重新画”。
3. **东头木盆、“下个月我再来数”**：第 36 章她八月去数，一个，是赶车的在路边沟里喝的。
4. **井账“记着”**：西头那家多出六十文，他说“记着”。第 36 章没有回收，可留着（他走时账上还挂着一笔，是他唯一没平的账）。如嫌多余可删。
