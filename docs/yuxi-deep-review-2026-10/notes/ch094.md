## 时间

第三百七十四年春，一天之内：早上她先醒数他的心（早搏两人同空）→ 早饭 → 上午药圃，广播 → 下午广播反复，工具房看账 → 晚饭后关一帆讲 → 夜里程心进麦田，“还吧” → 智子讲步骤、他对账 → 她记“在场。记着。” → 还钥匙 → 甜汤 → “带上种子” → 程心丝绸包木雕、钥匙包进最里层。生理年龄约 85（正文“四个人加起来大概三百四十来岁”）。

## 新设定

1. 第三百一十几年起两人偶发早搏，空拍是同时的。
2. 她坐矮凳（智子做，比地高一拃），他跪垫子；他已不下梯子，梯子口盖木板，井下归智子。
3. 钥匙线：白尼龙线断在第几十年，后来是她自己搓的麻线，换过多次；本章还给程心，程心包进木雕的绸子最里层。
4. 莲子塘在溪下游；百合在药圃西南角；灯烧麦秸压的油；碗是智子烧的粗陶，一只有缺。
5. 广播时手串“凉”，不烫不暖。
