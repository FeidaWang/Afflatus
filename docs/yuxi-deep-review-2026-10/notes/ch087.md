# 第 87 章 光比声慢 · 改稿说明

**星 51 = 新 87 = 旧 142、143 压缩（原创行动 8A、8B）；保留旧 142:12 怀表、142:21–29 声光倒错与蓝移红移、手臂折扇、手影滞后、142:22–23“程心，别怕”声先嘴后、142:48 荧光棒移到笔尖上方；旧 143:3–9 手摇计算机加游标卡尺、143:26–34 液氮开阀与二十二度／二十一度八、143:45 熏黑滚筒、143:68 盐糖水、143:72 四人轮值每半小时微调；8B 合并为一版（旧 142:36–37、80–82 与 143:51–52 的场景，内容改为问院子）**。新稿 `check.py 87` 字数约 5790。叙述、对白感叹号均 0；高频词全 0；违禁词无。

## 时间

接 ch086 章末（他转头，声音先到）→ 声光倒错 → 怀表挂衣钩、她记“入” → 关一帆转述低光速与外头时间（“算不出来，没有电”），两人记得书上那个数、不说 → 判断“还在往线那边滑，往里头”，他提“往横里走” → 掀地板，陀螺、卡尺、手摇计算机，一个读一个算一个记 → 第一回液氮阀：理论二十二度、实测二十一度八 → 第二回机尾阀推船往横里走 → 每半个钟头读一回、补一下，程心看表 → 降到零下二十度，她问程心院子 → 两人冻伤，他调盐糖水 → 轮班十几个钟头 → 最后一回“到了”，嘴先动、声后到，光不再爬（出口读数）。

## 章末

“这一回，是嘴先动的。”——他看着她、嘴唇在动，声音还没到：光又比声音快了。按接缝约定收在出口读数出现；ch088 从出黑域接起（光速回来、屏或电回来、外部读数约一千八百九十万年）。

## 新伏笔与回收

1. **小本上的读数**：“理论二十二度。实测二十一度八。差零点二度。记着。”与“两人冻伤，手指。盐糖水，每人半盖。”及“程心，七岁或八岁。枣，酸。”——星幕结算“你们做过的事”可引；他的字写在她本子上（全星幕两人最近的一次工作）。
2. **冻伤的手指**：两人右手（他）与举荧光棒的手（她）指尖冻伤，ch088 程心看自己手时可带一笔两人的手；小宇宙可作旧伤。
3. **院子**：老城、朝南、三级台阶第二级活的、枣树、院门锁涩——钥匙线后文回收（星 53 石刻或小宇宙）。
4. **熏黑滚筒那一卷纸**：白线拐角和一道道台阶，出黑域后可撕下保留（可选）。

## 待定

- 待定：方案“往横里走”是他按死线形状估的路线（线散成一长条，横着最短），不是原著的脱困方式；原著里程心与关一帆如何出黑域本稿不对应，按大纲“8A 原创”处理。手串全程不烫（往外走与书上“出来了”一致）。
- 待定：陀螺靠发条转、指针连滚筒细针，是为了让“卡尺读摆锤”“滚筒记录仪”在失重下说得通；若嫌过细，可删“指针另一头连着杆子”一段。
- 待定：失重写了（关一帆飘起、东西拿绳拴），阀开时人往一侧偏是惯性；ch088 若写了重力，对缝。
- 待定：开阀时长“四秒半”、卡尺“十一点四”“十一点二”都是实测/操作读数，非估算数；二十二度是他算出的理论值（大纲指定）。
- 待定：程心母亲、老城院子、枣树均为新设，不与原著冲突（原著未写程心童年住处）；若作者另有设定可替换。
