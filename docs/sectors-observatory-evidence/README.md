## 研究方法与覆盖

- **100 个机构 / 14 个产业层级。** 前沿模型、云与分发、加速芯片、设计与制造、存储与内存、高速互连、服务器与算力云、能源与散热、编程智能体、数据与开发工具、企业应用与搜索、创意与语音、机器人与具身智能、科学与独立评测。公司/产品品牌/子公司/非营利机构在有助于理解依赖时分别收录，不能把数量当成独立母公司数量或市场份额。“必不可少”按关键供应环节和影响力作编辑选择，页面披露其性质。
- **18 个模型。** 主榜采用 Artificial Analysis Intelligence Index v4.3.2 的公开展示分数，保留测量配置和同分并列；每个系列精选前沿代表，并保留成本/速度有用的替代配置。没有把每个旧型号都堆入排名。能力指数是一般能力评测，不等同于编程 agent 的端到端能力。
- **中美比较。** 当前精选模型的最高分与 Stanford 2026 AI Index 的 2025 年私人投资是两个明确分开的指标。另有研究/产业部署、模型控制与开放权重、全球硬件依赖三个定性对照维度。地理连接图只描述精选名录，不能推断各国全国供给。
- **Anthropic 上市前。** 公司官方融资/估值/年化运行收入，与路透社获得的秘密递交材料报道分开显示。涵盖收入质量、客户集中、亏损口径、非现金损益、长期算力义务、云合作关系、治理/控制/稀释问题。没有填入尚未核实的公开 S-1、股票代码、最终价格或上市日。
- **Agentic Coding。** 2024 年是产品前奏；把 2025 年视为进入主流的“元年”属于明确写出的编辑定义。23 条事件涵盖产品发布、CLI、云端 agent、IDE、协议、长期任务研究、行业整合和最新模型/平台。研究演示和通用可靠部署在文案上区分。
- **AGI。** 将页面组织为专项工具 → 受监督的智能体 → 可靠长程任务 → 自适应通用智能四道能力关卡。它们是概念门槛，不是统一量尺的四等分时间线。当前 benchmark 百分比单独标出测试、配置、日期和证据来源；没有创造总体 AGI 完成率。

## 关键事实口径

1. [Artificial Analysis 模型榜](https://artificialanalysis.ai/leaderboards/models)：快照于 2026-10-06；成本是完成 AA 测试任务的美元成本，**不是每百万 token 价格**。输出速度不涵盖全部推理等待，首段响应另列；缺失速度/延迟维持空值并排序到末尾。开放权重不等于无限制许可，未确认的开放状态不纳入该筛选。
2. [Stanford 2026 AI Index](https://hai.stanford.edu/ai-index/2026-ai-index-report)：投资统计期为 2025 年；US 285.9B / China 12.4B 是私人投资，不能代表全部政府及产业投入。报告中其他时间点的模型差距不与当前 AA 分数拼接为趋势线。
3. [Anthropic Series H](https://www.anthropic.com/news/series-h)：2026-05-28 官方融资 65B、估值 965B、年化运行收入 47B。年化运行收入不是已审计的完整年度收入。
4. [Reuters 上市材料报道（转载）](https://www.investing.com/news/stock-market-news/exclusiveanthropics-ipo-prospectus-shows-sweeping-ai-vision-surging-costs-4921382)：2025 年收入 4.6B，净亏损约 42B 包含约 34B 的融资工具公允价值损失；营业亏损超过 8B。三者都没有被改写为现金消耗。客户集中和未来目标仍作为报道处理。
5. [Reuters 算力义务报道（转载）](https://www.investing.com/news/stock-market-news/anthropics-518-billion-ai-buildout-hinges-largely-on-deals-that-cannot-be-canceled-filing-shows-4922031)：约 518B 为未来十年的算力建设/合同义务口径，约 80% 不可取消，不等于一年支出或全部债务。
6. [Anthropic Sonnet 5.5](https://www.anthropic.com/claude-sonnet-5-5)：2026-09-28 的 Terminal-Bench 4.0 70.6% 是厂商报告的特定测试成绩，**不是 AGI 完成率**。
7. [METR task horizons](https://metr.org/time-horizons)：50%/80% 成功率任务跨度用人类专家完成任务的时间衡量，不是 agent 的连续运行时长，也不是任意项目的可靠性保证。
8. [ARC-AGI-3 发布](https://arcprize.org/blog/arc-agi-3-launch)：2026-03-25 发布时低于 1% 的数字是历史结果，未宣称是十月实时榜单。页面同时连接[当前榜单](https://arcprize.org/leaderboard)，没有从未读取的榜单推断最新数值。

公司官网和近似总部位置沿用已有 9 月 27 日官方核对记录并补充本轮新机构；`checked` 表示资料审阅日期，不表示每个官网在这一秒都成功抓取。图上标记不是 GPU、机房数量或算力容量。
