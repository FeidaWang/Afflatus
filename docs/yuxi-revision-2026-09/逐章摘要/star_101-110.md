# 星幕逐章摘要：第101–110章

依据：设定圣经、星幕年表、星幕原创行动（定稿），逐字读完 ch101–ch110。块号为 `[块号|类型]` 中的块号。

## 先说总判断（读前提示）

1. **十章的章题全部是旧“威慑纪元 62 年”一段的题目**（执剑交接、水滴攻击、太阳系防线崩溃等），第 101 章题还是“墨尔本现实回归”。**十章正文却全是年表“七、蓝星与死线 / 八、647 号小宇宙”一段**（到达蓝星、关一帆、死线、黑域、云天明石刻、647 号、归零者广播、归还质量、五公斤生态球）。也就是说，正文对应年表里的现 137–156 章，被误放在 101–110。年表第四段（威慑与大移民）、第五段（广播纪元）、第六段（掩体纪元）在这个位置上是空的，要另写。
2. **十章里白道微、常灵珂几乎不是主角**：视点是程心、关一帆、智子。白、常全程以“白道伟／常令可”出场，是大罗金仙加“十维神经全息法身”的仙侠形象，在蓝星、小宇宙里指点、讲道、施法。
3. **没有一处**提到手串、同契、复演券、锁点警告、掐虎口、第 67 章污点、幕末结算。
4. 星幕原创行动的 8A、8B、9A、9B 在这里都只有零星素材，见各章及最后总览。
