# 星幕逐章摘要（第151–160章）

说明：块号沿用章文件里的 `[块号|类型]`。“主角作用”一栏里，“无”表示该场只是人物戏或景物，跟锁点无关。原著情节一律用自己的话概括。年表、圣经、行动清单的相关条目已读，下文称“年表”“圣经”“行动清单”。

先说这十章的总背景，方便查看各章：

- 本段对应年表“八、647号小宇宙”的末期（归零者广播、归还质量、留下生态球），然后是“星幕终：结算，回天枢”（年表标 157–160 重写）。
- 正文实际比年表多出一大段：出小宇宙后开穿梭机，进仙王座低光速黑域冬眠，睡过“四百多亿年”看完大坍缩（第155章块85起到第157章）。年表和圣经里没有这一段，星幕总时长也因此对不上（见下）。
- 全段从头到尾没有手串、复演券、锁点警告。同契写成胸口的“印记”和会发光的能量。系统能力【拾遗】【素问】不但在，而且在第158章“升级”后带回了现实。
- 全段没有第67章暗线、没有行动清单里的任何一条完整落地。
