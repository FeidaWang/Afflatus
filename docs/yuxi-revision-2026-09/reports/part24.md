# 分段24审稿报告（第185–192章）

### A. 本段总评

本段是营幕篇的高潮和收束，依次写了全营气雾消杀、毒气自毁与复演回溯、铁床战歌、攻破第十层、击溃主脑解除项圈、开启地表巨门、走出地面，以后以一场悬崖边的争吵与和解作结。情节全部原创，推进也快，但文字和设定都在失控边缘：几乎每段都有感叹号、“彻底/死死/瞬间/狂暴/神圣”一类的强化词和工程参数堆叠。8章里没有一段写得克制。

最突出的三个问题：
1. **核心设定硬冲突。** 第186章常灵珂中毒身亡，白道微却独自存活并使用复演券，直接违反“同契·一方死则双亡”。第191、192章白道微要靠遥测屏幕才知道常灵珂的心率，受伤时也毫无痛感分担，“同契”在本段形同虚设。同时，“四百年”“五十年”两个时间框架与主角2025年墨尔本出发的设定全面矛盾：常灵珂在营中行医“五十年”，两人“四百年前在皇家展览馆相遇”。
2. **科学、医学、工程数据大量出错，而且错在主角的专业领域上。** 比如医生教人用生石灰处理催泪弹入眼，从纯氧改成“高原自然风”后血氧反而升高，“紫铜液氮冷脆”，15米叶轮以1450转运转（叶尖超音速），负压达“数百个大气压”，10毫米生铁盾挡30毫米穿甲弹。流行病学家和数据科学家成了全能的药厂厂长、焊工、特种兵、黑客和外科医生。
3. **节奏重复，冗余严重。** 第190章已经写完开门、摘面罩、踏草地、饮河水、合唱，第191章又从“最初五分钟不敢出门”重演一遍。第185、187、189章各有一遍十万人欢呼加宏大口号，四次以上重复“深渊—阳光”的抒情。雷诺兹和云顶这条主线在第187章之后直接消失，没有交代。

最出彩之处：第188章块54女打字员投降、老马说“只要不替刽子手卖命，你们也是工人”，第189章块7老矿工用手掌垫住学徒的项圈，以及第192章常灵珂“我也怕啊”的崩溃。这几处有真实的人物温度，是全段最打动人的地方，值得围绕它们压缩其他段落。

### C. 设定与连续性事实表

- **楼层方向**：本段大体设定第十层是军事分界，其上为云顶，其下十一至八十层为中下层，第78和80层是最深矿井（第185章块47，第187章块5，第188章块1、52，第189章块63）。但第185章块49写“八十层巨构云端最顶峰”，块36“向下灌入37–80层”暗示18层以上为上；第187章块17写“负五层深矿”。前文第161章写“51–80层下沉深渊”，第167、169章写“75–80层为特权顶层”，前文本身就不一致。
- **关键楼层**：18层为主排风总站和总配液大厅；20层为中央保税医药库；12层为毒气储罐（第186章块5）；10层为中央总控要塞和主脑“阿尔戈斯-7”（第188章块57）；36层为隔离病区和战地医院；45层为家属区和纺织车间；52层为托儿所旧址；15、28、45层为禁闭要塞（第189章块61）；第十层之上300米是“泰坦之门”（第190章块0）。
- **人口**：十万人，即三万矿工加七万工友（第185章块66）；编组为三万矿工、四万技工、三万女工（第187章块37）。第185章块26误作“数十万”。云顶占人口1.5%，用电90%（第187章块3）。
- **巨构年代**：“二十一世纪四十年代巨构初建”（第186章块5），“半个世纪”；“哥德尔在一百年前”（第189章块13）与此冲突。大门封闭五十年（第190章块2）。
- **药物**：十吨两性霉素B和酮康唑原料，来自20层保税库（第185章块61）。气溶胶浓度为两性霉素B 12.8 mg/m³、酮康唑8.5 mg/m³，灭活率99.96%，血氧从68%升至97%（第185章块55–57）。
- **风机**：8台，单台2000千瓦，叶轮15米，1450转（第185章块24–31）；柴油发电机组6台×5000马力（块27）。第187章说是核聚变电力，第190章说是6台×3万千瓦地热汽轮机（块11）。
- **毒气**：3800吨，12座30米球罐，200大气压，22小时倒计时（第186章块9）。被导入“负八层”玄武岩岩浆暗河，深3000米、1400℃（块55、70）。注意“负八层”与“负五层为最深”（第187章块17）冲突。
- **复演券**：本段使用1次，由白道微捏碎金属圆盘，回溯24小时（第186章块27–35）。第24章曾由常灵珂以系统权限形式使用，形态不一致，剩余张数未交代。
- **同契**：本段未出现“同契”一词。常灵珂死亡而白道微存活（第186章块23–27）；白道微靠屏幕读取常灵珂心率（第192章块16）；第192章块48重新立下“同生共死”誓言。以上均与规则冲突。
- **项圈**：“泰坦-V”型，十万人全员佩戴，新生儿也有（第189章块48），内含三万伏电击和5克聚能炸药，倒计时180分钟（第188章块60）。第166、168章的项圈只套在信用破产者和死囚身上。
- **白糖**：50公斤，第177章为墨尔本私人许诺；第185章块69说是往昔在黑矿井里的争夺；第189章块55说是营中对全营的誓言，并在本段兑现。

### D. 与原著的关系

- 第185章：原创为主。主角主导配药和改装风道，其他情节无对应的已出版作品。
- 第186章：原创为主。复演回溯和潜入拆除毒气均由主角主导，“时间回溯救爱人”属通用类型桥段。
- 第187章：原创为主。敲铁床的集体抗议是监狱或罢工题材中的常见意象，并非照搬某部具体作品；主角是动员者。
- 第188章：原创为主。主角指挥破门，常灵珂负责战地救护，“用逻辑悖论击溃AI”属科幻通用桥段。
- 第189章：原创为主。主角同时对付主脑、剪断馈线，解除项圈，与已出版作品无逐段对应。
- 第190章：原创为主。开启巨门、重返地表属“地下城、避难所”类通用母题，主角主导。
- 第191章：原创为主。“地表其实安全、谎言被揭穿”为常见的反乌托邦母题，主角用检测和率先摘面罩起到关键作用。
- 第192章：原创为主。纯粹的主角情感戏，与原著无关。

整段没有发现对《三体》或《大明王朝1566》的复述或照搬。

### E. 疑问

1. 第185、186、188–192章反复提到“四百年前在墨尔本皇家展览馆相遇”，以及泰晤士河、南太平洋孤舟、极地冰原、数字幽灵、机械神殿、挡子弹、割皮培植抗体等经历。这些是否来自尚未审到的某一幕，还是本段新增的前史？与第1章“2025年唐人街剧本杀初识”如何统一？
2. 营幕的楼层编号以哪一套为准？第161章写“51–80层为下沉深渊”，第167、169章写“75–80层为特权层”，本段以第十层为界、云顶在上。另外，出口巨门与云顶是什么空间关系？雷诺兹和云顶的结局是否安排在第193章以后？
3. 营幕世界是地球还是“异星”？第185章块69写“异星巨构”，第191章却出现西伯利亚红松、金雕、旱獭。
4. 第186章常灵珂死亡而白道微存活，是有意设计的“同契例外”（例如复演券触发的特殊状态），还是疏漏？复演券的总数和剩余张数是多少？
5. 两人在营幕中停留了多久？第192章说常灵珂行医“五十年”，这是笔误还是营幕内时间流速另有设定？
