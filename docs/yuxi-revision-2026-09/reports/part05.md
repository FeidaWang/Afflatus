# 分段 05 审稿报告（第33–40章，明幕篇收尾）

### A. 本段总评

第33–40章是明幕篇的收尾。结构大致是：一场宫廷夜战（33章），五章小院日常与回顾（34–39章），再加一章告别兼跃迁（40章）。这一段的主要问题不在个别词句，而在整体形态。

第一，明显的生成痕迹和"元数据泄漏"。每章结尾都有系统结算框，框里写着"前N章全书累计字数突破××万字""全网独立无重复段落100%达标"之类的字样，像是生成时的指令残留。结算框里的"文明指数"从95%一路涨到100%，没有任何叙事功能。第38、40章还有几处没有块号的裸行，第40章块38–40两段几乎重复。

第二，时间线自相矛盾。穿越起点写的是嘉靖三十九年腊月，到隆庆元年四月实际已有六年多，但文中反复说"三年""一千零八十四天"，这个天数本身也算错了。第33章又说"这半年"。第40章更出现"三年前初入这间院子"，可他们二月才搬进来。

第三，主角全知全能，配角被工具化。复式记账、考成法、一条鞭法、牛痘、青霉素、口服补液盐全由两人包办。张居正向布衣下拜受教。海瑞到任不足一月就清出七百四十万亩隐田。月港开埠首月就进来美洲白银二百八十万两。史实错位也很密集：冯保掌印、张居正首辅、海瑞巡抚、马尼拉帆船、国槐四月开花、陶然亭、琉璃厂书肆，大多提前了数年到百余年。

34–39章的小院温情戏有相当篇幅是在空转：每章都有一段大段抒情告白，外加一段"文明火种"式的宏论，彼此高度同构。

出彩之处有三：第37章结尾"每秒一点二米排第三位"，第38章结尾"超维系统不收行李超重费"，第39章块59–70槐树下克制的对手戏。这几处对白短、有互怼、有潜台词，两人的区分度一下子出来了，建议以这种笔调为基准，大幅压缩其余的抒情段落。

### D. 与原著的关系

- 第33章：原创为主。借用了《大明王朝1566》的人物（陈洪、冯保、黄锦、朱七），但夜袭尚宫局和药烟伏击都是原创，主角主导全局（问题在于过度全能）。
- 第34章：原创为主。琉璃厂小院日常，与原著无关。
- 第35章：原创为主。义诊、修屋、教授复式记账；提到的开海、海瑞南下只是背景史事，没有复述原著情节。
- 第36章：原创为主。程掌柜对账、难产救治是原创；张居正夜访一场把史实中张居正的考成法、一条鞭法安排成主角口授，属于借用史实，并非照搬原著台词。主角作用过大，挤压了历史人物。
- 第37章：改编为主，以回顾为形式。块17–42按原剧大致顺序复述了周云逸廷杖、毁堤淹田、沈一石自焚、芸娘辗转、海瑞上疏入狱等主线。没有照搬台词，但这一段基本是剧情摘要，主角只是被补插成"在场帮手"，没有新的戏剧行动。
- 第38章：原创为主。烧饼日常；新政成果都以转述形式交代。
- 第39章：原创为主。槐花茶、捷报、遗赠；块24–25的前情（工部伪账、衢州疫病）是原创回忆。
- 第40章：前半段是改编加回顾，块13–21再次按原剧顺序速览周云逸、毁堤、沈一石、海瑞上疏、嘉靖驾崩，与第37章重复；后半段告别和跃迁是原创，但跃迁目的地与第二部的三体设定不符。本段尚未涉及《三体》内容。

### E. 疑问

1. 明幕篇的官方时间轴是什么？穿越发生在嘉靖三十九年腊月（原剧的开端），到隆庆元年四月实际已有六年多，但文中反复说"三年、一千零八十四天"。是有意压缩（异界时间流速不同），还是需要把年份或天数改掉一方？
2. 两人在墨尔本是剧本杀当晚才初识，还是早已在医学院咖啡馆相识？第40章块42说"你问我为什么非要接这个项目"，是否意味着穿越是主动接下的"项目"，而不是意外遭遇的异变？
3. 白道微的职业定位是数据科学家，还是量化金融从业者？常灵珂是在读博士还是已经成名的专家？本段两者都有漂移。
4. 第40章结尾的"昆仑号深空母舰、最高执政官、无限营地"与第二部三体（红岸）、第三部巨构营的设定都不一致。这是旧大纲的残留，需要重写吗？
5. 各章结算框里的"累计字数""全网独立无重复段落100%达标"是有意设计的元叙事玩笑，还是生成时留下的内容，可以直接删除？另外，冯保掌印、张居正首辅、海瑞巡抚提前到隆庆元年，是有意改写历史（"历史被改变"）吗？如果是，文中是否需要一句明确的交代？
