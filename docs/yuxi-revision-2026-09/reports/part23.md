# 分段23审稿报告：第177–184章（营幕篇·第二阶段收束至强攻医药库）

### A. 本段总评

这八章是营幕篇的枢纽：变压器房里定下白糖之约，告密，白道微替罪被贬，负三层起义，锈肺热爆发，熔断令，常灵珂逆行，强攻医药库。骨架是清楚的，戏剧节拍（温存—背叛—牺牲—集结—灾变—突围）也完整。问题在执行上，而且很集中。

最突出的三个问题：
1. **没合并的重复稿块成片出现。** 第181–184章里，好几处同一情节写了两到三个版本，顺序也是乱的。比如第182章常灵珂“冲向闸门”写了四遍（块82–86）；第183章转锁轮、气管切开、两人重逢、下达出击令各写了两遍；第181章块63的问句要到块67才有回答，中间插着另一版凯恩博士的对话。读者会明显感到“同一件事又发生了一次”。这是本段最急需处理的。
2. **硬设定前后矛盾。** 楼层方位颠倒：二十层在三十六层下面，冲车却“从负三层往上撞开三十层，再刺穿二十四层抵达二十层”。时间线说不通：上午十点焊门，矿工说二十分钟内不突围就会炸管，可救援“深夜十二点四十五分”才到。“锈肺热”在第162/166/170章已经是常灵珂治好的旧病，这里又成了“前所未见”的新真菌。白道微的身份从“一个月前坠入的底层苦力”变成“毕业于七十八层学院的前任总工、三年前救过几千矿工”。大崩溃的年份有三种说法。同契规则也和总设定冲突，下文细列。
3. **文风空转严重。** 八章约8.3万字，感叹号约1320个（第183章一章226个）；“彻底”约130次，“瞬间”约110次，“如同/宛如/仿佛”约160次。每个动作都加“狠狠/死死/疯狂”，人物动不动“宛如神祇”，章末总有一段“轰然出鞘/直冲苍穹”式的宏大收束。第180章块57–68直接写出了“第二阶段大冲突里程碑大盘点”“第180章的节点”，打破了第四墙，读着像游戏结算面板混进了正文。

最出彩的地方：第177章“一整袋白糖”这个意象选得好。在一个用卡路里定额奴役人的世界里，“甜”是一种很具体、很可感的承诺，后文还能反复回响。第178章用水管敲击传递“断尾”信号，第180章用听诊器贴管道通信，都是有工业质感的原创细节。第182章常灵珂拆穿“底层投毒”谣言那段，有真正的戏剧冲突（群众被煽动、要反锁女营），是本段少见的“人对人”的戏。

### D. 与原著的关系

- 第177章：原创为主。营幕篇的设定与刘慈欣、刘和平的作品无关；两位主角主导。
- 第178章：原创为主。告密、戒严、敲管道传信均为原创；白道微主导替罪布局，常灵珂执行自毁。
- 第179章：原创为主。公审、游街、劫狱属于类型套路（阶级反乌托邦），未见照搬已出版作品；白道微主导。
- 第180章：原创为主。常灵珂组织中层，白道微动员底层。
- 第181章：原创为主。常灵珂承担诊断主线。
- 第182章：原创为主。常灵珂辟谣并逆行，是本章核心。
- 第183章：原创为主。常灵珂抢救伤员，白道微冲车会合。
- 第184章：原创为主。白道微指挥攻库。

本段未发现逐段复述《三体》或《大明王朝1566》的情况。整体更接近“蒸汽朋克阶级起义”的类型套路（上下层分治、人造太阳、底层暴动），建议在细节上多做区分，避免落入类型窠臼。

### E. 疑问（需作者本人判断）

1. 本书对“四百年”和“多世轮回”的正式设定是什么？营幕篇里反复出现的崇祯、近代烽火、海防要塞、锦衣卫追杀等前史，是否打算在其他幕中补写？如果不打算，建议统一删除。
2. 白道微在营地的身份，到底是“一个月前坠入的苦力”（第170章），还是“七十八层学院出身的前任总工”（第179章）？如果是系统赋予的伪身份，需要在哪里交代？
3. 同契规则是否允许“读心”，以及痛感“放大”而非“分担”？白道微的替死计划和“一方死则双亡”如何自洽？
4. 第180章块74把瘟疫写成白道微蒸汽试验的副作用，这是有意的伏笔吗？如果是，后文是否会让主角面对这份责任？
