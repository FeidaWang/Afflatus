# 分段 03 审稿报告（第17–24章）

### A. 本段总评

第17–24章讲“倒严”的主线：吕芳离京，陈洪掌东厂，高翰文进京下狱，六必居赐菜，台州大捷与胡宗宪辞官，万寿宫大火，蓝道行扶乩，最后严府夜袭药典阁。骨架清楚，历史素材选得也准，但完成度偏低，读起来像没有修订过的初稿。

**最突出的三个问题：**

1. **时间线整体坍塌。**
   - 第17章开头是“五月二十五”，结尾却说第二天夜里就下暴雪。
   - 第18章跳到“十一月十六”。
   - 第21章写“四十一年初春”，章末又说“除夕将近”。
   - 第22章的大火定在“四十一年除夕”。按史实，这时严嵩早已倒台。
   - 第24章里，同一个夜晚一会儿是“正月”，一会儿是“除夕”，章末又写成“嘉靖四十年”。
2. **主角全知全能，“科学”大多站不住。**
   - 活性炭面罩挡一氧化碳。
   - 把纯氧注射进微循环。
   - 用磁铁在沙盘上写字。
   - 东莨菪碱两秒钟让人呼吸肌麻痹。
   - 常灵珂一个人击退八十名死士，白道微纵马跃过数丈高的墙。

   主角每次都零代价取胜，反派于是只剩被动挨打，冲突张力很低。
3. **AI腔堆砌严重。** 本段约8.6万字，感叹号1175个，折合每万字约136个；“彻底”100次，“瞬间”86次，“冰冷”63次，“轰然”33次。几乎每段都用“滔天/千古/惊天”收尾，章末一律是“即将轰然拉开帷幕”式的预告。另外，第18章的“三步擦肩”和高翰文押解两场戏，各被完整写了两遍，细节还互相矛盾。

**最出彩的地方：**
- 第24章块63–67，白道微给常灵珂罩大氅，两人斗嘴（“卡尔曼滤波”“差旅折宿费”）。这段克制、具体、有人味，两人的区分度一下子就出来了，是全段最好的文字。
- 第17章块31–32，小火者给吕芳送糖炒栗子，这个小人物的细节动人。
- 第20章让同一坛六必居酱菜在严、徐、裕三府引出三种反应，结构巧妙。
- 第22章写严世蕃想借大火平账，这个动机合理。

### D. 与原著的关系

- 第17章：改编为主。吕芳离京、陈洪上位的走向，以及吕芳、陈洪、杨金水、黄锦、朱七等人物都借自电视剧《大明王朝1566》（具体情节是否与原剧对应，待查证）。茶席说教、东厂立威、小火者送栗子等细节是原创。常灵珂智退东厂搜查、救治小内侍，白道微远程谋划，两人有一定原创作用，但对主线影响有限。
- 第18章：原创为主。高翰文押解进京、芸娘目送、金水桥“三步擦肩”都不是按原剧名场面复述。主角的作用只是交换情报，戏剧重心在高翰文身上。
- 第19章：原创为主。东厂刑讯、常灵珂施针救人、《广陵散》琴谱密码都是原创；高翰文、芸娘、陈洪沿用原剧人物。常灵珂在情节里起决定作用，但“救星恰好赶到”太巧。
- 第20章：改编为主。“六必居匾额为严嵩所题”是民间传说，原剧中有无相关桥段待查证。“三坛分赐三府”的结构是原创。白道微给裕王出谋、常灵珂诊断嘉靖中毒是原创，但科学解释牵强。
- 第21章：原创为主，取材于史实（台州大捷，胡宗宪、戚继光、俞大猷）。主角通过射表、阵法、药品远程参与，作用被写得过大，胡宗宪才是本章的真主角。
- 第22章：改编为主，取材于嘉靖四十年万寿宫失火的史实，但起因、时间和君臣各自的立场都做了反转。常灵珂火场救驾、白道微“法务会计”溯源是原创，作用关键，但科学上不成立。
- 第23章：改编为主。蓝道行扶乩倒严是正史事件，原剧可能也有演绎（待查证）；乩语的基本格局（问天下为何不治，指严氏为奸）接近正史记载。磁力装置是原创，但物理上不成立；主角在这里是幕后操盘者。
- 第24章：原创为主。夜袭药典阁、首次使用复演券、夜驰救人都是原创，主角是绝对主导。

### E. 疑问

1. **同契的边界。** 本段把同契写成可以远距离传送完整情报、图纸和化学数据的心灵通道，几乎每章都用。这是既定设定吗？若是，需要确认它有没有距离、频率和代价上的限制，否则“三步擦肩”交换情报（第18章）就没有意义了：既然随时能传，何必冒险见面？
2. **复演券的定义与数量。** 第24章的用法是“0.01秒内预演未来30秒”，而不是字面上的“复演/重来”。这与第一部开篇和后面结算系统的定义一致吗？首次使用之后还剩几张？每次使用有什么代价？
3. **常灵珂的年龄与宫中身份。** 第19章写她“年仅双十”，这与现代身份（流行病学专家）的设定一致吗？明代太医院没有女官，这是“幕”世界有意的改动吗？若是，建议在第一次出场时交代一句。
4. **时间线的意图。** 本段是想严格贴合史实（严嵩在嘉靖四十一年五月倒台，万寿宫在嘉靖四十年十一月失火），还是有意压缩、改写？如果是后者，“嘉靖四十一年除夕”这类具体日期建议全部模糊处理，以免和史实硬碰。
5. **第18章与第24章的重复段落。** 第18章的两遍“擦肩”、第17章的两段“茶席对话”，以及第24章结尾那段风格明显不同的斗嘴，是不同版本的稿件混在一起了吗？应该以哪一版为准？
