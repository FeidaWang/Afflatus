# 分段12审稿报告（第89–96章）

### A. 本段总评

本段写的是威慑纪元：从雪地工程逼停水滴，到罗辑下井执剑、温室社会、智子茶道、阶梯计划档案，一直写到程心接剑前夜。结构上最严重的问题是**第89–90章与第91–96章明显是两套互相冲突的稿子**。第89–90章里主角叫“白道伟/常令可”，住在墨尔本卡尔顿老宅，执剑满61年，罗辑101岁，人口两百亿，还有修真式的结算升级和“全书百万字”的出戏旁白；而且威慑崩溃、澳洲大迁徙、三体星系被毁都已经写完。第91章却倒回威慑元年，改用“白道微/常灵珂”，执剑54年、罗辑84岁、人口四十亿，第93–96章再一次推向交接。读者会以为时间线出了故障。

另外两个突出问题：
2. **数字和设定自相矛盾的地方很多**：三体距离写成4/200/210/400光年，舰队规模、罗辑年龄、井深、威慑度、纪年换算前后都对不上。
3. **主角先知先觉，对手被写成摆设**：主角握有“全知洞察”，还能直接说出程心会接剑、人类会被赶去澳洲，却只停留在事后评论和囤物资上。温室社会、秘书长、讲解员、埃里希等配角被漫画化，成了专门挨骂的靶子；文笔上“冰冷/彻底/死死/如同”高度密集，第90章单章有46个感叹号。

写得出彩的地方：
- 第92章罗辑下井前的手擀面晚饭、怀表和茶。
- 第93章便签从问句慢慢变成一道横线。
- 第91章白道微用物理熔丝绕开智子的构思。
- 第95章主角把铜钱留给智子、智子最后把它捏碎，这个前后呼应干净有力。

这几处都有真正的原创温度。

### D. 与原著的关系

- 第89章：改编为主。威慑盛世、智子茶道、社会厌弃罗辑，基本沿用原著的结构。原创部分是常令可对智子力矩和光谱的分析，以及几段明史类比。主角只是旁观和评论，唯一一个“慢雾”情报发现也没有产生后果。
- 第90章：基本复述。块3–15用画卷形式把原著第二部名场面逐条回顾；块47–87按原著顺序复述交接、水滴突袭、澳洲迁徙、广播、三体被毁，还直接使用了原著标志性台词。主角没有实质作用，只获得结算奖励、在旁观战。
- 第91章：改编为主，原创比例中等。雪地对决的结局沿用原著；原创部分有常灵珂现场急救、白道微参与停战谈判并争取解除锁死和对等验证、主角参与选址建井、小米粥等。主角在谈判技术细节上有实际作用，但结果和原著一致。
- 第92章：原创为主。三大发射台工程、物理熔丝对抗智子监督、手擀面告别晚饭、护送下井，都是原著没有展开的空白。主角作用实质性强（硬件设计、维生系统），是本段最好的一章。
- 第93章：原创为主。智子三轮心理攻势、史强之死、心脏急救、寿桃都是原创；温室社会的基调沿用原著。主角有实际作用，承担医疗和维护。
- 第94章：改编为主。女性化温室社会、程心苏醒、公投都沿原著大框架，但大幅夸张。主角只是评论、碰壁、囤物资，没有改变任何事件。
- 第95章：改编为主，原创比例中等。智子茶道和程心获得认可沿用原著；原创部分有茶室对峙、铜钱与围棋隐喻、常灵珂揭露智子的仿生参数、给万有引力号发密电。主角有一定作用，其中密电可能影响后续广播，值得做实。
- 第96章：改编为主，接近复述。阶梯计划的起源、只送大脑、选中云天明，都按原著的顺序和关键对白展开，并且扩写了维德的狠绝。原创部分是档案被抢救的来历、维德以勒索换票、胡宗宪类比。主角只是在读档案、做评论，没有作用。
