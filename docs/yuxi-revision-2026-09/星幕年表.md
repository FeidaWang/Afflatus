# 星幕权威年表

2026-09 改稿版 · 第一阶段。2026-09-30 按《星幕分场大纲》和工序 1 冲突检查修订（作者确认）。“现章节”一列为旧章号，新编号在重写阶段启用。确认后，星幕所有年份、冬眠节点、年龄、距离以本表为准。

## 纪年换算

- 危机纪元元年 = 公元 2007 年（沿用正文第 64 章）。
- 威慑纪元元年 = 危机纪元 208 年（沿用正文第 87 章）。
- 执剑交接在威慑纪元 62 年；此后是约两年的“威慑后”，再进入广播纪元、掩体纪元、银河纪元。
- 23 世纪以后，正文只写纪元年，不写公元年。网上对各纪元的公元换算说法不一，不跟它们硬碰。
- 标 ★ 的是锁点（原著大事件，主角改不了）。原标“待核”的三个年份已于 2026-09-30 对照两份第三方编年表核对（非原著原文）。
