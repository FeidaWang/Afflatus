# 第96章 · 阶梯计划历史回响 · 托马斯·维德的冷血决断
<!-- meta {"wordCount": 10116} -->

<!-- b0 text -->
威慑纪元第五十四年四月，在日内瓦浮空城最高档案馆那座由厚达半米的电磁屏蔽铅板包裹的底层密室中，两道泛着冷白色荧光的量子解密光束，正沿着两百年前公元世纪的只读光盘介质高速扫过。

<!-- b1 text -->
伴随着一阵由于古代编码协议转换而发出的轻微蜂鸣声，屏幕上缓缓跳出一枚深黑色的鹰隼徽章——那是危机纪元初期联合国行星防御理事会下属战略情报局（PIA）的绝密徽记。徽章下方，一行用红色警告字体标注的公文标题赫然在目：【绝密·阶梯计划全景档案·档案编号：PIA-0017-CC】。

<!-- b2 text -->
密室四周的空气被调节得极度干燥，带着一股陈年羊皮纸与磁带退磁后的微焦气味。这里存放着整座人类文明在进入信息云端化之前最后的物理载体。在这个浮空城的一切历史都可以被轻易篡改、重塑与美化的时代，唯有这些深藏在地下深处、没有接入任何市政网络的纯离线光盘，才完整记录着公元世纪最真实、也最血腥的喘息。

<!-- b3 text -->
白道微披着一件深灰色的呢料外套，双手按在冰冷的水晶操作台上。常灵珂坐在他身旁，手里捧着一支高精度微光显微笔，两人的目光同时凝固在档案卷首那一串斑驳泛黄的黑白历史影像上。在那个没有反重力浮空城、没有智子茶道、只有遮天蔽日的工业烟囱与恐慌狂潮的公元时代，整座人类文明正处于基础科学被智子彻底锁死的无边绝望之中。

<!-- b4 text -->
当时的联合国战略情报局是一个拥有近乎无限执法特权的影子内阁。当全球高能物理学家因为加速器数据被智子锁死而掀起自杀狂潮、末日逃亡主义与邪教在各大都市如野草般疯长时，战略情报局设立了秘密的“反失败主义执行处”，用铁血手段镇压一切动摇军心的社会异端。而这头情报巨兽唯一的领航者，正是托马斯·维德。

<!-- b5 text -->
影像中，一间昏暗压抑的地下会议室内，天花板上的老式荧光灯管在电流的喘息中发出刺耳的嗡嗡声。房间正中央的皮椅上，坐着一个约莫四十岁出头的男人。他穿着一件剪裁极其冷硬、没有多余褶皱的纯黑西装，两鬓略带微霜，面部轮廓如同用粗糙的磨刀石硬生生从生铁块上削凿出来。他的双眼深陷在浓密的眉骨阴影下，瞳孔中没有半点多余的情感波澜，只有两道如同刚刚从干冰中淬火取出的森然寒光。

<!-- b6 text -->
档案中甚至记录了一起针对维德本人的未遂暗杀事件。一枚由极端环保主义反战分子安放的微型炸弹在维德的专车底盘爆炸，导致他的左前臂被三枚高速弹片撕裂。然而在送往战地医院的紧急手术中，维德当场拒绝了任何全身麻醉药物，甚至连局部神经阻滞剂都不允许注射。他只是咬着一截厚厚的硬皮皮带，任由外科军医用镊子在血肉中生生剔出碎弹片。当手术结束时，他的脸色惨白如纸，但第一句话却是向秘书索要当天的近地轨道侦察简报。

<!-- b7 text -->
在一份维德亲笔书写的私人作战日记手稿中，白道微读到了这样一段令人不寒而栗的文字：“今夜仰望星空，群星冷漠无声。宇宙不在乎人类的悲喜，更不在乎联合国大厦里那些关于人权的冗长辩论。人权只是灵长类动物在灰尘大小的泥球上自我安慰的内部条约。在深空猎手降临的寒冬里，如果不把自己变成食肉的狼，羊群在秋风刮起的第一天就会被彻底剥皮抽筋。”

<!-- b8 text -->
常灵珂在档案附录中查阅到了战略情报局当年资助的一系列极端生命科学实验。为了保证大脑在脱离躯体后依然能保持神经突触的生物活性，维德动用了相当于一个小国全年的科研预算，在西伯利亚与阿拉斯加的地下实验室里强行推动了“超低温玻璃化脑细胞悬浮冷冻”技术。正是这项在当时遭遇全球伦理审查委员会口诛笔伐的魔鬼实验，才为后来阶梯计划大脑的完整封存奠定了唯一的医学基石。

<!-- b9 text -->
“前进！前进！不择手段地前进！”这是维德亲自刻在战略情报局大门玄关青铜壁上的唯一座右铭。在那个全人类都在为明日的存亡而发抖的恐慌年代，维德不仅对自己残忍，更是以一种视万物为刍狗的绝对冷酷，将整个人类文明视作了一块必须被压榨出最后一点剩余价值的生铁。

<!-- b10 text -->
“在大明朝堂上，这种人被称为‘酷吏’，如来俊臣、周兴、毛骧。”白道微的指尖在全息屏幕上轻轻划过维德那张苍白而冷酷的面孔，声音低沉得宛如石磨碾过粗粝的砂石，“但来俊臣杀人是为了媚上争宠，毛骧罗织罪名是为了皇帝清洗功臣；而托马斯·维德做恶魔，却是为了让人类这个卑微的物种，在神级文明的碾压下多苟延残喘几天。”

<!-- b11 text -->
常灵珂的目光落在一旁的一张青年女子证件照上。照片上的程心梳着整齐利落的齐耳短发，鼻梁微挺，眼神清澈而羞涩，带着刚刚走出大学校园的象牙塔女研究生的纯真与稚气。照片下方的评语只有维德手书的短短两行冷漠字迹：【专业能力合格，性格致命软弱，缺乏冷血杀伐决断力；但具备独特的非理性亲和力，留作观测与破局底牌】。

<!-- b12 text -->
“维德一眼就看穿了程心的死穴。”常灵珂轻轻合上指尖的显微笔，眼底满是复杂难言的酸楚，“他在两百年前就把程心绑上了这辆没有刹车的铁甲战车。维德以为自己可以用冷酷去驯化她的软弱，但他至死都没想到，正是这份被他鄙视的软弱，在两百年后彻底摧毁了他为人类编织的全部生路。”

<!-- b13 text -->
更令人唏嘘的是这份绝密档案能够留存至今的惊险历程。在威慑纪元三十年，全球情感谐振委员会曾通过了一项代号为‘焚洗野蛮’的文化净化法案，下令将公元危机前期的所有战略情报局档案、审讯记录与核战备预案全部投入等离子焚化炉，企图彻底从人类记忆中抹杀维德与阶梯计划的存在。

<!-- b14 text -->
然而，一位年过九旬的公元纪元老档案管理员，冒着被判处‘情绪反社会罪’的巨大风险，将这批原始光盘偷运出了中央机房，亲手用融化的生铅浇铸在古老法典的夹层内部，深埋在日内瓦地下的废弃排污管网深处。老人在遗书中写道：‘一个不敢正视自己身上恶臭与刺刀的文明，迟早会被外面的狼群扒皮抽骨。愿后人有胆量打开这块铅皮。’

<!-- b15 text -->
档案中还记录了维德当年对联合国‘面壁计划’的刻薄嘲讽。在一次绝密局长级跨部门通报会上，维德当着行星防御理事会轮值主席的面，冷笑着将四位面壁者的战略方案扔进了废纸篓：“泰勒想在太空里用量子幽灵舰队玩神风自杀，雷迪亚兹想用全太阳系的核弹勒索水星坠入太阳，希恩斯在神经科学里兜圈子，罗辑在湖畔抱着幻想中的女人做白日梦！这帮面壁者是联合国花重金请来在悬崖边上给羊群跳脱衣舞的戏子！真正的战争没有聚光灯，只有暗室里的匕首与骨头渣子！”

<!-- b16 text -->
维德的个人生活更像是一座寸草不生的荒芜坟场。档案中附带着一份维德当年办公室的清仓清单：一张黑色冷轧钢办公桌、三把折叠铁椅、一个军用铁皮文件柜、一只铜制烟灰缸、一台纯机械发条台钟，以及抽屉里常年压满子弹的伯莱塔手枪。他没有房产，没有家庭，没有朋友，唯一的行囊就是两套换洗的黑色西装。当联合国一位主管财务的高官曾半开玩笑地问他为何不结婚成家时，维德面无表情地吐出一句冷冰冰的回答：“趴在战壕里等待刺刀见红的死刑犯，从不需要在泥地里铺地毯。”

<!-- b17 text -->
甚至连亚洲舰队的创始人常伟思将军，在查阅了战略情报局的绝密日志后，也在绝密备忘录中写下了对维德的评价：“托马斯·维德是一条生活在深海万米水压下的恶煞狂鲨。在承平日久的岁月里，他是人类社会的公敌与梦魇；但在文明濒临灭顶的至暗时刻，也唯有这样没有神经痛觉的深海狂鲨，才敢咬着炸药包撞向外星神明的坚船利炮。”

<!-- b18 text -->
档案的第二卷，完整还原了那个让公元世纪所有航天专家冷汗涔涔的“阶梯计划”诞生之夜。那是危机纪元初期，三体第一舰队刚越过柯伊伯带外围，联合国急需向深空发射一枚探测器，获取外星舰队的一手物理参数与生物学标本。

<!-- b19 text -->
然而，人类现有的工质火箭与离子推进技术，在动辄以百分之一光速飞行的三体战舰面前，缓慢得宛如爬行的蜗牛。即便是倾尽全球储备的重聚变资源，发射一艘万吨级飞船在三百年内追上三体舰队的概率也是绝对的零。在日内瓦那个烟雾缭绕的子夜，年轻的程心凭借着航天工程学的敏锐直觉，提出了一个堪称天才、却疯狂至极的构想——“辐射光帆核脉冲阶梯推进”。

<!-- b20 text -->
在航线的前方，由人类预先布设一千枚高当量热核弹头。当巨大的超轻薄膜光帆载着飞行器掠过每一枚核弹时，核爆产生的狂暴伽马射线与等离子激波，将如同无形的钢铁巨鞭，一次又一次狠狠抽击在光帆之上！一千次核爆，一千级接力加速，最终将探测器在短短几个月内推至光速的百分之一！

<!-- b21 text -->
这项计划在联合国安理会激起了轩然大波。为了凑齐这一千零四枚百万吨级当量的核弹头，美、俄、中、英、法等五大核常任理事国必须在六个月内将各自战备核武库的一半直接拆卸并运往近地轨道。那是人类历史上规模最大、最危险、也是最壮丽的战略物资大调配。数百枚重型运载火箭在酒泉、拜科努尔与卡纳维拉尔角日夜轰鸣腾空，将刺目的火光刺入夜空。

<!-- b22 text -->
而那面总面积达二十五平方公里的超大型光帆，更是一项超越当时工业极限的奇迹工程。由单层碳纳米管与反射铝膜编织而成的薄膜，厚度仅有区区数十纳米，轻薄得就像一片飘在真空中看不见的幽灵肥皂泡。只要在折叠展开过程中产生一丝细微的静电吸附，整面巨大的星际风帆就会彻底扯碎成漫天飞扬的金属碎屑。

<!-- b23 text -->
当程心在白板上画出最后一根激波受力曲线时，战略情报局的所有科学家全部屏住了呼吸。那是一种将毁灭人类数万次的末日核武库，化作星际风帆强劲推力的狂放想象！然而，紧随其后的残酷工程计算，却像一盆刺骨的冰水，将全场刚刚升起的狂喜彻底浇灭。

<!-- b24 text -->
严苛的齐奥尔科夫斯基火箭方程与光帆薄膜耐受极限，对飞行器的载荷质量施加了近乎死刑判决般的绝对禁锢。在工程论证的第一周，预算载荷还是相对宽裕的五吨；第二周，在推力衰减模型修正后，被削减至一吨；到了第三周，热力学反冲模型证实，即便是使用人类最轻的纳米复合气凝胶，有效载荷也必须死死压制在一百公斤以内！

<!-- b25 text -->
来自俄罗斯的宇航科学院院士双手抱头痛苦呻吟，美洲舰队的推进专家甚至提议向太空发射一只经过脱水休眠的猕猴或者几株抗辐射地衣。一百公斤，连最轻便的生命维持机组都无法容纳，更遑论维生水槽、高压氧舱与宇航员的肉身！

<!-- b26 text -->
总工程师米哈伊尔指着满屏跳动的热力学与质量极限红线，当场失声痛哭：“局长，一百公斤不可能载人！光帆在核爆的高温烧蚀下只能撑住十八点五公斤的受力极限！十八点五公斤……这根本不是在造一艘宇宙飞船，我们是在造一只给鬼魂飞行的棺材！”

<!-- b27 text -->
维德坐在长桌尽头，一口一口缓缓吐出浓稠的青灰色烟雾。他掐灭了手中的雪茄，用一种毫无起伏的嗓音回答道：“鬼魂不需要上厕所，米哈伊尔。鬼魂不需要吃饭，也不需要氧气。鬼魂是整座地球上唯一能飞过四光年而不腐烂的东西。”

<!-- b28 text -->
在全场死一般的寂静中，维德面无表情地吐出了那四个让历史战栗的字：“只送大脑。”

<!-- b29 text -->
“只送大脑？！”当时的程心当场吓得面无血色，手中的圆珠笔啪嗒一声掉在地上，“局长，您在说什么？！大脑离开身体怎么可能活下去？这完全是对生命伦理的公开亵渎！”

<!-- b30 text -->
维德转过头，那双死灰色的眼睛死死盯住程心，目光如同两根淬毒的铁锥，直接刺穿了年轻女孩的灵魂深处：“程心，动动你的工程脑子！十八点五公斤装不下一个活人，但装一颗浸泡在生理盐水和营养液里的健康人类大脑，绰绰有余！人类做不到肉体超低温冬眠，但三体人能做到！智子展现出的微观物理技术，证明三体文明拥有远超我们的生物工程与量子克隆能力！他们如果捕获了这艘飞船，第一件事就是将这颗大脑重新复活并培育出一具新的躯体！”

<!-- b31 text -->
“我们是在给四光年外的敌人送去一个活体间谍，送去一颗扎在他们心脏里的特洛伊木马！”维德猛地一拍桌子，声音低沉如雷鸣，“至于伦理？底线？文明都要被连根拔起了，全人类都要变成宇宙里的灰烬了，你居然在这里跟我谈伦理？！如果出卖母亲能换来飞船提速一秒钟，我托马斯·维德会毫不犹豫地把亲生母亲卖进妓院！”

<!-- b32 text -->
会议室内的空气仿佛在刹那间被抽干了。几位资深的老生物学家当场干呕着冲出了大门，有人愤怒地摘下证件摔在地上宣布辞职，斥责维德是一个披着人皮的疯子与纳粹杂碎。然而维德只是面无表情地看着那些愤怒离去的人，眼神冷酷得没有一丝波动。他知道，在文明生死存亡的悬崖边上，所谓的高尚道德不过是一块用来遮羞的破布，唯有最极端的残忍，才能在死神的手指缝里撬开一丝缝隙。

<!-- b33 text -->
为了牵引这面巨大的超薄光帆，阶梯计划动用了汪淼院士纳米材料研究中心研发的‘飞刃’超高强度碳纳米管系绳。十二根比头发丝还要细上一百倍的纳米缆绳，如同十二根无形的蛛丝，死死拉拽着后方的有效载荷舱。只要其中一根缆绳在核爆的狂暴横切冲击波中产生微米级的应力断裂，整个风帆就会在太空中剧烈失衡偏转，飞船将瞬间被甩离既定轨道，化作深空中永远无法找回的孤魂。

<!-- b34 text -->
而在联合国大会对阶梯计划的最终表决中，维德动用了战略情报局全部的谍报暗网。档案显示，欧洲某大国驻联合国特使原本在伦理听证会上持坚定反对票，维德在前一天深夜将一份涉及该特使家族海外洗钱与地下军火交易的厚重档案拍在其床头柜上。第二天清晨，那位特使在投票箱前双手颤抖着投下了赞成票，阶梯计划最终以一票的微弱优势在联合国惊险通关。在维德的世界里，程序正义与道德洁癖，从来不值一颗核弹的一枚引信。

<!-- b35 text -->
光帆背面的防烧蚀热力学设计更是凝聚了当时基础材料学的全部心血。为了抵御一千枚核弹在千公里近距离内释放的千万度伽马光子轰击，帆面背向核爆的一侧，被喷涂了一层纳米微孔烧蚀碳气凝胶。每一次核爆的烈焰扑向光帆时，微孔碳材料在亿分之一秒内瞬间汽化，喷射出一股致密的高能等离子射流，在吸收致命高热的同时，形成了一股极为狂暴的次级反冲推力。这是一场在千亿度烈火与绝对零度真空之间走钢丝的极端工程魔术。

<!-- b36 text -->
在阶梯计划推进轨道的深空坐标图上，一千零四枚战备核弹被密密麻麻地锚定在从地球轨道一直延伸至木星轨道外侧的双曲线深空回廊中。这道长达十亿公里的核爆阶梯，宛如一条由千万颗炽热恒星骸骨铺就的登天长廊。整座人类文明动用了全部的太空力量，只为了将一枚不到二十公斤的冰冷器皿，以自残般的暴烈速度甩向茫茫黑暗。

<!-- b37 text -->
阶梯计划在维德铁腕的推进下以不可思议的速度向前狂奔。为了寻找那个“愿意为全人类献出大脑”的合适载体，战略情报局设立了苛刻到近乎病态的筛选模型：第一，必须具备极高的物理与工科智识，能够在外星环境中完成情报收集；第二，必须身患绝症、肉体即将死亡，以规避合法的故意杀人指控；第三，必须在现实社会中极度边缘化、毫无亲友牵绊，在潜意识中对人类社会保持着既疏离又深刻的哲思。

<!-- b38 text -->
在这场残酷的猎杀中，程心被维德任命为“阶梯计划特别联络官”。维德每天将她锁在地下情报室里，逼迫她审阅上百份重症病人的临终心理档案。年轻的女孩几乎每晚都在噩梦中惊醒，梦见自己的双手浸泡在浓稠冰冷的福尔马林药水里，无数颗鲜活跳动的大脑在器皿中无声哀嚎。

<!-- b39 text -->
在一次深夜的值班中，程心终于无法忍受这种近乎凌迟的折磨，她冲进维德的办公室，含泪质问：“维德局长！为什么是我？您明明知道我是一个软弱的人，我讨厌杀戮，我讨厌刺刀！您手下有几百名冷血的情报特工，为什么非要把我这样一个刚刚毕业的女孩推到刽子手的绞架旁？！”

<!-- b40 text -->
维德坐在落地窗前，凝视着窗外夜幕下的日内瓦湖。月光洒在他那张毫无血色的脸上，宛如一尊守墓的石像。良久，他转过身，缓缓吐出一口青烟：“程心，你以为毒蛇喜欢跟毒蛇打交道吗？全人类是一只惊恐万状的羔羊，如果战略情报局从头到尾只有我这柄带血的屠刀，公众的道德审判在第一天就会把这个项目撕成碎片。我需要你，因为你身上散发着这颗星球上最纯洁的母性香气。你的眼泪是最好的麻醉剂，它能让被选中的羔羊心甘情愿地躺在我的手术台上。”

<!-- b41 text -->
维德走到办公桌前，拉开抽屉，取出一柄沉甸甸的军用大口径手枪，重重地拍在大理石桌面上。他盯着程心的眼睛，声音低沉如恶魔的诱导：“程心，拿起它，对准我的脑袋开枪。如果杀了我能让这艘飞船提速哪怕一秒，你应不应该开枪？”

<!-- b42 text -->
程心吓得步步后退，整个人瘫软在墙角，泪水夺眶而出：“不！我绝不开枪！杀人是犯罪，杀人是魔鬼的行为！”

<!-- b43 text -->
“看吧，这就是你的本质。”维德弯下腰，收回手枪，眼神中没有愤怒，只有一种看透一切的深渊般的悲悯与轻蔑，“你是一个把自己的良心看得比整个种族存亡还要贵重的精致利己主义者。你宁可看着全人类被三体人屠戮殆尽，也不愿意让自己的双手沾染上一滴泥垢。在这个宇宙里，弱小不是生存的障碍，傲慢和自私的圣母心才是。”

<!-- b44 text -->
维德随手在全息屏幕上调出了三千份经过初筛的临终病人病历，当着程心的面将它们一张张划过：“在这座星球上，每秒钟都有人在病榻上痛苦地窒息而死。他们死得毫无尊严，化为医院焚化炉里的一撮灰烬。而我现在给他们一个机会——让他们的大脑飞越四光年的星河，成为整座人类文明的先知与刺客！这是莫大的荣耀！可你却在为他们的骨肉分离而哭泣！程心，收起你那廉价的眼泪吧，宇宙不会为眼泪停转。”

<!-- b45 text -->
然而，命运的荒诞与残酷就在于此。维德在浩如烟海的档案中，最终锁定了那个完美的候选人——身患晚期原发性肺癌、在孤僻与绝望中等待安乐死的航天系孤僻青年，云天明。而当维德顺藤摸瓜调查云天明的背景时，档案赫然揭示：云天明是程心在大学时代的同窗，并且，这个卑微内向的男孩，用毕生的孤独与秘密，暗恋了程心整整七年。

<!-- b46 text -->
甚至更残酷的是，正是程心本人在最初的局内技术交底时，曾随口提到过大学班上有位同学在低重力推进力学方面有着惊人的直觉与才华。维德利用大数据追根溯源，硬生生在一所破旧的临终关怀医院里，找到了正在大口咳血的云天明！

<!-- b47 text -->
当维德将云天明的病历摔在程心面前时，程心的整座精神世界轰然倒塌！维德命令她：“去见他，程心。用你那双清澈的眼睛看着他，去说服他自愿把头颅切下来送给三体人。只有你能做到这一点。因为对于一条在烂泥里快要淹死的狗而言，只要你的一滴眼泪，他就会毫不犹豫地爬上祭坛。”

<!-- b48 text -->
程心当时踉跄着冲出了办公室。在洗手间的镜子前，她看着自己惨白如死人的面孔，拼命用冰水冲洗着眼睛。她想逃跑，想辞职，想向媒体揭露维德的一切恶行；但一个更恐怖的声音在她心底响起——如果阶梯计划失败了，如果人类真的因为缺乏情报而被灭绝，她又该如何面对自己的良心？正是在这种道德双重绞杀的绝境中，程心最终屈服了。她迈出了走向云天明病房的第一步，而那一步，彻底将她的一生刻进了罪孽与救赎的无底深渊。

<!-- b49 text -->
在战略情报局大楼幽暗狭窄的消防安全通道里，维德曾点燃一支雪茄，在青灰色的烟雾中对程心说过一段令她一生梦魇缠身的对话：“程心，天底下有两种人。一种是挖井的人，他们满脸污泥、双手老茧、浑身散发着恶臭的汗酸味；另一种是喝水的人，他们坐在凉亭里，穿着白衣，用纯金的杯子盛着甘泉，写着赞美泉水清冽的诗篇。我就是那个在烂泥里刨食挖井的粗胚，而你，天生就属于那个凉亭。但你要记住，如果没有我满手的泥血，你们这帮喝水的人，早就在第一场旱灾里全渴死了。”

<!-- b50 text -->
档案中附带着云天明当年在北京郊区临终关怀医院的最后体检病历。那是原发性肺燕麦细胞癌，癌细胞已经广泛侵袭了纵隔淋巴结、胸膜与第四腰椎。在泛黄的医疗影像记录中，那个身形消瘦如枯槁树枝的年轻男孩，独自坐在破旧的病床上，剧烈地呛咳着暗红色的血沫，然后用颤抖的手将血迹擦在粗布床单上。由于家境贫寒，他的亲生父亲与姐姐甚至拒绝为他垫付最后一期靶向止痛药的费用，逼迫他尽快在安乐死协议上签字，以腾出名下那套老旧的回迁房遗产。

<!-- b51 text -->
正是在这样一个被整个世界遗弃、连至亲之人都视其为累赘的绝望寒冬里，程心带着战略情报局的保密协议与公文，走进了那间弥漫着消毒水与死亡腐气味的病房。而那个濒死的男孩，在看到昔日大学梦中情人的那一瞬间，眼中绽放出的不是求生的渴望，而是一种近乎神圣的坦然与决绝。

<!-- b52 text -->
为了让活体大脑提取在法律层面上合法化，维德甚至亲自参与了联合国在危机纪元三年通过的《特别自愿终结生命与战略器官捐献特别法修正案》的秘密起草。在这部日后被伦理学家痛斥为‘魔鬼法案’的文件中，维德极其隐晦地塞入了一条特殊条款：允许身患不可逆绝症的公民，在自愿实施安乐死的前提下，将其完整中枢神经系统签署捐献给‘具有关乎全人类最高生存利益的特殊宇航项目’。正是这一纸冷血的法条，将云天明推上了不可逆的剖脑祭坛。

<!-- b53 text -->
走出医院的那天黄昏，程心一个人走在北京街头刺骨的寒风里。天空中飘着灰白色的细雪，枯黄的梧桐树叶在水泥地面上打着旋。年轻的女孩靠在路灯杆下，双手捂着面孔失声痛哭。她不知道自己究竟是拯救人类的天使，还是索取灵魂的黑白无常。她把那个深爱自己的少年亲手送进了通往死神的铁棺，而命运却以一种最残忍的方式，把这个天大的罪孽包装成了至高无上的英雄史诗。

<!-- b54 text -->
档案的光影在纯白色的屏幕上渐渐淡去，密室内重新陷入了冰冷的静默。白道微缓缓站起身，指骨在沉重的铅板墙面上敲出清脆的声响，眼神中翻涌着穿越两个世纪的历史悲凉。

<!-- b55 text -->
“维德当年如果执剑，水滴根本不敢出动。”白道微的声音沙哑得可怕，“维德的威慑发射概率不是百分之九十，而是百分之百！他是一个只要为了目标可以不惜毁灭一切的疯子，三体人怕罗辑，但三体人对维德是深入骨髓的恐惧。可人类社会亲手抛弃了维德，人类用民主的选票把毒蛇关进了笼子，却把执剑的权杖送到了白鸽的手里。”

<!-- b56 text -->
“大明嘉靖朝也有维德这样的人。”白道微仰起头，看着斑驳的拱顶，“那是胡宗宪，那是戚继光。胡宗宪为了平定东南倭患，甘冒天下大不韪，借严嵩之势筹集军饷，在文官清流眼里，胡宗宪是个阿附奸相的无耻权奸；可要是没有他背着骂名在浙江杀人筹饷，东南半壁江山早就被倭寇化为焦土！天下人享受着胡宗宪打下的太平，却在严嵩倒台的那一天，迫不及待地把胡宗宪逼死在狱中！”

<!-- b57 text -->
“古来慈不掌兵，义不理财。”白道微冷笑一声，“商鞅在秦国变法，车裂而死，但秦军凭商鞅之法扫灭六国；吴起在楚国变法，伏尸受戮，但楚国因吴起而雄踞江汉；张居正为了大明国祚呕心沥血，死后尸骨未寒便遭抄家清算！历史上的狠人，把所有的脏水、恶名与血污全部揽在自己身上，替后人挡住风刀霜剑；而后代那些在暖阁里吃饱喝足的软骨头，却反过来唾弃他们的残暴！”

<!-- b58 text -->
常灵珂将指尖轻轻按在程心当年的档案评语上，眼角微微湿润：“道微，你看到了吗？程心不是生来就要做圣母的。在阶梯计划里，她亲眼看着那个暗恋自己的男孩被活生生地切下头颅，看着那颗大脑迷失在永恒的黑暗冰冷中。那种长达两个世纪的负罪感，已经把她的灵魂彻底压垮了。她今天之所以如此疯狂地渴望用‘爱与和平’去包容三体人，不是因为她真的有多么崇高，而是因为她急需一场全人类的救赎，来洗清自己双手上当年沾染的云天明的鲜血！”

<!-- b59 text -->
“她要用全人类的命，来为她个人的良心殉葬。”白道微冷冷地转过身，披上了大衣，“这种自私的崇高，比世间任何贪婪与残暴都要可怕一万倍！三体人早就把这一点算得清清楚楚。他们故意在茶道里奉承她，故意在舆论里神化她，就是为了让她在接剑的那一刻，完全沉浸在‘圣母降临’的虚幻道德高潮中，彻底丧失按下毁灭按钮的勇气。”

<!-- b60 text -->
而在浮空城的日内瓦最高法院遗址前，昔日托马斯·维德被宣布剥夺一切政治权利的旧审判庭，早已被改造成了一座挂满鲜花与反战诗歌的“星际爱心咖啡馆”。年轻的新人类情侣们坐在维德当年受审的被告席上，轻啜着草莓泡沫奶昔，调笑着那个“长得像个骷髅架子一样的公元老杀手”。

<!-- b61 text -->
常灵珂在随身携带的加密终端上，对地下医疗库的自动唤醒程序进行了最后的校核。三千支大容量多巴胺肾上腺素混合急救针、两万个便携式负压隔离帐篷，以及足够支撑十万人三个月维生的合成蛋白质胶囊，已经在澳洲内陆的红色沙漠地下完成了冷藏封存。她转头看向白道微：“道微，无论他们怎么选，我们救活一个是一个。”

<!-- b62 text -->
白道微将档案箱的物理重锁彻底扣死，沉重的黄铜锁扣发出一声冰冷的金属闭合声。这一段被尘封了两百年的冷血记忆，不仅没有随风而逝，反而像是一柄在时间尽头早已校准准星的狙击步枪。枪膛里的子弹已经呼啸出膛，跨越了两个世纪的寒夜，正不偏不倚地瞄准了整座文明脆弱的眉心。

<!-- b63 text -->
离开绝密档案馆时，白道微与常灵珂登上了穿梭在浮空城之间的反重力轻轨。车厢内铺着柔软的淡粉色羽绒地毯，数十位新人类青年正戴着全息发光发箍，低声传看着程心年轻时的全息生平影像，赞叹着“她连微笑都带着宇宙母亲的芬芳”。车厢内飘散着甜腻的果味芳香，没有人察觉到车窗外那越来越阴沉的天色，更没有人知道，他们的生路早在两百年前就已经被他们的博爱亲手掐断。

<!-- b64 text -->
白道微坐在车厢角落，冷眼看着那些无忧无虑的新人类，转头对常灵珂低声说道：“大明崇祯十七年三月，闯王李自成的大军已经逼近昌平，北京城里的东林党大臣们还在文华殿里为崇祯皇帝的一句‘君非亡国之君，臣皆亡国之臣’而据理力争，自诩满朝清流皆是道德君子。直到破城那一天，崇祯吊死煤山，文臣们争先恐后剃发出迎！今天这满车厢的粉头戏子，连当年的东林党人都不如，他们连剃发的力气都没有，只会在水滴落下来的那一秒哭着喊妈妈！”

<!-- b65 text -->
窗外，日内瓦湖畔的春雨淅淅沥沥地敲打着铅板外的双层钢化玻璃。在两千米深的地下，盘古发射井内的八十四岁老人罗辑，正在最后的静默中等待着交接的时刻；而在平流层之上的浮空天城里，四十亿沉浸在爱与感动中的新人类，正手捧着白色的蜡烛，为程心的新生高唱着圣洁的赞歌。两百年前托马斯·维德那双冰冷的眼睛，仿佛穿透了虚空与时光，在阴暗的角落里默默注视着这一切，发出一声令人毛骨悚然的无声冷笑。在这一片虚伪的祥和与爱意之中，距离那场注定到来的毁灭交接，只剩下最后的三十六个小时。

<!-- b66 text -->
密室的冷光渐渐熄灭，古老的光盘停止了旋转，重新归于永恒的幽暗与休眠。白道微与常灵珂的身影消失在通往地底升降机的长廊尽头。而在虚空之中，历史那沉重冷酷的车轮从未停歇，它碾碎了维德的残忍，也即将碾碎程心的慈悲，带着四十亿梦游般的生灵，径直冲向命运最深沉的血色断崖。
