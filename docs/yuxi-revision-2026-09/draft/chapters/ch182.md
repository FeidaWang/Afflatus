# 第182章 · 熔断令

<!-- b0 text -->
当十万工民在铁锈色血泊中艰难喘息时，第七十八层云顶最高执政大厅内，一场决定全域命运的秘密董事会议正步入最后的表决时刻。

<!-- b1 text -->
大厅正中，悬浮着由阿耳戈斯超算实时渲染的全息三维巨构模型。在中下层区域，代表着致命嗜热真菌感染密度的暗红色斑块，已经如同溃烂的毒疮般吞噬了整整四十层空间。六名身穿深黑色天鹅绒礼服的高级董事围坐在圆桌旁，手中摇曳着昂贵的水晶杯，神情漠然而冷血。

<!-- b3 text -->
“诸位请看这组动态资产折旧曲线。”雷诺兹总监手中握着一支镀金的激光教鞭，指向了全息悬浮光幕上的精算模型，“第三十六层至下沉负三层，集中了整座巨构百分之八十的重体力劳动者。过去十年中，由于重度矽肺、关节畸变以及热应力损伤，这批工人的综合劳动力净残值已经降至每人每年不足三百信用点；而为了维持他们的呼吸与最低卡路里，我们每年必须耗费价值四百万点的工业合成淀粉与高压蒸汽。”

<!-- b4 text -->
“换句话说，这场嗜热真菌风暴不是天灾，而是大自然为我们量身定做的一场‘资产不良包出清’。”雷诺兹眼神狂热而冷血，嘴角噙着刀锋般残忍的笑意，“只要我们彻底焊死六十八道主隔离闸门，让高温和缺氧在密闭空间内自然发酵，七十二小时后，整座中下层将变成一座无菌化的骨灰坑。所有的工潮苗头、所有的反抗分子，连同白道微那个狂妄的技术刺客，都将被一次性永久物理消解！而我们节省下来的巨额热能，足以支撑云顶区平稳度过未来的百年极夜！”

<!-- b10 text -->
执政厅内，负责资产审计的女董事埃莉诺夫人优雅地放下了手中的银质茶匙，猩红的唇角勾起一抹讥诮：“雷诺兹总监，如果按照第七号规程彻底熔断中下层，我们在帝国商业联合会上的报表该如何平账？整整十万名登记在册的低阶契约劳工，在法律账目上可是一笔不小的流动资产。”

<!-- b11 text -->
“这一点夫人大可放心。”雷诺兹微微躬身，眼中闪烁着老谋深算的狡诈，“法务与精算部门已经准备好了全套‘不可抗力极端生物灾变豁免报告’。我们可以向云顶中央保险总局全额申请巨额的‘全域不可逆损耗重组理赔金’！理赔所得的战略外汇，不仅能彻底抹平这批贱民的账面残值，甚至能为我们下一季度的财报带来高达百分之二十八的超额净利润！这是一场在商业上无可挑剔的完美出清！”

<!-- b12 text -->
雷诺兹举起酒杯，将杯中殷红如血的勃艮第红酒一饮而尽，眼神中闪烁着如同毒蛇般的得意与冷酷：“先生们，为了奥林匹斯重工集团永远健康的财务报表，为了一个没有冗余、没有暴动的纯净巨构，干杯！让这座天然的大熔炉替我们清理垃圾吧，到了下周一，所有的负债都将化作灰烬！”

<!-- b13 text -->
几名原本还在犹豫的董事听到这里，眼中顿时绽放出贪婪的光芒。在一片优雅的刀叉碰撞声与香槟泡沫的轻响中，十万条鲜活人命的生存权利，被这群穿着体面晚礼服的金融寡头们，在杯盘狼藉之间轻描淡写地彻底抹杀！

<!-- b14 text -->
大厅内陷入了短暂的死寂。六名董事互相对视了一眼，随后，一只又一只戴着璀璨宝石戒指的手掌，缓缓举起。全票通过！

<!-- b15 text -->
“执行最高指令。”雷诺兹在终端上狠狠按下了血红色的执行符印，“发布‘第七号全域物理熔断令’！启动全区铝热焊死程序！将那群贱民，永远埋葬在他们的生铁坟墓里！”

<!-- b16 text -->
上午十点整。整座穹顶巨构原本断断续续的警报声，在同一毫秒内骤然转变为一种令人汗毛倒竖的持续长鸣平直尖啸！

<!-- b17 text -->
滋————！刺耳刺目的紫红色最高级生化危险爆闪警示灯，如同地狱深处裂开的猩红巨眼，在八十层回廊的每一个天花板上疯狂旋转！

<!-- b18 text -->
紧接着，全域广播网的高音喇叭里，响起了阿耳戈斯超算那冷酷无情的自动化执行播报：

<!-- b19 text -->
“警告！全域防化紧急条例第七号已激活！判定第三十六层以下区域为不可逆深度生物污染死区！启动主闸门绝对物理阻断！倒计时：五、四、三、二、一！”

<!-- b20 text -->
轰！轰！轰！轰！轰！

<!-- b21 text -->
一连串惊天动地、足以引发小型地震的沉重撞击声，在垂直纵贯三百米的天井四周疯狂炸开！数十道单扇自重超过四十吨的铅钢复合重型防爆气密主闸门，在脱扣电磁铁的断电释放下，顺着抹满重油的钢轨以自由落体的恐怖动能断崖式轰然砸落！坚固的高强混凝土立柱在剧烈的撞击下迸裂出一道道触目惊心的蛛网裂纹，漫天烟尘与铁锈粉末如暴雨般倾泻而下！

<!-- b22 text -->
在第三十六层主闸门外侧的防暴警戒哨塔内，六名身穿全封闭防生化重型装甲的奥林匹斯精锐近卫宪兵，正隔着镀金强化防弹面罩，冷漠地注视着门内那一张张绝望捶打铁门的面孔。他们的耳机里充斥着云顶指挥部下达的‘格杀勿论’死命令，四联装大口径速射机枪的电热供弹机在电机驱动下发出冰冷刺耳的预热蜂鸣。在极权统治者的机器眼中，门内的十万同胞早已不是人类，而是一堆需要被物理隔绝的生物垃圾！

<!-- b23 text -->
原本畅通无阻的垂直悬梯被闸门硬生生腰斩切断！中层与底层之间仅存的六十八条换乘栈桥、物流滑槽与安全检修竖井，在短短数秒内全数被厚达半米的冰冷合金板死死封死！

<!-- b25 text -->
在第十六层的主通道前，甚至上演了一幕幕撕心裂肺的人间惨剧。一名年仅十二岁的运料小童正试图冲过正在下坠的厚重钢闸去寻找另一侧的哥哥，闸门底部的巨大刀刃在零点几秒内砸落，老工人拼死将孩子向后拽回，沉重的铁门轰然闭合，将走廊地面上的一根粗达五十毫米的高碳钢撬棍瞬间切成两截！烟尘狂涌，气浪将数十名工民掀翻数米之远，而那条连接亲人与生路的钢铁走廊，在这一瞬间化作了永不可逾越的生死天堑！

<!-- b26 text -->
伴随着大门砸落，自动铝热剂焊接系统瞬间被强行触发！上百台固定在门楣上方的自动焊接机械臂如同嗜血的机械毒蜂般向下垂落，耀眼夺目的蓝白色电弧刺得人双目剧痛！高达三千摄氏度的铁铝热熔流如同一道道炽热的金色瀑布，沿着闸门边缘的密封凹槽疯狂浇灌！厚重的钢格板在超高温下发出痛苦的滋滋哀鸣，油漆迅速炭化起火，焦黑的毒烟遮天蔽日，将一道道生铁大门彻底焊铸成了一堵堵一体成型的冰冷墓碑！

<!-- b27 text -->
在第二十八层与第三十层的主换乘平台上，沉重闸门的砸落甚至诱发了局部的管线大爆炸！由于闸门下砸时巨大的剪切力硬生生切断了两根直径达半米的低压回水管道，上百吨滚烫的工业热水混合着生铁瓦砾如天河决堤般疯狂倾泻！数十名正在走廊里排队等待分发退烧药的年迈工民连惨叫都来不及发出，便被狂暴的浊流卷入了数十米深的天井空腔！

<!-- b28 text -->
几名忠诚的年轻机修工拼死将一根长达四米的重型工字钢横插在三十六层副闸门的滑轨中央，企图用钢铁的死力强行阻挡闸门的闭合。然而，在四十吨闸门自由落体形成的巨大冲击力面前，那根坚韧的高碳工字钢宛如一根脆弱的火柴棒，在崩裂出一连串刺耳的火星后瞬间被砸成了扭曲的麻花！闸门轰然到底，将所有生的希望以最野蛮、最冷酷的方式彻底踏碎！

<!-- b31 text -->
当最后一座主闸门被铝热剂焊死的沉闷轰鸣传到下沉负三层时，整座地底玄武岩大殿内的环境，在数十分钟内演变成了一场灭绝性的物理灾难！

<!-- b32 text -->
随着上层所有排风竖井的绝对切断，地心深处四口深层地热井持续喷涌出的上万吨超临界高温蒸汽，彻底失去了向外宣泄的对流通道！原本维持在四五十度的高温空间，其室温在以令人发指的速度一路飙升——五十五度、六十度、六十五度！滚烫炽热的白雾浓稠得伸手不见五指，每一块裸露在外的铁板都变得滚烫如火炭，普通人只要皮肤轻轻贴上去，便会被瞬间烫起成片的巨大水疱！

<!-- b33 text -->
更致命的是氧气浓度的雪崩！三万人聚集在密闭的玄武岩空腔内，每一分每一秒都在消耗着原本就极其微薄的存量氧气。中央监控仪表盘上的氧气浓度指针，正在以每小时近一个百分点的恐怖速度直线下跌！空气中充斥着浓烈刺鼻的二氧化碳、二氧化硫与重金属硫化物蒸汽，工人们大汗淋漓、面色惨白，每一次呼吸都像是有一把烧红的钢刀在喉管与肺叶中疯狂搅动！

<!-- b35 text -->
工人们身上的粗麻工装在滚烫的汗水与蒸汽浸泡下紧紧贴在皮肉上，稍微动作剧烈，就会将整层表皮硬生生撕扯下来！几十名患有严重矽肺病的老矿工在极度缺氧的高温环境中痛苦地翻滚着，他们的指甲在坚硬的玄武岩地面上划出道道血痕，浑身剧烈抽搐，由于高热引发的脑水肿，不少人已经开始出现幻觉，疯狂地撕扯着自己的头发与衣服！整座三万人聚集的大殿，已然濒临群体性热衰竭休克的崩溃边缘！

<!-- b36 text -->
在下沉负三层深处那座宛如火山内部的机修大厅内，独眼老陈与老马正赤裸着汗流浃背的精壮上身，挥舞着沉重的生铁手锤拼死加固着‘撼地者一号’装甲冲车车头的聚能破障角铁。空气中的温度已经攀升到了令人眩晕的六十三度，每一次吸气都伴随着气管黏膜被灼伤的剧烈痛楚。

<!-- b37 text -->
“白工！二号与四号高压蒸汽主锅炉的蓄压表针已经打到了红线最顶端！一百五十个工程大气压！”老马抹了一把满脸的滚烫汗水，声音沙哑如砂纸摩擦，“再不泄压，整座机修大厅的蒸汽母管就要发生大面积物理爆管了！我们必须在二十分钟内发动冲锋，否则就算不被焖熟，我们也会被自己的蒸汽大炮活活炸碎！”

<!-- b38 text -->
“稳住！把所有过热蒸汽全部注入冲车的超临界增压汽缸！”白道微单手撑在冲车车门上，目光冷静得如同一尊俯瞰万物的死神，“这股蒸汽，不是我们的坟墓，而是我们要送给雷诺兹的开门大礼！”

<!-- b39 text -->
在负三层深处那间闷热如蒸笼的机修大跨间里，滚烫的高温冷凝水不断自数百米高的生铁顶梁上滴落，砸在烧红的机车外壳上发出清脆刺耳的滋滋声。为了对抗缺氧与恐怖热浪带来的精神崩溃，在白道微的带领下，几名白发苍苍的老矿工率先敲击着手中的生铁扳手，唱起了一支在深渊矿坑中流传了八十年的古老劳动号子：“生在黑铁坑，死在生铁槽，不拜天顶神，只握手中镐……”

<!-- b40 text -->
起初只是微弱沙哑的低哼，但仅仅片刻之后，这首古老悲壮的歌谣便如同低频雷暴般，在整整三万名狂躁窒息的硬汉胸膛深处轰然共鸣！没有人再惊慌乱跑，没有人再绝望啜泣，数万双滚烫的大手握紧了风镐与铁锤，将濒死的绝望在战歌声中淬炼成了焚尽一切的革命烈焰！

<!-- b42 text -->
“白工……我们被彻底焊死在棺材里了！”一名年轻的矿工学徒扑倒在掘进机旁，大口大口地喘着粗气，胸膛剧烈起伏，眼泪混合着汗水在黑灰的脸庞上冲刷出两道白印，“通风全停了！上头要活活把我们三万人全焖熟成肉干啊！”

<!-- b43 text -->
“慌什么！都给我把腰杆挺直了！”

<!-- b44 text -->
一声如同怒雷般的断喝在浓雾深处炸响！白道微身披一件湿透的阻燃帆布工装，迈着沉稳有力的步伐踏上了装甲机车的高台。尽管汗水顺着他冷峻的下颌不断滴落，尽管高温蒸汽将他右颈处的死囚烙印灼烧得阵阵剧痛，但在那双如鹰隼般深邃坚毅的黑眸中，看不到一丝一毫的慌乱与动摇！

<!-- b45 text -->
“老马！老陈！立刻启动三号与五号备用矿井压缩空气瓶组，向大殿核心区注入纯净氧气，维持兄弟们的生命体征！”白道微声音洪亮如钟，有条不紊地下达着一道道精准至极的工程指令，“传令爆破连队，将四台‘撼地者’装甲冲车的蒸汽过热锅炉全部点火加压！雷诺兹以为用几十吨铁板就能把我们困死？他太小看地底工人的力量了！准备聚能切割炸药，目标——第三十六层东侧主换乘闸门！”

<!-- b46 text -->
与底层的物理绞杀相比，在第四十层以上的中层区域，雷诺兹操弄的舆论诛心毒计正在疯狂发酵。

<!-- b47 text -->
全域广播中，播音员的声音换成了一种极具煽动性与悲悯色彩的伪善调子，一遍又一遍地在各层回廊中轰鸣回荡：

<!-- b48 text -->
“各位中层的守法工民、工匠与妇女同胞们！管委会极其沉痛地通告一项紧急事实：下沉负三层的暴徒与极端恐怖分子，在白道微的指使下，恶意破坏了底层地热生物安全阀，主动将深埋地底的致命‘嗜热黑死真菌’作为生化武器在巨构内引爆！”

<!-- b49 text -->
“目前，底层的暴民已全员陷入真菌感染的狂暴失控状态，并企图携带致命病毒向中层生活区疯狂反扑，企图拉上中层十万无辜妇孺与他们同归于尽！为了捍卫第四十二层女营的纯洁与你们家中幼童的生命安全，管委会不得不采取壮士断腕的痛苦决断——暂时焊死下沉通道！任何企图从下方开启闸门的行为，皆属于恐怖袭击，中层公民有权就地反击歼灭！”

<!-- b51 text -->
广播甚至播放出了一段段经过移花接木、被刻意剪辑过的声音片段——将矿工们痛苦的呛咳声与呼救声，配以刺耳的金属撞击音效，生生描摹成了“生化变异暴民正在啃食铁门、企图冲入女营宿舍撕咬幼童”的恐怖神话！

<!-- b52 text -->
这番颠倒黑白、将受害者污名化为投毒暴徒的恶毒广播，瞬间在第四十层至第四十五层的难民群体中引发了一场剧烈的恐慌风暴！许多不明真相的年轻母亲吓得面色如纸，紧紧抱住怀中发烧的孩子；几名车间巡查员甚至挥舞着扳手冲到三十六层闸门前，歇斯底里地高喊着“绝对不能放底层的感染暴民上来”！

<!-- b53 text -->
