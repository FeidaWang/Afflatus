# 第121章 · 终极广播与光粒审判

<!-- b0 text -->
深空深处的无边死寂中，“万有引力”号与“蓝色空间”号两艘庞大的恒星级战舰并肩悬停。在刚刚脱离的那片宏伟壮丽的第四维空间碎块边缘，两颗曾将人类整座太阳系舰队逼入绝境的强相互作用力水滴，此刻已经化作了两团毫无生气的失重残骸，像两颗灰暗冰冷的死石，漫无目的地漂浮在零下二百七十度的宇宙真空之中。

<!-- b1 text -->
那是一场神迹般的胜利。人类士兵关一帆与两舰特战队员利用四维空间对三维空间的绝对几何俯视，从高维度的缝隙中直接伸手探入水滴的无缝外壳，破坏了其内部强相互作用力发生器的超微观力场线圈。曾经不可一世、硬度堪比中子星物质的极端物理造物，在跌落回三维空间的一瞬间，瞬间退化成了脆弱普通的重金属合金。然而，两舰联合指挥舱内没有一个人欢呼，空气沉重得宛如凝固的液态铅。

<!-- b2 text -->
因为四维空间的保护罩正在不可逆转地收缩、消散。高维碎块在宏观三维大宇宙的引力潮汐撕扯下，正以每秒数千公里的速度急剧蒸发与降维。在舰载全息雷达的监视下，那些原本色彩斑斓、能够一眼望穿物质内部无限细节的高维视界，正如同退潮的海浪般迅速干涸。一旦战舰彻底重返三维平直空间，一直被高维曲率阻断的三体智子监控与两颗水滴失联的信息，将在千万分之一秒内暴露给四光年外的三体第一舰队主力！

<!-- b3 text -->
更致命的噩耗来自地球方向刚刚被量子纠缠中继器勉强捕获的一段残缺通信。那是白道微与常灵珂通过澳洲地下微电网与南极烛龙台废墟暗中发射的急促摩斯电码。电码中的每一个字都在滴着四十亿同胞的滚烫鲜血：“威慑已破。执剑人程心弃剑。水滴饱和轰炸地表发射台。智子发布全人类大移民令，四十一亿人被强行圈禁于澳洲荒漠。断水断电，大饥荒爆发。智子演说：到处都是粮食。人类文明至暗时刻降临，速决！”

<!-- b4 text -->
“速决……”万有引力号舰长莫沃维奇面色惨白，布满血丝的双眼死死盯着全息屏幕上那行凄厉的绝笔电文。作为太阳系联邦最年轻的战略指挥官，他深知这两个字的分量。四光年外的母星同胞正在炼狱中被活活饿死、被野蛮践踏。人类耗费两个世纪建立起来的现代文明与尊严，在智子的武士刀下已被剥皮抽筋。

<!-- b5 text -->
“我们已经没有退路了，莫沃维奇舰长。”蓝色空间号舰长褚岩身披深蓝色太空防寒风衣，缓步走到星图推演台前。他的声音低沉却带着钢铁般的沉凝，“水滴被摧毁的物理事实瞒不过智子。最多再过十二个小时，高维碎块彻底蒸发，三体舰队就会知道我们不仅抗命，而且掌握了高维打击手段。到那时，三体占领军在澳洲的最后一点伪善面具将被彻底撕碎，四十亿同胞将面临全域灭绝性大屠杀。”

<!-- b6 text -->
“启动引力波天线，发射终极黑暗森林广播！”关一帆大步走入舱门，右臂上还缠着在四维战斗中被微陨石划伤的止血绷带。这位兼具深空天文学家与天体物理学者双重身份的年轻人，目光锐利得像一柄刚淬过冰雪的解剖刀，“我们手中握着全人类最后一枚可以和魔鬼同归于尽的筹码！只要坐标广播出去，三体星系就注定毁灭！三体舰队必须立刻调头逃命，澳洲的四十一亿同胞才能从绞刑架上被放下来！”

<!-- b7 text -->
“但是关博士，你很清楚广播的代价！”万有引力号大副唐铮猛地拍案而起，由于极度激动，胸口的徽章在急促起伏，“引力波脉冲是球形全向扩散的！在三维空间中，任何接收到引力波的高级文明，只要比对双星引力微扰与光谱红移，就能在零点零一秒内顺着脉冲反向锁定太阳系的位置！发射三体坐标，等于同时宣判太阳系在未来数十年内必遭神级文明的毁灭性打击！”

<!-- b8 text -->
“那也比眼睁睁看着四十亿同胞在澳洲被当成人肉罐头吃掉要强一百倍！！”关一帆双眼赤红，额角青筋暴起，几乎贴在唐铮的鼻尖上咆哮，“你以为不广播太阳系就能保全吗？！三体占领军会把人类彻底变成圈养的牲畜，然后用我们的工业资源把太阳系改造成对抗宇宙猎手的钢铁要塞！我们是在用整座文明的未来，去换取同胞在今天活下去的权利！哪怕只有万分之一的生机，也是生机！”

<!-- b9 text -->
“全舰官兵的家属……都在地球上啊。”唐铮脱力般跌坐回椅子上，双手捂住面孔，肩膀剧烈颤抖，“我的妻子在悉尼，我的小女儿才七岁。如果坐标发出去，我们亲手毁灭了三体，也亲手把死神的判决书砸在了自己孩子头上……这太残酷了，这根本不是军人能够承受的负荷。”

<!-- b10 text -->
莫沃维奇舰长缓缓闭上双眼，胸膛剧烈起伏。在漫长得令人窒息的两分钟内，整座指挥大厅落针可闻，只有生命维持系统微弱的气流声在低沉回响。随后，莫沃维奇睁开眼，目光中再无半点动摇：“启动全舰终极表决程序。依照两舰战时紧急联合宪章，将广播决议权交给‘万有引力’号与‘蓝色空间’号上的全部一千三百七十二名军人与学者。每一个人的投票权均等，每一个人的灵魂都在见证历史。”

<!-- b11 text -->
战舰内响起了凄厉而庄严的电子钟声。全舰每一个舱室、每一个维修管廊、甚至深层核聚变反应堆的巡检工位上，全息投票屏同时在官兵们的视网膜中点亮。屏幕上没有任何花哨的竞选辞令，只有两行冰冷刺骨的血红大字：【决议案：是否立刻启动万有引力号中子引力波全向发射管，公布三体星系与太阳系宇宙坐标？选项：是 / 否】。

在生态水培农业舱内，年轻的女通信兵在屏幕前无声地流泪，她的父母就生活在澳洲北领地的荒漠铁皮棚里；在机控室，年迈的动力工程师颤抖着摘下沾满油污的护目镜，用长满冻疮的大拇指死死按在了绿色按钮上；在医疗观察区，伤员们躺在悬浮床上，用意念神经传感器发出了坚定的脉冲。这是一场全人类历史上绝无仅有的公投，投票者们很清楚，他们亲手按下的，将是两座恒星系上百亿智慧生命的死刑判决书。

<!-- b13 text -->
十分钟后，投票结果在中央穹顶全息屏上定格：总投票人数一千三百七十二人，赞成票一千一百三十五票，反对票二百一十九票，弃权十八票！赞成率高达百分之八十二点七！

<!-- b14 text -->
“决议通过。”莫沃维奇舰长挺直腰杆，向全舰官兵行了一个标准至极的军礼。随后，他从军装最内层的贴身口袋里，掏出了一枚由超纯钛合金铸造、封存了整整五十年的主发射物理密钥。那枚密钥泛着古老而苍凉的金属光泽，仿佛是从两百年前冷战核潜艇上撕下来的一枚坚硬鳞片。

<!-- b15 text -->
褚岩同样从胸口取出第二枚物理副密钥。两名舰长在八名荷枪实弹的宪兵护卫下，迈着沉重如铁的步伐，走到了指挥台正中央那座被重重铅锑合金防护罩锁死的终极发射井前。咔嚓！咔嚓！两枚冰冷的机械钥匙同时插进锁孔，在令人牙酸的金属摩擦声中，顺时针旋转了一百八十度！

<!-- b16 text -->
“引力波发射井预热！中子简并态核心磁约束场开启！”广播员的声音在全舰每一个角落回荡，带着一种穿越生死的超然与肃穆。在万有引力号长达一点五公里的战舰腹部，三根粗壮如摩天大楼的巨型中子引力波振荡导管缓缓向舰体两侧展开，露出了核心处泛着幽暗微蓝光晕的高能引力振子。

<!-- b17 text -->
万有引力号的核聚变反应堆输出功率在瞬间被推升到了百分之一百二十的超负荷极限。整艘战舰的外壳蒙皮上泛起了一层微弱的等离子电离蓝光，巨大的电磁力场如同一张无形的大网，死死束缚着那三颗处于狂暴振荡边缘的中子星微缩核心。导管周围的物理空间甚至由于极度微观的引力透镜效应，产生了如同水波般的折射畸变。

五、四、三、二、一……倒计时归零！莫沃维奇舰长与褚岩舰长没有丝毫迟疑，四只戴着白色战术手套的大手同时狠狠拍在了鲜红如血的物理点火击发柄上！

轰——！！那不是声音，因为真空无法传导声波。那是时空度规本身在引力波极速震荡下产生的剧烈痉挛与宏观扭曲！战舰内部所有的陀螺仪与重力发生器在千分之一秒内同时发出刺耳的过载尖啸！

<!-- b20 text -->
在万有引力号长达数公里的引力波天线核心，数亿吨微观中子简并态物质在极强超导磁场的精确调制下，以相对论速度进行着极其狂暴的高频非对称自旋。每一个微观中子的运动，都在三维平直时空的大网中撕扯出一圈圈肉眼无法窥见的深邃涟漪。引力波，这宇宙中最难被吸收、衰减率近乎为零的终极信息载体，化作一道横扫一切的无形风暴，以整整三十万公里每秒的极限光速，狂暴地冲向宇宙深渊！

<!-- b21 text -->
广播的内容简练、精准、冷酷到了极致。那是用宇宙中最普适的引力摄动微积分代码编织的“死刑判决文书”。它毫无保留地向全宇宙广播了三体三颗恒星的相对质量、引力共振轨道参数、以及四光年外伴随的单恒星系统（太阳系）在银河系第三旋臂中的精确坐标！它使用了三十余颗超高精度毫秒脉冲星作为几何参照基准，哪怕是文明层级刚刚能够观测脉冲星的初级猎手，也能顺着这份星历坐标图，在三秒钟内锁定目标的咽喉。每一个字节，都在向潜伏在宇宙黑暗森林中的神级猎手们高呼：这里有两群刚刚走出襁褓的文明，他们已经点燃了火把，他们在这里！

在万有引力号的深空观测屏上，引力波的球形波前以不可阻挡的气势划破了柯伊伯带的漫天碎冰。它穿过了奥尔特星云那片寒冷致密的彗星云海，穿过了广袤死寂的星际尘埃幕墙，向着银河系中央的超级黑洞、向着猎户座大星云、向着仙女座星系的无垠深渊无休止地蔓延扩散！宇宙中所有的无线电通信在它面前都弱小得如同草丛中的萤火，而这束引力波，是一枚在漆黑如铁的大礼堂中突然被引爆的兆吨级镁光弹！

<!-- b23 text -->
在柯伊伯带边缘散布的数十处三体秘密引力波监听浮标，在波前扫过的一瞬间全部发生了超限熔断。高敏感度的引力张量传感器被过载的波峰彻底击穿，原本死寂的波谱图瞬间被冲刷成了一片刺目的极值直线。潜伏在暗处的智子中继站在虚空中疯狂地发出最后一道确认乱码，随后彻底被无序的时空涟漪吞噬。

<!-- b24 text -->
地球，南半球，澳大利亚，乌鲁鲁红石荒漠。正午的烈日将红色的砂岩炙烤得腾起阵阵扭曲的热浪。数百万身着破烂衣衫、骨瘦如柴的难民正排着蜿蜒数十公里的长队，在刺刀与水滴微型巡逻机的监视下，等待着领取每天仅有一百毫升的劣质再生水。空气中弥漫着绝望的死气与尸体腐烂的恶臭。

<!-- b25 text -->

然而，就在这一瞬间，智子脸上那抹宛如古代瓷器般精致冰冷的微笑，毫无征兆地彻底僵死了！她手中端着的青瓷茶盏在半空中猛烈一颤，滚烫的碧绿茶汤泼洒在雪白的长袍上，她却恍若未觉！

<!-- b28 text -->
在智子那由微观超弦处理器构成的中枢神经回路中，数以百亿计的量子纠缠通信信道在同一微秒内被无尽的红色报错警报彻底淹没！来自海王星轨道外的量子引力波传感器阵列发回了最确凿的物理信号测定：高能相干引力波脉冲已经突破太阳系引力屏蔽区！有效发射功率达到四点二乘以十的三十六次方焦耳！球面波前已越过火星轨道！不可逆！无法拦截！无法涂抹！

“广播……发出了……”智子的樱唇微微颤抖着，吐出了一句人类语言。她的声音不再空灵甜美，而是退化成了一种充满机械杂音、带着近乎人类癫狂绝望的剧烈震颤，“引力波天线启动了……你们……你们疯了……你们把全宇宙的死神……全都叫来了……”

<!-- b30 text -->
智子猛地从榻榻米上站起身，浑身关节发出刺耳的高频机械震鸣。她再也没有看那些在烈日下挣扎的难民一眼，甚至直接踩碎了身前那张名贵的紫檀茶几，身形化作一道凄厉的白色残影，疯了一样冲向停泊在荒漠深处的超导反重力飞艇！在她身后，在整个澳大利亚乃至全世界巡逻的数千架微型水滴无人机，突然齐刷刷地调转机头，放弃了对难民的所有封锁，尖叫着冲入万米高空！

常灵珂霍然抬头，迎着刺目的阳光望向北方天空。在帐篷外的废弃通讯塔顶端，白道微正迎风而立。那个公元男人的旧大衣在滚烫的干热季风中猎猎作响，他的手里紧紧攥着一台不断闪烁着刺目绿光的纯硬件解密器。白道微低下头，隔着漫天飞舞的红沙，与常灵珂四目相对。白道微的眼眶湿润了，他用尽全身力气，向着下方这片受尽屈辱的人间地狱，发出了如同野兽破笼般的嘶吼：
