# 第94章 · 人性向安逸滑落 · 极度女性化与温室社会

<!-- b0 text -->
威慑纪元第五十四年的春日，阳光以一种前所未有的纯净透亮，穿透了地球平流层那层薄如蝉翼的微纳环境调控膜。在三千米高空的云海之上，数万座通体由轻质发光复合材料与反重力场发生器托举的“浮空天城”，正如同盛开在苍穹中的巨大白色雪莲，随风静谧漂移。

<!-- b1 text -->
脚下的大地早已退化成了一片无边无际的莽莽原始森林与沼泽荒原。人类在威慑纪元的这半个世纪里，彻底废弃了公元世纪那些笨重喧嚣的地面钢筋混凝土丛林，也将危机纪元那宛如地底蚁穴般的地下树城封存进了历史档案馆。新人类将自己的全部生活、艺术与浪漫，搬上了这片与雷电云雾为伴的空中天庭。

<!-- b2 text -->
白道微与常灵珂并肩走在浮空都市“新雅典”中央大道通透的玻璃步道上。脚下是翻滚如白色波涛的平流层积云，间或能从云隙中瞥见两万里下波光粼粼的太平洋蔚蓝水面。道路两侧没有传统的店铺与招牌，随处可见的是由分子重构雾化喷泉凝结而成的透明休憩亭，空气中弥漫着混合了甜橙花与合成雪松的微醉冷香。

<!-- b3 text -->
浮空城的建筑构造彻底抛弃了“防御”的概念。所有的住宅与公共机构没有一扇实体防盗门，也没有一把机械或电子锁。在人际交往中，隐私被一种由微表情与神经脑电波礼貌协议所约束的虚化光栅替代。在公众认知中，给自己的房门装上一把锁，是对邻人和文明的最大侮辱，意味着使用者心中依然残留着公元世纪野蛮盗窃与杀戮的阴暗烙印。

<!-- b4 text -->
整个城市的交通网络由无声的反重力滑行泡组成。这里听不见任何引擎的轰鸣与刺耳的刹车声，人们在半空中悄然交错，通过脑神经植入芯片进行着无声的信息交换与问候。大声喧哗被视为极度粗鲁的冒犯，连街头的宠物都是经过基因静音改造的发光软体水母，在微风中慢悠悠地浮沉漂泊。

<!-- b5 text -->
这里的食物供应已经彻底脱离了动植物屠宰与烹饪的痕迹。街角的空中餐厅里，人们围坐在柔软如棉花糖的磁悬浮气囊沙发上，用晶莹剔透的水晶小匙舀食着富含多肽与微量元素的半透明凝胶，或者饮用着散发着果香与晨露气息的人造花蜜露。在整个城市的法律法规中，任何金属刀叉、明火烹饪以及动物红肉都被视为“极具进攻性与血腥原始崇拜的违禁品”，连餐厅使用的餐具都是边缘圆润、受力即化的可降解琼脂材料。

<!-- b6 text -->
迎面走来的一群年轻新人类让白道微不由得放慢了脚步。如果不是胸前微型生物身份光环上的微弱性别标识，即便是最精明的老中医，也绝难在十步之内分辨出这些青年的男女。他们的面部骨骼被基因修饰与产前骨密度微调雕琢得极其精致小巧，下颌圆润如初生的白瓷，鼻梁纤细修长，没有半点粗粝的骨节突起。

<!-- b7 text -->
他们身上裹着由感光智能变色纤维编织的半透明宽袍，那种袍服随着心情与微风在淡粉、浅鹅黄与薄荷绿之间如水波般流转。男孩子们的腰身细得仿佛一只手就能环抱，声音经过喉软骨声带调频器的修饰，显得娇柔清脆、宛如林间黄莺出谷；他们三五成群，手挽着手，在浮空草坪上追逐着几只由纳米微机械驱动的透明发光蝴蝶，银铃般的欢笑声在轻柔的暖风中回荡。

<!-- b8 text -->
新人类的日常语言也经历了一场彻底的“去冲突化”洗礼。在他们的词典里，“战争”、“敌人”、“消灭”、“处决”、“牺牲”等具有血腥意味的词汇，早已被教育委员会从初级启蒙教材中彻底剔除，取而代之的是“跨周期协调失范”、“未对齐的潜在伙伴”、“重塑谐振态”等一长串软绵绵的学术代称。任何在公共场合提高嗓门、使用带有命令性口吻说话的人，都会被全息安全系统立即亮起黄灯，判定为“情绪失控且需要接受芳香疗愈的心理患者”。

<!-- b9 text -->
为了盘古深井基地的常规设备维护，白道微曾前往浮空城资源调配总署，试图申领一批耐高压的超导碳炔电缆与深井液氮泵替换件。然而，接待他的是一位只有二十余岁、眼窝抹着晶莹珠光眼影的青年行政专员。专员连握笔写字都会觉得手指酸痛，只是轻飘飘地划动着全息光屏。

<!-- b10 text -->
“白老先生，您的申请在第一轮人工智能伦理审查中就被驳回了。”青年专员的声音柔弱得几乎让人听不真切，“全球和平预算委员会刚刚将深地重工业与地下战备设施的资金削减了百分之九十二。那些资源已经被全面转拨给‘太阳系环轨道花瓣光雕艺术工程’与‘三体文化共鸣交响乐团’。在这个两个文明共同走向永恒博爱的黄金年代，您为什么还要把珍贵的超导材料，埋进那些暗无天日、充满暴力隐喻的冰冷石头洞里呢？”

<!-- b11 text -->
白道微看着眼前这位甚至没有力气拧开一瓶物理密封水的年轻专员，眼底的冷意愈发深沉：“如果四光年外的水滴突然落下来，你那些花瓣光雕能抵挡水滴一微秒吗？”

<!-- b12 text -->
专员像是听到了某种不可理喻的荒诞胡话，娇嗔地掩住了嘴唇，眼眸中满是怜悯与惊恐：“天呐，白先生，您怎么能有这么可怕的想法？智子女士每周都会在文化沙龙上为我们展示三体星系的优美诗歌，他们怎么可能发射水滴呢？暴力只是低维野蛮物种的自残行为，真正的神级文明之间，唯有爱与美的共鸣。您的暴力妄想症真的需要去谐振中心做一次全脑净化了。”

<!-- b13 text -->
“在大明万历年间，这种体貌做派被称作‘粉头小旦’，那是秦淮河画舫上的伶人取悦达官显贵的花样。”白道微走出调配总署，双手插在深灰色的毛料大衣口袋里，眼神冷峭如古井寒潭，“可现在，整整四十亿人类青年，全变成了这副没有骨头的娇嫩模样。力量与肌肉被斥为野蛮，刚毅与铁血被判为残暴。一个人若是骨头硬一点、眼神凶一点，就会被这个温室社会视为异端。”

<!-- b14 text -->
常灵珂挽着白道微的臂弯，指尖轻轻滑过路旁一朵由水气凝聚而成的人造水晶玫瑰。那花朵在指尖触碰的刹那，化作了一缕温暖的香雾，随后又在微电磁场的束缚下重新凝聚成型。“道微，这不仅仅是审美风尚的变迁，这是人类神经内分泌系统的群体退化。在过去的半个世纪里，没有饥荒，没有战争，没有沉重的体力劳动，甚至连轻微的病痛都在胚胎期被基因剪刀彻底抹杀。生物学告诉我们，环境决定形态，极度安全温和的温室，必然培育出最没有自卫能力的脆弱花草。”

<!-- b15 text -->
在步道中央的广场上，一座巨大的球形全息水幕正向公众展示着本年度的“星际和平艺术大奖”获奖作品。画面中，三体第一舰队那棱角分明的反物质战舰被渲染成了温和的淡紫色剪影，而地球的一艘科考穿梭机正优雅地穿行在战舰的光环之中，两道等离子尾迹在太空中勾勒出一个完美的金色同心圆。配乐是经过超声调频的舒缓竖琴曲，数以万计的新人类青年坐在台阶上，眼含热泪地仰望着水幕，如痴如醉。

<!-- b16 text -->
“他们真的以为，和平是这串竖琴音符带来的。”白道微冷哼一声，转过头去不愿再看，“他们不知道，在这首曲子背后，在两千米深的地下冰冷石窟里，有一个八十四岁的老人正把手指死死扣在毁灭两个世界的扳机上，每一秒都在拿自己的命当赌注。他们吸着那个老人流血换来的氧气，却在为刽子手的微笑感动得痛哭流涕。”

<!-- b17 text -->
社会的极度娇弱化不可避免地带来了对历史的激进反攻。在过去的二十年里，全球人文科学界掀起了一场席卷所有大中小学教科书与公共舆论的“反思危机纪元运动”。在那套由新人类哲学大师与伦理学家精心构建的话语体系中，危机纪元两百年的抗争史，被整体定性为“人类集体歇斯底里症与父权毒性进攻欲的丑陋爆发”。

<!-- b18 text -->
在新雅典浮空城的中央历史陈列馆前，白道微与常灵珂驻足在一座名为《挣脱锁链》的巨型现代雕塑下方。雕塑由一种漆黑沉重的玄武岩雕刻而成，刻画着一个面目狰狞、手持骷髅手杖的老人，正死死卡住两个纯洁婴儿的脖子。婴儿一个代表地球，一个代表三体。而在老人的头顶，用鲜红如血的激光打出了一行触目惊心的大字：【独裁者罗辑与未被审判的反人类罪】。

<!-- b19 text -->
更荒诞的是陈列馆内对末日之战的历史解构。在全息沉浸式剧场中，当年水滴贯穿人类两千艘恒星战舰的惨烈杀戮，被重新剪辑为一场“文明接触的沟通悲剧”。解说词中用柔和的合成女声娓娓道来：“……那是由于公元世纪遗留的军国主义思维作祟，人类联合舰队摆出了极其粗暴的受降包围阵列，导致三体无害的和平探测器在受到过度引力激惹后产生了被动防御反应。丁仪教授等人若是能够以拥抱而非冰冷的榔头去接纳它，那场大火或许根本不会烧起。”

<!-- b20 text -->
白道微曾试着走进浮空城的一所高等自然哲学学堂。在天文观测台上，当一位年轻的教师向学生们展示浩瀚璀璨的银河猎户座旋臂时，白道微忍不住插了一句：“星光虽美，但每一颗恒星后面都可能藏着手握光粒与二向箔的猎手。宇宙是一座黑暗森林。”

<!-- b21 text -->
话音刚落，整间教室陷入了死一般的惊恐与窒息！数名学生吓得捂住耳朵尖叫失声，那位年轻的女教师脸色瞬间煞白，颤抖着用胸前的手环按下了紧急心理干预报警：“安保系统！这里有未登记的公元纪元精神创伤遗留者！他正在向未成年人散播极度残暴的‘猎杀性宇宙毒素’！快来救救孩子们！”

<!-- b22 text -->
不到三十秒，三台圆滚滚的粉色心理安抚机器人便悬浮冲入教室，向空气中喷洒出浓烈的镇静香雾，并极其客气地将白道微“请”出了教学区。白道微站在走廊尽头，看着那些在香雾中软绵绵倒在软垫上的师生们，心中唯有一阵深入骨髓的悲哀。在这个连真理都被判定为犯罪的世界里，任何试图叫醒梦中人的声音，都成了十恶不赦的噪音。

<!-- b23 text -->
陈列馆内，一位身穿淡紫羽纱长裙、面容清丽的年轻男性讲解员，正用一种饱含悲悯与控诉的颤音，向一群只有七八岁大的幼童讲解着历史：“孩子们，请记住这个黑暗的名字。在半个世纪前，这个叫罗辑的人，利用核弹与宇宙暴徒的黑暗法则，强行阻断了我们与三体兄弟文明和平拥抱的历史进程。他把自己关在地下，用毁灭两个星系的疯狂手段，剥夺了全人类在阳光下无忧无虑呼吸的权利。他不是英雄，他是人类文明进化史上一颗迟迟未能切除的恶性肿瘤。”

<!-- b24 text -->
几个幼童吓得扑进年轻母亲的怀里，眼眶通红地哽咽道：“老师，那个怪物现在还在地底下吗？他会不会突然按动炸弹，把我们的天城炸掉？”

<!-- b25 text -->
“别怕，宝贝们。”讲解员弯下腰，温柔地抚摸着孩子们的额头，眼角泛起圣洁的泪光，“文明的光芒终将驱散野蛮的幽灵。全球公投委员会已经收到了三十八亿张连署请愿书，我们将用无私的爱与最高道德的选票，在今年之内彻底收回那柄暴虐的权杖。我们将把罗辑请出地下室，送上人类伦理法庭的审判席，让他为自己五十年来对全人类自由意志的绑架付出代价。”

<!-- b26 text -->
在新雅典浮空城的公共全息频道中，甚至上演了一出名为《空椅审判》的虚拟法庭辩论。智能AI公诉人指着正中央那把空荡荡的黑色高背椅，列举了罗辑的七大罪状，包括“未经全人类民主授权擅自设立毁灭机制”、“长期散布宇宙丛林猜疑论毒害儿童心灵”、“以引力波发射按钮对地外友善文明实施长达半世纪的跨星际霸凌”。全息网络上的实时支持率投票柱，瞬间飙升到了百分之九十八点九的“有罪定论”。

<!-- b27 text -->
白道微站在人群后方，双拳在袖袍中捏得咔咔作响，浑身的血液仿佛在瞬间凝结成了冰碴。在大明朝堂上，他见过文官集团颠倒黑白、构陷忠良；他见过严党为了私利构陷沈炼、杨继盛；他见过朝廷把浴血杀敌的将士当成叛贼问斩。但他从未见过这般荒谬绝伦的人间惨剧——一个文明被拯救者亲手将拯救自己的神灵推上绞刑架，甚至是用一种极尽温柔、饱含道德优越感的方式！

<!-- b28 text -->
“当年北宋宣和年间，徽宗皇帝在汴京城里修艮岳、造万岁山，天下文人吟风弄月，自夸天朝上国礼乐昌明，把驻守西北边陲与西夏死战的西军将领视作粗鄙杀才。”白道微的声音低沉得可怕，“结果呢？金兵铁骑南下，渡过黄河如入无人之境，汴京城破之日，徽宗钦宗被掳北狩，三千宗室宫女尽沦奴籍，百年繁华不过是一场风吹即散的绮梦！眼下这群穿着纱裙的新人类，比当年汴京城里的亡国文人还要昏聩十倍！”

<!-- b29 text -->
常灵珂伸出双手，紧紧握住白道微颤抖的右手，将自己掌心的温热一点点渡入他的指节：“道微，冷静。莫与虫豸论春秋。从我们走出大明国门的那一刻起，你就该明白，凡俗众生的狂热从来与真理无关。当人类习惯了免于恐惧的特权，他们就会反过来憎恨让他们认识到恐惧存在的人。在他们眼里，三体舰队是看不见摸不着的四光年外的童话，而地下室里手握开关的罗辑，才是他们床榻底下随时会爆炸的火药桶。”

<!-- b30 text -->
在公共虚拟网络上，针对罗辑的道德审判已经演变成了一场全民狂欢。著名虚拟偶像“爱丽丝”发布了一首名为《放下那把剑，去拥抱星光》的流行单曲，下载量在三天内突破了五十亿次。在歌曲的音乐录影带中，数千名穿着白色纱裙的年轻男女手持纸折的和平鸽，跪在盘古基地被全息投影覆盖的地表竖井周围，唱着祈求“和平与宽恕”的歌谣。主流媒体的社论用极其轻蔑的笔调写道：“威慑纪元是人类文明的耻辱柱，它证明了即使在掌握了反重力技术的今天，我们的大脑中依然残留着旧时代茹毛饮血的丛林残余。”

<!-- b31 text -->
作为全球生命维持工程与公共卫生伦理委员会的首席顾问，常灵珂在威慑纪元第五十四年三月，受邀前往位于日内瓦浮空总部的全球人类生理与心智监测中心，对全人类的年度体质报告进行交叉审核。

<!-- b32 text -->
