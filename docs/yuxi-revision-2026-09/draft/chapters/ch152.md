<!-- b2 text -->
在椭球空间的极远端边界处，原本高耸坚硬的玄武岩环形山脉上空，骤然垂落下了数百道犹如实质的淡蓝色离子分解光幕。光幕如同一把把由纯粹引力张力编织而成的巨大梳子，轻柔而无可阻挡地拂过千万年来沉睡的灰黑岩层。

<!-- b3 text -->
岩石接触到光幕的刹那间，没有飞沙走石，也没有震耳欲聋的崩裂声。坚硬的硅酸盐矿物、致密的玄武岩晶格与金属矿脉，在强相互作用力退相干算法的作用下，被瞬间抹平了分子间的化学键结合力，化作了一缕缕细腻无暇、泛着幽幽冷蓝微光的等离子体气溶胶！

<!-- b4 text -->

<!-- b5 text -->
白道微站在穿梭机敞开的登舰舱门旁，手中握着全息测控光笔，深邃的双眸死死锁定在主控光屏的微观流变图谱上。

<!-- b7 text -->

<!-- b8 text -->

<!-- b9 text -->

<!-- b10 text -->

<!-- b11 text -->

一道微弱、纯净而生机盎然的碧绿光晕，在冰冷死寂的金属底板上悄然绽放开来。

<!-- b79 text -->
那是一只只有排球大小、由绝对透明的高强度石英玻璃吹制而成的全封闭微型生态球！

<!-- b80 text -->
球体内部注着大约两升清澈纯净的小宇宙山泉水。在清冽的水底，铺着几颗五彩斑斓的鹅卵石；一小株青翠欲滴的细叶水草在水中舒展着柔嫩的叶片，叶片表面挂着几颗微小的氧气泡；而在水草的掩映下，一尾只有两寸长、浑身泛着璀璨金红光泽的小金鱼，正摆动着轻纱般的透明鱼鳍，在玻璃球内灵动欢快地游戈嬉戏！

<!-- b81 text -->
这只微小的生态球，连同里面的水、草与鱼，净重整整五公斤。

<!-- b82 text -->
随着物质抽吸工程的推进，小宇宙内的声学环境发生了诡异而森严的剧变。

<!-- b83 text -->
原本由于松软泥土、茂密麦田与木屋对声波的自然吸收，小世界里的声音总是温润而柔和的。然而此刻，当所有的有机物与地貌全部被剥离干净之后，整座空间只剩下一座空旷巨大、直径达一公里的内凹金属球壳！

<!-- b84 text -->
每一个人的呼吸声、皮靴踩在合金地面上的金属摩擦声，都在这死寂的铁盒子里被无限放大，激起阵阵冰冷刺骨的回响。空气变得极其稀薄，头顶的天幕彻底熄灭，原本温暖的人造白昼化作了一片纯粹的幽黑，唯有穿梭机两具主探照灯射出的雪白光柱，在冰冷的金属地板上投下长长的人影。

<!-- b90 text -->
白道微凝视着那只五公斤的生态球，清瘦的面庞上浮现出一抹从未有过的复杂神色。这位精通大宇宙宏观拓扑的战略大师，在这一刻，看穿了这个小球背后那震撼整座宇宙的终极哲学隐喻。

<!-- b91 text -->
“程心，灵珂，”白道微缓缓开口，声音在空旷的金属球壳内激起幽远的回声，“你们知道这只球有多重么？”

<!-- b92 text -->
“净重五公斤。”常灵珂柔声回答，美眸坚定地迎向白道微深邃的目光。

<!-- b93 text -->
“五公斤……”关一帆苦笑了一声，有些手足无措地挠着花白的头发，“天啊，我们刚刚向大宇宙归还了整整三亿八千五百万吨物质，连一根麦秆、一捧泥土都没舍得留下……而你们两个，却要在这座即将被彻底拆毁湮灭的小宇宙里，留下整整五公斤的质量？！”

<!-- b94 text -->
“一帆，这不是自私。”常灵珂走到白道微身旁，伸出温热的手掌，轻轻贴在白道微坚毅的胸膛上，声音轻柔却充满穿透万古的力量，“大宇宙的大坍缩，是为了让生命在新的十维田园里重生。如果在这场毁灭与新生的漫长等待中，整个宇宙连一尾游动的小鱼、连一株翠绿的水草都没有留下……那么在时间的尽头，大宇宙迎来的究竟是生命的复活，还是一场冰冷的物理重演呢？”

<!-- b95 text -->
常灵珂顿了顿，眼眸如星河璀璨：“生命是宇宙唯一的奇迹。把这五公斤的生命留在这里，不是偷窃，而是我们人类文明写给未来新宇宙的一封情书。我们要让未来的造物者知道，在这个黑暗残酷的冰冷长夜里，曾有一群凡人，那样深情、那样倔强地爱着生命本身。”

<!-- b96 text -->
白道微长长吐了一口气，眼底的冷峻在这一瞬间彻底化作了无尽的宠溺与钦佩。他伸手搂住常灵珂的肩膀，用力点了点头：“好！留下来！这五公斤，是人类文明的傲骨，也是大宇宙最崇高的图腾！就算大宇宙最终差了这五公斤而无法坍缩，那也是这个冷酷的物质世界配不上如此美丽的生命！”

<!-- b97 text -->
关一帆呆立良久，突然爆发出了一阵畅快淋漓的大笑：“哈哈哈哈！老白！灵珂！程心！你们真是疯了！可老子就喜欢你们这股疯劲！留下来！把这只金鱼留在这里！让它在时间的尽头，替咱们游到宇宙的明天！！”

<!-- b98 text -->
四人缓缓蹲下身，围拢在那只被安放在冰冷合金地板正中央的五公斤微型生态球旁。

<!-- b99 text -->
穿梭机刺目雪白的探照灯光芒从上方笼罩下来，照亮了玻璃球内那片不可思议的微观奇境。

<!-- b100 text -->
球体内部的水质纯净透明，没有丝毫杂质。那一株小小的细叶水草扎根在三颗圆润的鹅卵石之间，叶片在水中轻柔地摆动，像是一柄柄微型的绿色翡翠羽扇。在水草的缝隙间，那尾璀璨的金红小鱼欢快地游弋着，嘴里吐出一串细小如珍珠般的气泡，气泡缓缓升腾，在水面上啪的一声轻脆破裂。

<!-- b101 text -->
它根本不知道这间居住了三十年的宏大宇宙刚刚被全部拆毁；它不知道自己脚下这块长宽一公里的金属球壳即将在几个小时后彻底坍缩湮灭；它更不知道整座外部大宇宙正面临着生死存亡的热寂危机。

<!-- b102 text -->
它只是活着，只是在水里优雅而自由地游动着，吐着气泡，摆动着美丽的鱼鳍。

<!-- b103 text -->
“看它游得多欢快啊……”常灵珂伸出一根手指，轻轻贴在微凉的玻璃外壁上。那尾小金鱼似乎感受到了指尖传来的微温，竟然灵动地游了过来，隔着薄薄的玻璃，用圆溜溜的金色眼睛好奇地打量着这位照顾了它三十年的女主人。

<!-- b104 text -->
程心眼含热泪，双手合十，神情庄重得如同一位守护圣婴的修女：“在过去的几个世纪里，人类制造了引力波广播天线，制造了反物质曲率飞船，制造了能在太空里摧毁星系的超级武器。我们自以为掌握了宇宙的一切秘密。可是直到此刻，看着这只小金鱼，我才真正明白——大自然制造的这一尾小小的生命，远比我们制造的所有钢铁战舰都要伟大一万倍。”

<!-- b105 text -->
关一帆长长地吐出了一口白汽，蹲在球体旁，眼眶泛红地笑了：“是啊……五亿吨物质全还回去了，唯独留下了这五公斤。如果归零者看到这只球，他们会惩罚我们吗？”

<!-- b106 text -->
“归零者如果真的拥有超越维度的神性，他们会向这只球致敬的。”白道微的声音沉着笃定，带着无可置疑的哲理威严，“因为宇宙存在的全部意义，不在于拥有多少亿亿吨冰冷的质量，而在于这些质量中，能够诞生出有知觉、有温存、能够凝望星空的双眼。”

<!-- b107 text -->
关一帆蹲下身，伸出粗糙的手指，轻轻碰了碰生态球底座上那块微型核同位素温差发电机。电池的外壳散发着极其温和的微热，给冰凉的玻璃底部带来了一抹永恒的暖意。

<!-- b108 text -->
“钚二三八放射性同位素电池，半衰期八十七点七年，配合小宇宙内部的超导能量闭环倍增器，理论上能稳定发光两万至五万年。”关一帆眯着眼睛，喃喃自语，“两万年……对于大宇宙的百亿年沧桑来说，不过是白驹过隙的一瞬。但这尾小鱼在玻璃球里游动的两万年，却是整个大宇宙漫漫长夜里，唯一一簇没有熄灭的生命篝火。”

<!-- b109 text -->
程心弯下腰，双手捧着生态球，郑重其事地将它安放在了小宇宙绝对几何中心的激光测距十字线上。那是整座一平方公里人工底板上，重力场与引力曲率最平稳、最受保护的核心锚点。

<!-- b110 text -->

<!-- b111 text -->

<!-- b114 text -->
