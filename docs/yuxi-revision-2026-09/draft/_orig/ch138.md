# 第138章 · 蓝星世界巡礼与关一帆的降临
<!-- meta {"wordCount": 10045} -->

<!-- b0 text -->
蓝星，紫海平原。这片距离母星太阳两百八十六光年之外的未知大地，在此刻迎来了两个半世纪以来最震撼人心的一幕。

<!-- b1 text -->
湿润而带着微甜气息的异星微风吹拂着平原上无边无际的紫色草浪。在那座流线型水银色星环号飞船刚刚降落的玄武岩平坦台地边缘，一个身穿灰白色深空连体宇航服的年轻男子正如疾风般狂奔而来。他的面庞被强烈的异星紫外线晒成了健康的小麦色，双眼中闪烁着狂喜、震撼与不可置信的滚烫泪光。而在飞船的升降舷梯下，刚刚摘下头盔的程心、艾AA、白道微与常灵珂四人同样怔怔地看着他，心跳在胸膛中如战鼓般疯狂轰鸣！

<!-- b2 text -->
“程心！真的是你们？！天啊……真的是你们！！”男子的喊声在空旷寂静的平原上回荡，粗重而颤抖。他冲到程心面前两步远的地方猛然刹住脚步，胸膛剧烈起伏，几乎不敢伸出双手去触碰眼前这个跨越了数百年时光的故土同胞。而在他的胸前，那个由双螺旋与四维超立方体交织构成的金属胸章在恒星的照耀下熠熠生辉——那是属于当年深空科考战舰【万有引力号】的专属纹章！眼前这个青年，正是当年随万有引力号一同流亡深空的首席天文学家——关一帆！

<!-- b3 text -->
“关博士……关一帆！”程心再也无法抑制胸中汹涌的千重狂澜，泪水夺眶而出，上前一步死死抓住了关一帆结实的肩膀。艾AA同样激动得双眼通红，扑上去用力抱住了关一帆的另一只手臂。白道微与常灵珂快步走上前，四只来自太阳系的手掌与关一帆的手掌紧紧交叠在一起。掌心传来的滚烫温度与有力的脉搏，在这一刻化作了人类文明跨越两百八十六光年绝境生还的最伟大铁证！

<!-- b4 text -->
“我们不是在做梦……我们真的活下来了！”艾AA一边抹着眼泪，一边又哭又笑地捶打着关一帆的胸膛，“关一帆！你知不知道我们在太阳系经历了什么？！二向箔把整座太阳系都压平了！木星、土星、地球、甚至连太阳都被压成了一张没有厚度的画！罗辑博士留在了冥王星……整个太阳系三十亿人都死了！我们以为整个大宇宙里就只剩下我们四个人了！！”

<!-- b5 text -->
听到“二向箔”与“太阳系二维化”这几个字眼的瞬间，关一帆那张原本洋溢着重逢狂喜的脸庞瞬间僵硬了，浑身的肌肉不可遏制地剧烈战栗起来。虽然作为深空理论物理学家，他早在数十年前就已经在理论模型中推演过神级文明清理太阳系的各种可能手段，但当这句残酷到极致的终极宣判真真切切从眼前同胞口中说出时，那种整个母星文明彻底断绝的冰冷刺骨之感，依然如同一柄万丈重锤，狠狠砸碎了他的灵魂。

<!-- b6 text -->
“太阳系……终究还是没能逃过这一劫吗……”关一帆缓缓闭上了双眼，两行滚烫的眼泪顺着坚毅的脸颊滑落。他松开双手，转过身，面朝着遥远天鹅座深空中太阳系所在的那片早已不可见的虚空方向，缓缓挺直了身躯。在呼啸的异星风中，这位银河人类的科学家庄严地脱下右手手套，按在自己的心口，向着远方死去的母恒星系、向着那位独自坐在卡戎断崖前为文明雕刻墓碑的罗辑老人、向着三十亿沉睡在画卷深处的父老乡亲，深深低下了头颅，默哀良久。

<!-- b7 text -->
白道微、常灵珂、程心与艾AA同样静静伫立在风中，任凭异星的微风拂乱他们的发丝。在这颗美丽的蓝色星球上，过去的悲伤化作了一道深沉而神圣的丰碑，深深刻进了每一个幸存者的灵魂深处。过了许久，关一帆才缓缓抬起头，抹去脸上的泪痕，声音中带着深深的沉痛与由衷的庆幸：“当年在万有引力号上，我们曾无数次推演过母星的未来。我们知道黑暗森林打击迟早会降临，但我们没想到，神级文明使用的竟然不是光粒，而是二向箔……三十亿人啊，整整一个星系……但好在，你们把星环号开出来了，托马斯·维德当年的遗愿实现了！”

<!-- b8 text -->
良久，关一帆长长呼出了一口胸腔中的浊气，擦干了眼角的泪水。他转过头，看着白道微与常灵珂，眼神中带着由衷的钦佩与欣慰：“这位就是白道微长官和常灵珂医生吧？在万有引力号离开太阳系前夕的档案库里，记录着你们在水星深核基地坚守半个世纪、记录了你们在掩体纪元大撤退中的所有航迹。你们两位是真正的人类脊梁。能够驾驶一艘拥有曲率光速引擎的飞船穿透两百八十六光年的死寂星海来到这里，维德和罗辑当年的苦心没有白费。”

<!-- b9 text -->
“关博士，不必客气。在浩瀚的黑暗森林中，我们都是侥幸活下来的流浪者。”白道微沉稳地伸出手与关一帆紧紧相握，“能在这里见到你，见到万有引力号的同胞，是我们此行最大的奇迹。”

<!-- b10 text -->
“走吧，先去我的野外驻扎营地歇歇脚。”关一帆指了指平原深处那几座半圆形的白色充气生态穹顶，“那是我三个月前乘坐穿梭机降落蓝星时建立的临时前哨站。这一路上，我带你们好好看看这颗美丽的星球！”

<!-- b11 text -->
五人并肩漫步在无边无际的紫海平原上。双脚踏在松软而富有弹性的紫色泥土上，那种脱离了钢铁甲板与合成地面的真实触感，让程心感到一种前所未有的心旷神怡。地面上生长的紫色草类大约有半米高，叶片扁平肥厚，表面覆盖着一层极其细腻的天然蜡质保护膜，摸上去宛如顶级的天鹅绒缎带。当鞋底踩过草丛时，被碾碎的叶茎内部渗出了一种散发着淡淡清凉薄荷香气的汁液，这种香气弥漫在空气中，令人精神为之一振。

<!-- b12 text -->
常灵珂弯下腰，用随身携带的便携式生物探针刺入一株紫色植被的根茎。仪器屏幕上闪烁着密集的生化分子图谱：“太神奇了！这里的植物完全没有地球绿色植物那样的坚硬木质纤维素，它们的维管束结构由高分子多糖与天然蛋白质复合物构成，极易降解，而且富含水溶性葡萄糖与多种氨基酸！艾AA刚才在轨道上的光谱分析没错，它们依赖类视黄醛与花青素进行光合作用，这意味着蓝星的整个生物圈在生化底层逻辑上与我们地球生命极其接近，但又独立演化出了一套更加纯粹高效的代谢链条！”

<!-- b13 text -->
平原上的地质构造同样令人称奇。脚下的土壤呈现出一种健康的暗红褐色，富含铁铝硅酸盐与大量微孔团粒结构。白道微抓起一把泥土，轻轻捻碎，嗅了嗅泥土的气息：“没有重金属毒素，氮磷钾养分充足，微孔结构具备极佳的保水透气性。如果在这些平原上播撒我们带来的小麦、大豆和水稻种子，甚至不需要施用过多的化肥，作物就能以惊人的速度茁壮成长。这里就是一块天然的万顷良田。”

<!-- b14 text -->
不仅如此，平原的地表温和湿润，缺乏地球上由于青藏高原或安第斯山脉剧烈隆起引发的极端对流风暴。这里的气候类似于地球地中海气候与温带海洋性气候的结合体，终年温和宜人。平原微风轻拂，蓝星的大气压力仅比地球海平面低百分之二，这意味着人类无需任何加压服即可长期户外活动。

<!-- b15 text -->
“不仅如此，你们看那条河！”艾AA像个欢快的孩子一样奔向了平原低洼处的一条大河。那是一条宽达数百米的清澈大河，河水在微风的吹拂下泛起粼粼的碎金波光。艾AA蹲在河滩边，伸手捧起一汪清澈见底的河水，将探针伸入水中。仪器屏幕上立刻跳出了一串纯净的绿色数值：“弱碱性！pH值7.35！重金属含量为零！微生物群落全部属于低毒性的自养型固氮菌！程心，道微，这水可以直接喝！”

<!-- b16 text -->
说着，艾AA毫不犹豫地将手中的河水送入口中，随后满足地发出了一声惊叹：“甘甜！比母星经过二十道超滤反渗透处理的循环水好喝一万倍！真真切切的天然矿泉水！”

<!-- b17 text -->
在河岸边的浅水区，几只透明的微型水生生物正悠闲地在水草间游弋。它们体长只有两三厘米，身体通透如水晶，透过光线甚至能看清内部微弱搏动的两腔心脏。这些小生物没有眼睛，依靠触角感应水流中的养分微粒，对人类的造访没有表现出丝毫的恐惧与逃避。常灵珂蹲下身来观察它们，发现它们的遗传密码同样由四种碱基构成，展现了碳基生命在不同星系演化中的某种惊人同构性。

<!-- b18 text -->
顺着河流向下游望去，视线的尽头是一片波澜壮阔的紫色大洋——“紫海”。大洋的水体中富含发光微藻，在阳光下呈现出深邃而神秘的蓝紫色。海浪拍击着岸边的玄武岩平原，激荡起一层层晶莹剔透的雪白泡沫，空气中弥漫着淡淡的海风咸味与植物的甘甜。没有任何工业污浊，没有任何战争硝烟，这是一座在宇宙深处静默自足了亿万年的自然天堂。

<!-- b19 text -->
当抬头望向天空时，高纬度平流层中正悄然泛起层层绚烂的淡绿色与淡紫色极光帷幔。蓝星强大的偶极磁场将来自F型主序星的高能带电粒子流优雅地引向两极，在电离层中激荡出一道道无声的华美极光。没有辐射威胁，只有纯粹的天文奇观。整个生态系统展现出一种令人惊叹的自洽与平衡。

<!-- b20 text -->
关一帆微笑着看着欢呼雀跃的艾AA，眼眸中闪烁着温和的光芒：“三个月前我刚降落的时候，也像你一样震惊。在这座距离太阳系近三百光年的陌生星系里，竟然存在着一颗在温度、气压、重力和水文条件上与母星地球如此高度相似的奇迹星球！蓝星的陆地上目前没有演化出大型掠食性动物，只有一些类似昆虫与小型软体生物的节肢类自养体。海洋里也大多是原始的浮游藻类和无脊椎软体鱼。这是一个极其年轻、极其干净的世界，没有任何攻击性物种，没有任何致命的寄生虫病毒。对于人类而言，这简直就是宇宙神明在大灾难前夕亲手为我们准备的伊甸园！”

<!-- b21 text -->
“这不是宇宙神明的准备……”程心凝视着倒映在清澈河水中的钴蓝色天空，声音轻柔得如同一缕叹息，“这是云天明的准备。”

<!-- b22 text -->
穿过半公里的紫色草浪，五人来到了关一帆的野外考察营地。那是三座由高强度防辐射凯夫拉织物充气构筑而成的半球形连体穹顶，静静矗立在一处背风的坚硬花岗岩台地之上。营地外侧竖立着一台小型静音反物质发电机，以及一套六联装的高敏度微波与引力波深空监测天线阵列，天线正以极慢的角速度缓缓追踪着深空轨道上的天体运动。而在营地不远处，稳稳停泊着那架长达三十米的灰白色深空穿梭机——“捕食者号”。机体表面布满了细微的微流星撞击麻点与星际微尘冲刷留下的暗淡灼痕，展现出这艘战鹰在深空中经历过的漫长岁月。

<!-- b23 text -->
“请进吧，欢迎来到我的简陋小窝。”关一帆微笑着掀开双层隔热气闸软帘，邀请众人步入中央穹顶。营地内部的陈设整洁而紧凑：中央是一张宽大的金属工作台，上面堆满了各式各样的蓝星岩石矿物切片、植物生化标本管与全息深空星图投影仪；角落里整齐码放着十几箱高能压缩军用口粮，以及两张简易的折叠行军床。在穹顶中央的人造暖光照耀下，这间孤立在异星荒原上的帐篷散发着一种属于人类探索者的浓郁烟火气息。

<!-- b24 text -->
常灵珂与艾AA好奇地打量着工作台上的星图仪器，而白道微则快步走到深空天线阵列的数据终端前，凝视着屏幕上那些跳动的引力波信标频率。白道微转过身，神色无比郑重地看着关一帆：“关博士，当年万有引力号与蓝色空间号脱离太阳系之后，究竟发生了什么？你们现在的人口规模有多大？其他同胞现在都在哪里？”

<!-- b25 text -->
听到白道微的询问，程心与艾AA也立刻围拢了过来。这是所有幸存者心头最迫切想要解开的终极谜团。在太阳系全军覆没的今天，流亡深空的“银河人类”是全人类仅存的另一支血脉。

<!-- b26 text -->
关一帆拉开一张折叠椅坐下，顺手给四人各倒了一杯用蓝星天然雪山融水冲泡的速溶茶，神色凝重地开始讲述那段尘封了半个多世纪的壮烈史诗：

<!-- b27 text -->
“五十四年前，威慑纪元崩溃，智子切断了太阳系的三大引力波发射台。当时我们万有引力号正与蓝色空间号航行在柯伊伯带外围的深空之中。三体人的两颗强相互作用力水滴同时向我们发起了致命伏击！在千钧一发之际，蓝色空间号利用在深空中偶然发现的四维空间碎块，完成了不可思议的高维跃迁，从四维空间内部反向摧毁了水滴的核心微观力场发生器，并迫使我们万有引力号上的官兵与他们联合在一起！”

<!-- b28 text -->
“随后，两舰经过全体舰员的全民公投，毅然按下了天线开关，向全宇宙广播了三体母星系的坐标，敲响了三体文明的丧钟！广播发出后，两舰深知太阳系已经无法回头，留在原处只有死路一条。褚岩舰长与我们全舰科学官商议后，决定彻底脱离人类社会，将两舰合编为‘银河探索联合舰队’，向着银河系的未知旋臂深处全速起航！”

<!-- b29 text -->
“在最初的三十年里，我们在两艘恒星级战舰的内部建立了完整的微型生态闭环社会。经历过严苛的配给制、心理危机与民主制度的重新确立，两百多名年轻健康的男女舰员彼此通婚，诞生了第二代与第三代深空新人类。”关一帆的眼神中浮现出一抹由衷的自豪与感慨，“三十年前，联合舰队在距离太阳系一百二十光年的仙后座边缘，幸运地找到了一处包含四颗宜居行星的富饶恒星系！我们在那里建立了四个独立的殖民定居点，分别命名为【新地球】、【春秋】、【希望】与【方舟】！”

<!-- b30 text -->
“在最初降落新世界的几年里，许多第一代老舰员患上了严重的‘蓝天综合征’。”关一帆轻叹一口气，“常年在狭小幽闭的飞船金属回廊里生活了几十年的人，突然面对无边无际的空旷蓝天，会产生一种仿佛要坠入虚空的剧烈恐惧。但人类这个物种的适应力是惊人的。孩子们在大地上奔跑，抚摸着泥土，那种深埋在基因里的农耕记忆在短短几年内便彻底苏醒。”

<!-- b31 text -->
“在宪法体系上，银河人类彻底废弃了公元时代的民族国家与地缘博弈体制，实行基于直接民主与科学共识的‘舰队大议会制’。”关一帆介绍道，“同时，为了防止人工智能失控或基因改造带来的阶层固化，宪法第一条便严禁创造具备自我意识的强人工智能，严禁进行人类生殖细胞的排他性基因定向改造。每年七月，四个新世界都会联合举行‘母星回响纪念日’，学校里的孩子们依然在背诵李白杜甫的诗篇，依然在学习牛顿麦克斯韦的物理学。”

<!-- b32 text -->
