# 第98章 · 只送大脑 · 光帆飞船发射与偏航之痛

<!-- b0 text -->
危机纪元三年立冬，日内瓦北郊地下四百米处的一处特级生化防御掩体内，进行着人类医学史上最精密、也最毛骨悚然的一台外科手术——“阶梯计划零号载荷活体中枢神经组织剥离与玻璃化冷冻手术”。

<!-- b1 text -->
手术室内被无影冷光灯照得通体惨白，空气中弥漫着高浓度七氟烷麻醉气体与极度冰冷的氟碳灌注液气味。整台手术由来自全球六个顶尖神经外科中心的十八位权威专家联合执刀。在中央那张被磁流体恒温垫托举的钛合金手术台周围，摆放着三十余台嗡嗡作响的特种生命维持机组与体外膜肺氧合系统。

<!-- b2 text -->
当时以公元纪元神经病理学与公卫特聘专家身份进驻联合国的常灵珂，身着无菌隔离防护服，站在二层石英玻璃观察廊上，亲眼见证了这场将一个活生生的人类青年彻底解构为十八点五公斤物理构件的悲壮过程。在常灵珂的行医生涯中，在大明朝堂的瘟疫与刀兵里，她见过无数死伤狼藉的惨状，但从未有哪一场死亡，能像眼前这般残酷、精密而冷静。

<!-- b3 text -->
在推入手术室前的最后三分钟里，云天明曾费力地转过头，透过氧气面罩看着站在推车旁的程心。他的呼吸已经极度微弱，但那双深陷的眼窝里，却浮现出一抹让人心碎的温柔笑意。他用尽最后一丝力气，轻轻抬起右手食指碰了碰程心的衣角，含糊不清地低语道：“程心……别哭。这很好，比在烂泥里发烂发臭好得多。我替你……去看看星星。”那句话如同一记无形的烙铁，将永恒的悔恨与负罪感死死烫在了年轻女孩的心脏瓣膜之上。

<!-- b4 text -->
云天明平躺在手术台上，全身的血液已经在深度低温诱导下被置换为一种半透明的微胶囊化全氟萘烷冷冻保护剂。他的呼吸与自主心跳早已停止，脑电图上只剩下微弱的阿尔法波在超低温的抑制下缓慢起伏。两根微型塑料插管精准插入双侧颈内动脉与椎动脉，高压微蠕动泵以每分钟四十毫升的恒速，将带有甘油与二甲基亚砜的抗冻灌注液推入颅内微循环血管网，彻底冲刷出脑实质内的全部微细血栓。

<!-- b5 text -->
高频超声骨刀在电机的轰鸣声中轻柔地切开枕骨与顶骨，头皮与颅骨瓣被整齐地剥离掀开，露出了那颗重约一千四百克、散发着微弱生物电辉光的人类大脑。主刀医生额头上渗出细密的汗珠，巡回护士用无菌吸水海绵飞速擦拭着手术视野。常灵珂在观察廊上紧紧抿着嘴唇，她深知，任何一根毛细血管的破裂，都会在未来的复苏程序中导致大面积脑梗死与不可逆的记忆崩解。

<!-- b6 text -->
外科主刀医生的手极其沉稳，但在剪断视神经、听神经与延髓交界处的最后一截迷走神经束时，老专家的眼眶依然忍不住泛起了一层薄雾。随着剪刀发出“咔嚓”一声极其微弱的脆响，云天明与他赖以生存了二十八年的肉身皮囊，彻底断绝了最后一点生理连接。他所有的痛苦、所有的自卑、所有的孤独与那份深藏于心底的滔天深情，全部被浓缩进了这团由一千亿个神经元与百万亿个突触交织而成的纯白组织之中。

<!-- b7 text -->
大脑被迅速转移进一只由超纯钛合金与碳纤维编织而成的双层真空冷冻舱内。液氦在纳秒级注入减压夹层，温度在十秒内从摄氏四度骤降至绝对零度之上的七十七开尔文，脑组织内的全部水分子在极速冷冻中形成了均质的非晶态玻璃体，避免了任何微观冰晶对神经细胞膜的机械刺破。整个载荷舱经过最后的电子自检与密封焊死，称重传感器上跳出了那个被全人类计算了无数次的终极数字：【有效载荷总质量：18.46公斤】。

<!-- b8 text -->
隔着厚重的石英玻璃，程心双手死死扒在扶手上，整个人已经哭得几乎瘫软脱水。她看着那具被白布缓缓覆盖推入冷藏库的无头躯体，又看着那个被吊车缓缓装入深海运载箱的银白色小球，喉咙里发出宛如被生生撕裂般的窒息悲鸣。她亲手为那个深爱自己的男孩戴上了通往星辰的荆棘王冠，而那个王冠，是用一把沾满血腥的骨锯铸成的。

<!-- b9 text -->
手术室内的法律见证程序堪称人类历史上最严苛、也最压抑的一场官僚仪式。联合国人权理事会轮值特使、行星防御理事会司法副长官以及来自红十字国际委员会的独立医学观察员，排成整齐的一列坐在防弹玻璃后方。当执行医师在活体中枢神经组织摘除授权书上按下红色指纹印泥时，整间屋子里只能听见盖章声在水泥墙壁间撞出的沉闷回响。每一个在场的人都明白，他们正在亲手撕下人类文明最后一块法律遮羞布，将同类的头颅送上神明的祭坛。

<!-- b10 text -->
在载荷舱彻底封装焊死前的最后三分钟里，程心曾颤抖着从怀中掏出了一只小巧的铅封金属微囊。那是她在北京街头一家濒临倒闭的花木店里买下的一枚普通的中国冬小麦麦粒，以及几粒干燥的大豆种子。她将这只微囊亲手用耐极温环氧树脂贴在冷冻舱外壁的一个次级固定槽内。年轻的姑娘眼含热泪地轻声低语：“天明，带上它们吧。如果……如果你真的能见到外星人，告诉他们，这是生养你的泥土里长出的麦子。你是人类的孩子。”

<!-- b11 text -->
常灵珂在医学日志中记录下了那只微型冷冻舱内部极其精密的微观流体悬浮构造。为了抵御核脉冲在零点几秒内释放的数百个G的恐怖过载，整颗大脑被悬浮在一个由八层高分子阻尼凝胶构成的仿生微重力球形内胆中。内胆内部充盈着与脑脊液等渗、但黏度高达普通水三倍的特种全氟萘烷聚合物，使得整颗脑组织在受到狂暴剪切力冲击时，能够像浸泡在羊水中的胎儿一样均匀分摊应力，最大限度地规避脑干扭转与神经轴索断裂。

<!-- b12 text -->
手术室内的伦理争议在主刀医生切下第一刀的前夕达到了顶峰。一位来自国际红十字会的资深伦理学观察员，在看到云天明已经陷入深度浅昏迷的面容时，突然按响了紧急录音器的暂停键，声音颤抖着质问：“维德局长，按照《纽伦堡法典》与《赫尔辛基宣言》，任何具有毁灭性结局的活体人体实验都是非法的！你们正在把一个活人的生命中枢切下来装进铁皮盒子里，这与中世纪的斩首示众有什么区别？！”维德冷漠地从公文包里抽出一份由联合国安理会五大常任理事国元首亲笔联合签署的特急行政命令，甩在那位专员的胸口：“区别在于，中世纪的刽子手是在惩治罪犯，而我们是在给四十亿即将被送进毒气室的囚徒，寻找哪怕百分之一的翻盘机会。闭上你的嘴，否则下一秒你就会以战时叛国罪被宪兵拖出这间屋子！”

<!-- b13 text -->
在微创开颅的过程中，主刀专家动用了当时最前沿的激光光子止血镊与显微双极电凝仪。当头皮瓣与颅骨在机械固定支架的支撑下彻底暴露时，云天明的大脑皮层在特氟龙冲洗液的浸润下微微搏动着。灰白色的脑回在冷光灯下泛着珍珠般的温润光泽，额叶、顶叶、颞叶与枕叶的沟回结构清晰得如同一幅微缩的大陆地理版图。在这块仅重三磅的有机组织深处，密布着上百亿个精密神经回路，每一个回路里，都深藏着一段关于湖畔、红围巾、草稿纸与孤独星空的永恒记忆。

<!-- b14 text -->
在最后的密封焊接工序中，一台高精度激光电子束自动焊机，沿着钛合金半球形舱体的赤道缝隙高速扫过。一道耀眼的苍蓝色等离子弧光照亮了整间无菌操作室，伴随着刺鼻的微弱金属电离气味，双层真空舱体在纳秒级实现了分子级的致密熔接。称重传感器与氦质谱检漏仪同时亮起绿灯：气密性泄漏率低于每年十的负十五次方帕立方米，内部超低温液氦蒸发余量足以维持长达两百年的自主悬浮平衡。

<!-- b15 text -->
常灵珂在二层观察廊上，看着那个被吊车缓缓装入深海防震运输箱的银白色小球，心底泛起一阵前所未有的荒诞与震撼。一个人的一生、二十八年的喜怒哀乐、所有的爱恋与遗憾、甚至那份足以照亮二百八十六光年外恒星的滚烫深情，最终竟然被人类最顶尖的科技，压缩成了一个比保龄球还要小上一圈的冰冷金属疙瘩。在这个冷酷的宇宙面前，人类肉体与灵魂的渺小，被这台精密的电子束焊机嘲讽得体无完肤。

<!-- b16 text -->
一个月后，肯尼迪航天中心与酒泉卫星发射基地的三枚重型聚变火箭，将阶梯计划的核心飞船、微型载荷舱以及那面承载着全人类最后希望的超大型星际光帆，送入了距离地面一千公里的太阳同步近地轨道。

<!-- b17 text -->
在近地轨道的国际空间站大型装配平台上，数百名身穿厚重舱外宇航服的航天工人在失重环境中紧张作业。飞船的核心舱只有一只普通行李箱大小，通体涂覆着高能抗辐射陶瓷涂层，里面静静地封存着那颗浸泡在固化氟碳冰块里的大脑。而在核心舱外围，十二个特种钛合金液压卡扣，正死死咬合着十二根由汪淼团队亲自监督拉丝的‘飞刃’纳米碳缆。

<!-- b18 text -->
随着中央展开电机的指令被激发，被紧密折叠在一个直径仅有四米圆柱体内的纳米碳膜风帆，开始沿着八条柔性充气支架向外缓缓绽放开来。在近地轨道的强日光直射下，长宽各五公里、总面积达二十五平方公里的纯银色巨大薄膜，如同神祇在深空中缓缓抖落的一匹万丈素绢，在漆黑无垠的宇宙背景上无声平铺舒展！

<!-- b19 text -->
那是一场足以令整座地球为之屏息的视觉奇迹。这面薄膜的厚度仅有数十纳米，轻薄得几乎感觉不到自重，但反射率却高达百分之九十九点九九。当它完全展开时，在地面夜半球的数千万城市中，数十亿民众抬头望向天顶，看见夜空中升起了一颗比满月还要璀璨夺目的银色巨星。柔和圣洁的银色冷辉穿透了工业烟霾，将清辉洒在每一座防空洞、每一片农田与每一张仰望的面庞上。人类在绝望的寒夜里，为自己升起了一面飞向死神的巨帆。

<!-- b20 text -->
而在光帆的前方，从近地轨道一直延伸至火星与木星轨道外侧的双曲线深空回廊中，一千零四枚战备核脉冲推进站早已布设完毕。每一座推进站都是一枚重达数十吨的特种深空核武方尖碑，其内部装载着一枚百万吨级高聚变比当量的氢弹，以及一套由激光雷达与原子钟构成的毫微秒级起爆触发总控阵列。

<!-- b21 text -->
日内瓦战略情报局总指挥中心的大厅内，托马斯·维德嘴里嚼着半截没有点燃的雪茄，双手撑在巨大的全息星图控制台前。他的脸色苍白如铁，深陷的眼眸中没有半点艺术家的浪漫，只有一尊冷酷暴君在检阅自己死囚军团时的绝对冷漠。

<!-- b22 text -->
“检查所有核脉冲引信状态。”维德的声音低沉而刺耳，在死寂的指挥大厅中激起阵阵回音。

<!-- b23 text -->
“一号至一千零四号核弹阵列同步完成！脉冲测距雷达锁定完毕！光帆姿态配平完成度：100%！”总工程师米哈伊尔的声音在颤抖，手心满是冷汗，“局长……这是人类有史以来在太空中引爆的最大规模核武库。只要有任何一枚核弹发生千分之一秒的延时，光帆就会被当场扯得粉碎！”

<!-- b24 text -->
“那就让它粉碎。”维德甚至连头都没有抬一下，右手狠狠拍下了那枚通体鲜红的总发射启动闸刀，“前进！前进！不择手段地前进！发射！”

<!-- b25 text -->
在近地轨道装配平台上，由美洲、亚洲与欧洲三大航天司令部联合组成的施工舰队，经历了长达二百四十天的艰苦轨道作业。每一座核脉冲推进站的布设都是一场在死神指尖上的舞蹈。重达数十吨的方尖碑状核武平台上，集成了最先进的高能定向爆轰反射锥镜与液氦冷却激光测距环。航天员们在强烈的范艾伦辐射带内轮流作业，数名高级工程师在受到过量宇宙射线照射后出现了严重的骨髓抑制，但没有一个人申请退出现场。在全人类存亡的生死时刻，整座文明的工业血肉在这一刻被死死铆接在了一起。

<!-- b26 text -->
在发射倒计时的最后一夜，整座地球的数十亿民众度过了一个彻夜未眠的不眠之夜。在纽约时代广场、在莫斯科红场、在北京天安门广场以及内罗毕的贫民窟里，无数巨型全息转播屏将近地轨道的实时高清画面投射在夜空之中。当那面二十五平方公里的纯银色光帆在晨曦的第一缕日光中舒展开来时，全球数十亿人同时双膝跪地，无论他们信奉哪一种宗教，无论他们口中念诵的是哪一种经文，所有人都在向着天空中的这面巨帆祈祷。在人类文明长达数十万年的漫长演化史中，这是四十亿孤独的灵魂第一次如此整齐划一地凝视着同一片星海。

<!-- b27 text -->
那十二根由汪淼团队制造的‘飞刃’纳米系绳，堪称人类凝聚态物理学皇冠上的明珠。每一根系绳的直径不到十微米，但其轴向抗拉强度却高达惊人的一百吉帕斯卡！即便挂上一列满载矿石的万吨重型重载列车，这些比蚕丝还要轻盈的黑色细线也绝不会产生一丝塑性断裂。然而，这种极端材料也有着其致命的阿喀琉斯之踵——在高温等离子体与强电离射线的轰击下，碳原子的六角晶格结构极易在局域电荷堆积下发生晶格滑移与脆化断裂。

<!-- b28 text -->
飞船核心舱的微型电力系统更是一项在质量红线边缘压榨出的工程奇迹。为了在十八点五公斤的总预算中留出足够的结构重量，工程师们舍弃了所有传统的化学蓄电池与太阳能帆板，仅仅依靠半克高丰度的钚-238同位素衰变热电偶（RTG）来提供微弱的电力。这半克放射性金属产生的热量微弱得如同一只在暴风雪中喘息的火柴，仅仅能够维持中央石英陀螺仪、一个微型频移应答机以及一套用于监控冷冻液晶态结构的微电极阵列的最低功耗运转。

<!-- b29 text -->
第一道核爆烈焰在太空中轰然绽放！在距离飞船后方五百公里的虚空中，一枚百万吨级氢弹在千分之一秒内化为了一团直径达数十公里的炽热等离子火球！狂暴的伽马射线与高速中子流如同一记来自雷神手中的无形重锤，狠狠砸在了二十五平方公里的银色光帆之上！

<!-- b30 text -->
光帆背面的纳米微孔碳气凝胶在千万度的高温中瞬间汽化，喷射出一股惊天动地的反冲激波！整面巨大的银帆在太空中猛烈地凹陷鼓起，十二根纳米系绳在极限张力下被拉扯出尖锐的微观量子啸叫，推举着中央的载荷舱以不可思议的加速度向外太空狂暴弹射！速度表上的数字疯狂跳动：每秒三十公里、五十公里、一百公里！

在地球的地表深空测控网络中，位于美国加州戈德斯通、西班牙马德里与中国北京密云的三座七十米口径巨型深空抛物面天线，同时捕获到了那组象征着灾难的遥测信号突变。多普勒频移数据显示，飞船的径向速度矢量在第八号缆绳断裂的瞬间，产生了一个每秒三点四米的微小侧向跳变。对于近地航天器而言，三点四米的微扰不过是一次轻微的姿态配平；但在漫长达四光年的星际尺度上，这微不足道的三点四米横切速度，在时间积分的作用下，将把飞船无情地甩开数万个天文单位的深渊鸿沟！

<!-- b45 text -->
指挥中心大厅的长桌上，原本温热的浓缩咖啡早已结上了一层油腻的冰凉硬皮。数十位来自各国的轨道测控专家像木雕泥塑一样瘫坐在各自的屏幕前，没有人说话，甚至没有人敢去碰桌子上的通信麦克风。全息投影中，那面纯银色的光帆在失去了控制后，宛如一片被秋风吹落的枯黄树叶，在深邃冰冷的太阳系背景中打着旋，越飘越远，其反射的光芒逐渐暗淡，最终从每秒数万次的雷达回波中，退化为了一个不可辨识的微弱宇宙杂波。

<!-- b46 text -->
在地球这一端的北京密云深空测控中心，白发苍苍的老地面总工程师摘下了厚厚的近视眼镜，双手掩面无声地抽泣起来。几十位年轻的地面测控员呆呆地望着窗外华北平原阴沉的夜空。那个在病房里为了心爱女孩买下一颗恒星的北京少年，此刻正独自躺在那只冰冷的铁箱子里，以每秒数百公里的速度，朝着永恒的漆黑深处绝望坠落。在他前方的整片银河系里，再也没有一盏灯火会为他点亮，再也没有一声呼唤能够穿透那无边无际的冰冷死寂。

<!-- b48 text -->

<!-- b53 text -->
