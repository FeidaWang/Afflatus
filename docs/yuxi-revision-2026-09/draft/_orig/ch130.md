# 第130章 · 给岁月以文明 · 飞向海王星的卡片

<!-- b0 text -->
掩体纪元六十七年。人类文明已经在太阳系气态巨行星庞大无匹的阴影庇护之下，度过了长达半个多世纪表面繁花似锦、内部却盲目麻木的黄金岁月。

<!-- b1 text -->
距离托马斯·维德在星环城放下武器被联邦最高法院判处死刑，已经过去了整整三十五年。在那场轰轰烈烈的反曲率光速飞船风暴彻底平息之后，人类主流社会以空前一致的道德狂热与政治正确，将“空间曲率驱动技术”彻底钉死在了反人类罪与反宇宙公序良俗的耻辱柱上。联合国与太阳系舰队联合颁布了最为严酷的《深空航行基本法典》，任何试图在微观真空中制造负能量曲率泡、甚至在理论物理论文中讨论超光速逃逸机制的学者，都会被立刻剥夺一切科研权限并流放到外柯伊伯带的采矿死囚营。

<!-- b2 text -->
在人类的大众舆论与主流哲学家眼中，曲率光速飞船是自私、背叛与阶级特权的终极代名词——因为光速飞船不仅造价高昂到足以破产整个联邦财政，更可能在起飞时留下暴露出母星坐标的低光速死线尾迹；更为可怕的是，光速飞船是不可追溯的逃亡工具，极少数掌握财富与权力的精英可以驾船逃入大宇宙，而将数十亿普通民众遗弃在绝望的太阳系。这种绝对的不平等，是现代掩体社会绝不容许存在的终极恶魔。因此，“消灭曲率驱动，全员驻守掩体”，成为了深植于每一个人脑海深处的神圣信条。

<!-- b3 text -->
取而代之的，是掩体工程那近乎神迹般的工业大爆发。在木星、土星、天王星和海王星这四颗巨大行星的背阳面阴影锥内，人类文明一共筑造起了六十七座宏伟绝伦的超巨型旋转太空城。每一座太空城都是一个直径数公里、长达数十公里的自给自足生态圆筒，内部拥有人造重力、温润的人造阳光、人工河流与广袤繁茂的亚热带森林。

<!-- b4 text -->
木星基地群是整个掩体文明当之无愧的心脏。在木星背阳面那道长达数百万公里的深黑本影暗锥深处，二十多座太空城排布成三条规整交错的璀璨星轨长龙。“太平洋城”、“新巴黎”、“亚洲一号”、“欧罗巴之光”……这些闪烁着万家灯火的人造浮岛在绝对零度的深空中徐徐旋转。在“新巴黎”的香榭丽舍全息林荫大道上，盛大的狂欢派对几乎夜夜笙歌；市民们端着来自人造葡萄园的红酒，在温暖恒温的微风中翩翩起舞，将公元时代与危机纪元所经历的苦难嘲笑为古代人的集体神经质。

<!-- b5 text -->
每当居民们漫步在太空城内壁那绿树成荫的林荫大道上时，只要抬起头，透过穹顶巨大的透明复合晶体视窗，就能仰望到外太空那颗遮天蔽日的宏大气态巨行星——木星那由狂暴红褐色氨云与氢氦风暴交织而成的庞大本体，犹如一面从天而降的永恒神盾，稳稳地横亘在太空城与遥远的太阳之间。在大众传媒日复一日的宣传灌输下，居民们深信这面数万公里厚的行星巨盾能够抵御宇宙间一切灾厄。掩体联邦议会甚至在近期公开讨论削减常规防空预警预算，因为在他们看来，宇宙暗森林中的打击不过是极小概率的天体闪电，永远无法穿透木星坚不可摧的地幔。

<!-- b6 text -->
而在木星那巨大的大红斑风暴外侧，太阳系舰队的三千多艘重型聚变恒星级战舰正在以威严整齐的阵列执行例行战备巡航。长达千米的战舰外壳在巨行星冷冽的散射光芒中泛着坚不可摧的玄武岩亚光涂层，舰艏的超大功率聚变推进器喷吐着长达数公里的苍蓝等离子焰流。在掩体社会的绝大多数公民看来，人类不仅从三体危机的百年阴霾中彻底涅槃重生，更在这片冰冷的宇宙深空建立了永不沉没的钢铁长城。

<!-- b7 text -->
“我们已经驯服了太阳系，我们在巨人的影子下获得了永生。”这是当时流传在六十七座太空城所有学校教科书扉页上的狂妄宣言。绝大多数人类坚定不移地相信：黑暗森林的打击手段无非就是向太阳投掷一枚亚光速动能光粒。而一旦那一刻到来，木星和土星庞大无匹的地幔将彻底吸收恒星爆发的全部冲击波；人类文明将安然无恙地躲在巨行星这面巨大的天然盾牌后面，继续繁衍、歌唱并走向下一个黄金纪元。

<!-- b8 text -->
然而，在这片浸泡在狂热安详与廉价狂欢中的虚妄海洋边缘，依然有极少数人清醒得如同寒冬中未化的坚冰。

<!-- b9 text -->
木星第五拉格朗日点，深空极端天体物理监测站——“天琴基地”。在距离繁忙的太空城集群上百万公里的荒僻深空轨道上，这座孤零零的圆盘形空间站正像一只沉默的苍鹰，将数十面口径达数百米的超导引力波射电反射天线，冷冷地对准了太阳系外围无边无际的深邃虚空。

<!-- b10 text -->
在这座被冰冷液氦管道与轰鸣量子超算环绕的空间站顶层观测舱内，白道微正独自静静地伫立在全景偏光舷窗前。

<!-- b11 text -->
三十五年的光阴在白道微的鬓角染上了一层斑白的霜雪，但他的身姿依然挺拔如松，深邃平静的眼眸深处透着一种洞穿时空宿命的沉静与凛冽。自三十五年前维德在火星轨道被逮捕并慨然赴死后，白道微便拒绝了联合国太空防务委员会的所有高官厚禄，与常灵珂一同隐退到了这处偏远荒凉的深空前哨基地。他们远离了太空城内部那些醉生梦死的政治博弈与霓虹派对，将全部的生命倾注于对太阳系外围深空的死寂守望。

<!-- b12 text -->
“又在看柯伊伯带的外侧吗，道微？”一声轻柔而温润的叹息在白道微身后响起。常灵珂披着一件深灰色的厚重防辐射大衣，端着两杯腾腾冒着热气的合成热茶，轻手轻脚地走到了他的身侧。在过去的半个多世纪里，他们共同经历了三体水滴的灭世杀戮、澳大利亚荒原上人吃人的绝望冬夜、以及星环城地下船坞那场未能燃起的曲率风暴。生与死的反复淬炼，早已让两人之间的灵魂纽带超越了世俗凡人的情感，化为了一种在宇宙极寒深渊中相濡以沫的绝对默契。

<!-- b13 text -->
白道微接过热茶，目光却依然死死钉在舷窗外那颗隐没在无边黑暗中的微弱黄白斑点——那是被木星本体庞大阴影彻底遮蔽的太阳。他的指尖在冰凉的钛合金窗台上轻轻摩挲着那枚始终随身携带的明代古铜钱，声音低沉得宛如叹息：“灵珂，掩体工程是一座建造在薄冰上的象牙塔。这三十多年来，我每天晚上闭上眼睛，脑海里回响的都是三十五年前维德被押上穿梭机时对程心说的那句话——‘程心，你把人类推进了深渊。’”

<!-- b14 text -->
“维德已经走了三十五年了，连星环集团最后的秘密基地也早已被舰队工程兵拆成了一堆废铁。”常灵珂轻声说道，眼神中泛起一丝深沉的哀伤，“整个社会都在庆祝掩体工程的全面竣工，连新一代的孩子们都以为巨行星背阳面就是宇宙中最安全的摇篮。人们用群体的道德绑架了生存的本能，把最宝贵的生路当成了自私的毒药。”

<!-- b15 text -->
“摇篮？那分明是一个自缚手脚的棺木！”白道微转过身，将茶杯重重放在了控制台上，眼眸中闪烁着刺目的锐利锋芒，“三十年前在拉格朗日点，云天明用三个童话故事冒死送给人类三条救赎路径：曲率驱动光速飞船、低光速安全黑域、以及降维打击的防范预警！然而人类社会因为狭隘的道德洁癖与对速度的恐惧，亲手掐灭了维德点燃的曲率火种，彻底放弃了光速逃亡与黑域自保的可能！他们自欺欺人地选择了最懒惰、最愚蠢、也是最无知的掩体工程！这群人以为，宇宙猎手所有的惩罚手段，都仅仅局限于向恒星投掷一枚光粒！他们以为只要躲在巨行星这块天然巨石的死角里，死神的镰刀就永远割不到他们的喉咙！”

<!-- b16 text -->
白道微的话音未落，控制台中央的引力波预警中枢突然发出了一声尖锐短促的电子蜂鸣！那不是常规的通信请求，而是太阳系外围深空雷达网络触发最高级别异常跟踪时独有的刺耳警报！

<!-- b17 text -->
滴——滴——滴——！蜂鸣声在死寂的观测舱内急促回荡，刺眼的猩红全息光幕瞬间在白道微与常灵珂面前自动弹开。光幕顶端闪烁着来自太阳系最外围预警哨站的紧急加密数据源标签：【海王星远日点第二拉格朗日点“寒潭”深空预警基地·科学巡洋舰“启示号”即时遥测链路】。

<!-- b18 text -->
“寒潭基地的超长基线中微子阵列捕获到了实体目标？”常灵珂迅速俯下身，修长的手指在超导光量子键盘上飞速掠过，直接接入了海王星哨站的原始物理传感器阵列，“方位角：黄经214度，黄纬负12度，距离太阳大约三十八个天文单位……目标刚刚切过了柯伊伯带内侧边缘，正在沿着一条极度精确的大双曲线掠海轨道，平稳穿过海王星的公转平面！”

<!-- b19 text -->
“速度是多少？推进方式是什么？”白道微跨前一步，目光如鹰隼般紧盯着光幕上不断刷新的时空测距雷达数据。

<!-- b20 text -->
“非常慢……只有真空中光速的百分之一，大约每秒三千公里！”常灵珂报出这个数值时，语气中透着一股难以掩饰的惊疑，“没有任何等离子推进工质喷射，也没有任何宏观电磁辐射尾迹！更诡异的是它的速度值——如果是摧毁三体母星的高能光粒，相对论速度必须达到零点九九九倍光速以上，才能诱发恒星重核聚变失稳！区区每秒三千公里，连恒星际穿梭的门槛都勉强，甚至只比我们舰队主力重巡洋舰的常规冲压巡航速度略快一线！”

<!-- b21 text -->
然而，真正让白道微浑身肌肉在一瞬间骤然紧绷的，并不是目标的相对论航速，而是紧随其后由海王星引力波干涉仪与高能中微子透射望远镜反馈回来的宏观物理读数：

<!-- b22 text -->
【引力扰动监测报告：零。目标周围未检测到任何微观或宏观引力场形变，引力透镜弯折角严格为零。】

<!-- b23 text -->
【静止质量测算报告：无法收敛。根据惯性引力红移反算，目标静止质量极限趋近于绝对零（M ≈ 0）。】

<!-- b24 text -->
【电磁雷达截面积（RCS）：正向法线方向未检出任何米波、微波及厘米波雷达回波；偏光红外热成像仪未检测到任何黑体辐射发射峰，表面热力学温度处于绝对零度（0 Kelvin）。但在侧向微弱的黄道星光折射背景下，目标边缘呈现出极度规则的几何反光截断！】

<!-- b25 text -->
“没有质量？没有引力？没有热辐射？”常灵珂倒吸了一口凉气，整个人僵立在控制台前。在现代天体物理学的认知框架中，任何在三维空间中宏观存在的物质实体，无论其密度多么稀薄，都必定由夸克、轻子或暗物质粒子构成，都必定遵循万有引力定律并在周围时空中制造出与其质量成正比的微观引力井。在宇宙中，绝对静止质量为零的只有在真空中以光速传播的光子与胶子，但在海王星轨道被捕获的这个未知目标，却正以每秒三千公里的非光速在绝对真空中悠然漫游！这在基础广义相对论的方程体系中，简直是一个赤裸裸的违抗公理的物理学幽灵！

<!-- b26 text -->
与此同时，太阳系舰队最高统帅部与各大太空城的安全理事会也被这条不可思议的深空警报彻底惊动。在木星“新巴黎”太空城的舰队中央指挥大厅内，全息投影会议室里挤满了匆匆连线的将军与资深参谋。然而，与白道微那如临大敌的极度凝重完全相反，整个指挥大厅内部的气氛竟然异常轻松，甚至弥漫着一种荒诞的亢奋与好奇。

<!-- b27 text -->
“这绝不可能是黑暗森林打击武器！”一位佩戴着上将军衔的舰队参谋长毕路逊在全息信道中信誓旦旦地高声发表意见，“三体母星被摧毁的过程我们观测得清清楚楚：那是蕴含着毁天灭地动能的高速光粒！而眼前这个小东西，速度只有区区百分之一光速，质量甚至测量不出来！哪怕它直接撞上海王星的地表，其动能撞击当量也不会超过一枚常规的战术聚变鱼雷！”

<!-- b28 text -->
“会不会是某种高级外星文明遗留在深空的被动科学探测浮标？”另一位太空城理事长微笑着提出了猜想，“或者是某种地外文明向我们抛出的友好‘瓶中信’？在公元纪元，人类的旅行者号飞船也曾携带过记录文明声音的金唱片。也许这是一个路过太阳系的高阶低熵体，在见证了掩体工程的伟大奇迹后，特意向我们留下的一张问候信？”

<!-- b29 text -->
在长达半个多世纪没有遭受任何外来打击的虚妄和平中，掩体社会的高层早己丧失了对宇宙深空最基本的敬畏与敏锐。在他们看来，拥有数千艘重型聚变战舰与庞大掩体堡垒的人类文明，已经是一个不可忽视的星际强权。在舰队指挥部的统一调度下，一道轻率而从容的军令被迅速下达给了游弋在海王星轨道附近的深空科学勘测巡洋舰——“启示号”：【命“启示号”立刻向目标变轨靠拢，执行超近距离光学与量子扫描；在确保安全的前提下，尝试使用电磁机械力场臂将其捕获，运回木星基地进行全面物质分析！】

<!-- b30 text -->
更荒谬的是，这则捕获深空未知微小造物的军事情报，在指令下达后不到十分钟，便通过某些政客的私人量子信道被泄露给了各大太空城的全息新闻网络。在“亚洲一号”、“新巴黎”与“太平洋城”的各大虚拟演播厅内，全息脱口秀主持人们兴奋得红光满面，纷纷将这枚未知造物浪漫化地包装成‘来自外星绅士的宇宙名片’或‘造物主遗落的圣洁书签’；自诩开明的宇宙社会学家们在各个频道连线辩论，滔滔不绝地分析这是否代表着人类终于凭借宏伟的掩体工程赢得了银河系神级文明的建交认可。整个掩体社会沉浸在一种盲目亢奋的狂欢派对之中，数以十亿计的普通民众在人造林荫道上举杯欢呼，根本没有人意识到，死神的冰冷指甲已经悄无声息地搭在了太阳系的门把手上。

<!-- b31 text -->
“糊涂！简直是愚不可及的自杀命令！”在天琴基地的观测舱内，白道微在听到这个轻率的捕获指令后，气得浑身发抖，一拳狠狠砸在了钛合金控制台上，“在黑暗森林中，任何不可理解的微观异象都是悬在头顶的死神铡刀！他们竟然还想把它当成战利品拖回木星？！”

<!-- b32 text -->
“道微，我们无法直接干涉舰队司令部的战术决断。”常灵珂一把拉住白道微颤抖的手臂，急促地提醒道，“但天琴基地的超导中继链路拥有舰队特批的最高科研权限，我们可以同步接收‘启示号’传回的一切微观物理传感器第一手数据流！”

<!-- b33 text -->
