### Task 2: `src/lib/worldsModel.js` (TDD)

**Files:** Create `src/lib/worldsModel.js`, `tests/worldsModel.test.js`.

**Produces (all pure, `now`/`rng` injected):**
- `TEAM_SEED_ELO`: `{GEN:1750,HLE:1700,T1:1650,DK:1650,BLG:1750,TES:1700,AL:1650,IG:1650,G2:1600,MKOI:1550,KC:1550,TL:1600,LYON:1550,CFO:1600,TSW:1550,LOS:1500}`.
- `eloExpected(rA, rB) → number` (standard 400 logistic).
- `updateElo(ratings, games, K=40) → ratings` where `games: [{winner, loser}]` applied in order; returns a new object.
- `seriesWinProbFromGame(p, bo) → number` — Bo1 `p`; Bo3 `p²(3−2p)`; Bo5 `p³(10−15p+6p²)`.
- `gameProbFromSeries(P, bo) → number` — bisection inverse of the above on [0.001,0.999], 60 iterations.
- `blendGameProb({pMarket, pElo}) → number` — `0.6·pMarket + 0.4·pElo` when `pMarket` is a finite number, else `pElo`.
- `fearlessDelta(depthHome, depthAway) → number` — `clamp(0.01·(dH−dA), −0.05, 0.05)`.
- `enumerateSeries(p, bo, delta=0) → { pWin:[h,a], scores: {'2-0':x,…}, best:{score, p} }` — game 1 uses `p`, later games `clamp(p+delta, 0.01, 0.99)`; scores written home-away.
- `impliedOdds(pWin) → [h,a]` — `Math.round(100/p)/100`, each ≥1.01.
- `applyAdjustment(pWinHome, adj) → number|null` — returns clamped p when `|adj| ≤ 0.05`, else `null`.
- `simulateChampion({ teams:[{code,w,l,status}], ratings, scheduled:[{home,away,bo,pWinHome}], runs=10000, seed=1 }) → { [code]: percent }` — mulberry32 PRNG; Swiss rounds until every team has 3 wins or 3 losses: known `scheduled` series use given `pWinHome`, other pairings pair same-record teams randomly avoiding earlier opponents (fall back to any same-record pairing), Bo3 when `w===2||l===2` else Bo1 with `pElo` via `eloExpected`; QF: two `3-0` teams each drawn against a `3-2` team, remaining four random; QF/SF/F Bo5 single elimination; result rounded to 1dp and renormalised so the sum is exactly 100.0.
- `mvpWeights(players:[{player,teamCode,role,kda,kp,dpm}]) → [{player,teamCode,w}]` — role prior `{mid:.30, adc:.25, jng:.20, top:.15, sup:.10}` × `(1 + (kda/μ_kda + kp/μ_kp + dpm/μ_dpm)/3 − 1)` with μ = team means (missing stat → ratio 1); normalised to sum 1 within each team.
- `mvpBoard(champion:{code:percent}, weights) → [{player, teamCode, prob}]` — `P(team)·w`, top 6, renormalised to 100 (1dp).
- `scoreSeries(series) → {hit, exact, brier} | null` for a series with `pick` and `result`; `exact` requires `hit`; `brier = (pWin[pickSide] − 1)²` when hit else `(pWin[pickSide])²`.
- `buildRecord(series, since) → record` — `{since, resolved, correctOutcome, exactScore, winRate(int %), brier(3dp mean), log:[≤12 most recent {id,label_en,label_zh,pick_en,pick_zh,ok,exact}]}`; `label` = `HOME h-a AWAY`, `pick` = `CODE win` / `CODE 胜`.

### Task 7: `scripts/build-worlds-candidate.mjs`

**Files:** Create `scripts/build-worlds-candidate.mjs`; add npm script `"data:worlds:candidate": "node scripts/build-worlds-candidate.mjs"`.

**Consumes:** Task 2 model, Task 4 stages/validator, Task 6 sources. **Produces:** `<output>/worlds-data.json` (validator-clean, explanation fields empty strings / `factors_*: []`) and `<output>/worlds-run-payload.json`.

Flags: `--output=<dir>` (required), `--baseline=<path>` (default `public/worlds-data.json`, optional), `--offline-fixtures=<dir>` (skip network; read `matchlist-main.html`, `matchlist-playin.html`, `game-<id>.html`, `champions.html`, `players.html`, `polymarket.json`, `polymarket-winner.json`, `kalshi.json` from that dir — the live run writes the same files into `<output>/raw/` so a failed run can be replayed).

Algorithm:
1. `now = new Date()`; fetch Main Event + Play-In matchlists; Play-In games only feed Elo.
2. Games: for every played Main Event game fetch `game(id)` unless `baseline.series[].result.games[].gameId` already has it → picks/winner; group rows into series by `(round, {home,away})` — swiss R1/R2 are Bo1 series; R3+ series are Bo3 when both teams’ entering records are `2-0` or `0-2`, Bo1 for `1-1` (compute records from earlier rounds); knockout rows (gol.gg round label not `ROUND\d`) → `qf/sf/final` by label text (`Quarter`, `Semi`, `Final`).
3. Swiss table: w/l per team from completed games; `status` advanced at 3 wins, eliminated at 3 losses.
4. Market: Polymarket series matched to gol.gg series by `{home,away}` set; `market.pWin` mapped by code; `liquidity < 5000` → `market: null`. Kickoff for unplayed series = Polymarket `gameStartTime`, else `${date}T17:00:00Z` (12:00 CT during CDT) flagged `kickoffEstimated:true`.
5. Elo: seeds → apply Play-In then Main Event game results in chronological order (rows reversed), K=40.
6. Fearless depth per team: unique champions picked this tournament (from games) + `0.5·min(seasonUnique,40)` where `seasonUnique` = count of `champion_icon` images on `teams/team-stats/{id}/split-ALL/tournament-ALL/` (ids: AL 2848, BLG 2849, CFO 2880, DK 2802, G2 2897, GEN 2804, HLE 2805, IG 2850, KC 2899, LOS 2895, LYON 2954, MKOI 2900, T1 2809, TL 2813, TSW 2887, TES 2852); failure → 0 and a note.
7. For each unplayed series: `pElo = eloExpected`; `pMarket = market ? gameProbFromSeries(market.pWin[0], bo) : null`; `p = blendGameProb`; `delta = bo>1 ? fearlessDelta(dH,dA) : 0`; `enumerateSeries(p, bo, delta)` → `pick = { side, pWin, score, pScore, oddsImplied, adj:0, decidedAt: now }`. If `now ≥ kickoff`: reuse baseline pick verbatim when present, else `pick:null, missed:true`. Series with result keep the baseline pick verbatim (never recomputed).
8. `champion` via `simulateChampion` with `scheduled` = unplayed known series; `market` = mean of Polymarket price and Kalshi mid (either alone if the other is missing), renormalised to 100 (1dp). `mvp` via players table + `mvpBoard`; `market: null`.
9. `meta` = top 12 by presence from the champion table. `fearless[]` = `{team, depth, champs:[{name,slug}], note_en:'', note_zh:''}`.
10. `record = buildRecord(series, '2026-10-25')`. `sources` = every fetched URL with `fetchedAt`.
11. Top-level: `tournament:'Worlds 2026'`, `updated` (Chicago date of `now`), `version` = baseline.version+1 or 1, `mode:'live'` (or `'archive'` when a `final` series has a result), `patch:'26.20'`, `decidedAt: now`, `note_en/zh` = fixed disclaimer sentence, `archiveSource` = gol.gg matchlist URL with bilingual labels, `teamLogos: TEAM_LOGOS`.
12.
