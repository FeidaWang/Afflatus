# M7 修复记录

日期：2026-11-06（墨尔本时间）。审查报告在分支 `claude/brave-borg-e7cc6b` 的 `docs/elections/M7.md`（提交 `1179d50f`），没有合并到这里。编号沿用该报告。

## 已修

| 编号 | 问题 | 做法 |
|---|---|---|
| H1 | 各党叠加后越过多数线 | 每党一条短条，各自与多数线比较。美国参议院不画 51 线，留任席位有来源后再画 |
| H2 | 过时比赛在手机、地图和席位图上看不出来 | 状态文字加 `· stale`，并进入标记的读屏标签；标记加虚线描边 |
| H3 | 校验失败时采集器崩溃，页面仍显示 `OK` | 转成 `schema_drift`，走隔离、退避和 `status: error`，旧数据保留 |
| M1 | 页内导航后切语言回到枢纽 | 每次移动都同步语言链接 |
| M2 | 切换后焦点丢失，标题不变 | 切议院时焦点留在按钮并播报；打开控制台时焦点移到标题；同步 `document.title` |
| M3 | 未加载席位对比度 1.52:1 | 按审查建议不加深灰色，加描边 `#80837E`；不改选描边透明度提到 .7；地图分界线加深 |
| M4 | 抽屉打开后地图只剩缩略图 | 抽屉变窄；1279 以下抽屉放到地图下方。实测地图 1440 从 367×217 到 428×253，1024 从 193×114 到 493×292 |
| M5 | 768 用手机布局 | 手机断点改到 640，隐藏文字时也隐藏空框 |
| M6 | 文案与事实不符 | 改为「已对照官方来源核对」和「否则本页不显示结果，请看官方网站」；美国说明加「部分比赛可能之后还有决选」。**路易斯安那的决选日期没有查到官方来源，没有写具体日期** |
| M7 | 1024 宽度统计条塌没 | 断点提高到 1279 |
| M8 | 党派只靠颜色 | **部分修复：** 状态文字和读屏标签加党派名，统计条每行有党名。党色本身没有改，红绿色盲下工党和绿党仍然接近 |
| M9 | 未校验字段可注入 HTML 或打断页面 | 校验 2CP 票数、变化类型和差值、指针时间；渲染转义；非法时间显示 `—` |
| M10 | 状态带每次检查都播报 | 去掉状态带的 `role=status`，只留 `#el-live` |
| M11 | 已宣布的大区被算作无判定 | 单列「已宣布，未按席位分配」 |
| M12 | 首个文件 `returned=0` 被判为重计 | 只有之前有投票点返回，或已在重计，才算重计。**VEC 真实行为要到 11-25 试运行才能核对** |
| M13 | 所有独立候选人被标成 `Ind / Teal` | 改为 `Independent / 独立` |
| M14 | 美国时间同时标两个时区 | 固定写 `ET` |
| M15 | 美国状态词误导 | 改为 `Leading`、`No votes reported`。③ 列标题未改 |
| L2 | `初选` 译法 | 改为「第一优先票」；`8 个选区各 5 席` 改为大区 |
| L3 | `Newest source time` 倒退 | 取历史最大值 |
