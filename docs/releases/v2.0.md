# feida.au v2.0 发布验证

版本：`2.0.0`。Git 发布标签：`v2.0`。该版本标记 feida.au 的首次整体视觉重制里程碑，发布内容见 `CHANGELOG.md`。

## 已通过的发布检查

- 生产构建及其数据、路由、导航、样式、双语内容、影片资源和 SEO 检查。
- TypeScript 类型检查与所有前端包体预算检查。
- 播放器、拖动、双语静态首页、发布安全和启动导航：5 个测试文件，24 项测试通过。
- 播放器桌面及 320px、390px 窄屏视觉与交互检查；详见根目录 `design-qa.md`。
- 软件包、锁文件、启动页及 `/version.json` 版本信息已同步。数据检查会校验公开版本清单与软件包版本一致。

## 全量测试基线

全量单元测试为 1890 项通过、95 项失败。失败涉及旧首页、旧字标及其他已有模块；全量测试没有全部通过。

将相同的 19 个失败测试文件与当前生产提交 `0dd16f09f17c51fb5e3c149ca81572753c33471c` 比较，95 个失败断言均一致，新增失败为 0。文案对齐测试需要读取本地 `main`，对照运行使用了同一只读 Git 引用。详细机器结果保存在本地 `artifacts/film-player/release-test-comparison.json`。

生产项目为 Vercel `afflatus`，生产分支为 `main`，域名为 `feida.au`。发布后需核对生产提交、Vercel READY 状态、公开版本清单及实际播放器交互。
