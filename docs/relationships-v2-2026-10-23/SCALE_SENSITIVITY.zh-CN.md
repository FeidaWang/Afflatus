# rel-six-dim 0.2.0 · 量表说明、标定与敏感性（REL-070）

2026-10-24，按站主对 PR #28 的裁定修订。裁定原话是「用最客观的数据来做」。代码在 `src/lib/relationships/scale.js`，标定脚本是 `scripts/calibrate-rel-six-dim.mjs`。文中数字都来自合成出生资料，不是任何真人的结果，也不是命中率。**这是娱乐指数，不是预测。**

## 0.1.0-draft → 0.2.0 改了什么

| | 0.1.0-draft | 0.2.0 |
|---|---|---|
| 规则分值 | 手设（五合 3、六合 3、半合 2、冲 3、刑 2……） | **取消**。规则表只写「影响哪一维、是支持还是磨合」，命中记 1 |
| 地支格权重 | 日×日 1.0、日×年 0.6…… | **取消**，16 格等权 |
| 相位强弱 | 合 3、拱 2、六合 1.5 | **取消**，顺相位（含合相）和硬相位各记 1 |
| 规则族 | 各自封顶，除以手设预算 | 每族取「已判定的检查中命中支持（或磨合）的比例」，**同一维内各族等权平均** |
| 0–100 映射 | `50 + 50 ×（支持比 − 磨合比）`，预算手调 | 分段线性标定：规则表的理论最小值 → 0，样本中位数 → 50，理论最大值 → 100 |
| 状态 | `unverified` + `draft_weights` | `unverified` + `entertainment_index`、`not_externally_validated`；覆盖不足的维另加 `rule_coverage_low` |

每个规则族只属于一个体系（八字、紫微或西洋），所以「同一族内各体系等权」自然成立。

**仍然有人为判断的地方**：「哪类关系落在哪一维、算支持还是磨合」这张分类表（`FAMILY_TABLE`）。分类取自传统说法，比如日干五合主吸引、相冲主节奏不合。没有真实结局数据，无法用数据检验这张表，所以页面写的是「不是预测」，状态保持 `unverified`。0.2.0 只去掉了数值上的倾斜。

## 计算

对每一维 d：

- 族 f 的支持份额 `s_f` = 命中、且在 d 上记支持的检查数 ÷ 该族已判定的检查数；磨合份额 `fr_f` 同理。
- `support_d` = 所有能影响 d 的族的 `s_f` 平均；`friction_d` 同理；`raw_d = support_d − friction_d`。
- 理论范围：每族在 d 上能取到的「支持 − 磨合」最小值与最大值（包括「都没命中」= 0），各族平均。
- 分数：`raw ≤ 中位数` 时为 `50 ×（raw − 理论最小）÷（中位数 − 理论最小）`，否则为 `50 + 50 ×（raw − 中位数）÷（理论最大 − 中位数）`，取整后限定在 0–100。
- 综合分 = 六维等权平均。

## 标定结果（写进 `scale.js` 的 `CALIBRATION`）

| 维度 | 参与的规则族 | 理论最小 | 样本中位数（raw） | 理论最大 | 样本分数 p5 / p25 / p75 / p95 | 标注 |
|---|---|---|---|---|---|---|
| 吸引 `attraction` | 日干、太阳元素、吸引相位 | 0 | 0.0556 | 1 | 0 / 50 / 65 / 71 | 规则覆盖不足 |
| 情感支持 `emotional_support` | 日干、互为喜用、命宫、月亮相位 | -0.25 | 0.25 | 1 | 25 / 38 / 58 / 70 | — |
| 沟通 `communication` | 日干、太阳元素、命宫、水星相位 | -0.75 | 0.1786 | 0.75 | 29 / 40 / 59 / 78 | — |
| 节奏 `rhythm` | 日干、地支合、地支冲刑害破、命宫、火星相位、太阳相位 | -0.8333 | -0.0381 | 0.5 | 31 / 41 / 61 / 71 | — |
| 共建 `building` | 日干、互为喜用、地支合、地支冲刑害破、太阳元素、命宫、太阳相位 | -0.2857 | 0.2054 | 0.8571 | 28 / 40 / 58 / 68 | — |
| 成长 `growth` | 日干、火星相位、太阳相位 | -0.3333 | 0.1111 | 1 | 6 / 38 / 62 / 72 | — |

中位数映射到 50。由于分段标定，各维的理论最小值和最大值落在 0 和 100，左右对称；0.1.0 中「成长」下限偏高的问题已经消除（p5 由 50 降到 6）。

**「吸引」标注为规则覆盖不足。** 能影响它的三族里，只有「吸引相位」带磨合，而硬相位同时记支持和磨合，净值为 0。所以吸引的净值不可能低于「都没命中」，理论最小值恰好等于 0，样本里约四分之一的对子得 0 分。按裁定，这里不补权重，只标注 `rule_coverage_low`，页面显示「规则覆盖不足」。

覆盖不足的判定（只是标注，不改分）：能影响该维的族少于 2 个；或者净值范围是单边的（没有规则能把它推到「都没命中」以下或以上）；或者标定后样本 p5 到 p95 的跨度不足 20 分。

## 敏感性：把单一规则族的权重 ×0.75 或 ×1.25，综合分的变化

样本为另一组 3,000 对合成生日（种子 777），沿用同一套标定。

| 规则族 | ×0.75 平均｜最大 | ×1.25 平均｜最大 |

| bazi.day_stems | 0.57｜2 | 0.57｜3 |
| bazi.favours | 0.53｜2 | 0.45｜2 |
| bazi.branch.harmony | 0.20｜1 | 0.19｜1 |
| bazi.branch.tension | 0.41｜1 | 0.38｜1 |
| western.sun_elements | 0.55｜2 | 0.57｜2 |
| ziwei.life_palaces | 0.57｜3 | 0.48｜2 |
| western.attraction | 0.48｜2 | 0.11｜1 |
| western.moon | 0.24｜1 | 0.19｜1 |
| western.mercury | 0.21｜1 | 0.14｜1 |
| western.mars | 0.23｜1 | 0.21｜2 |
| western.sun | 0.27｜2 | 0.25｜2 |

任何一族的权重变动 25%，综合分平均变化不到 0.6 分，最大 3 分。合成样本的综合分分布：p5 36、p25 44、p50 49、p75 54、p95 59。综合分是六维的平均，所以比单维更集中。
