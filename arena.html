PRE-MARKET · plan the next session

Use the latest completed session’s high, low and close to calculate the next session’s classic pivots. PP = (H + L + C) / 3; R1 = 2PP − L; S1 = 2PP − H.

POST-MARKET · review the last session

Calculate reference pivots from the preceding session, then compare them with the latest completed session’s range and close to review tested levels. Missing daily data cannot establish a test or breakout.

How QF-01 builds a simulation.

The model scores stocks using completed daily prices, then limits each position and sector. At each historical step, it uses only data available at that time and deducts the configured trading costs. Scores rank the inputs; they are not win probabilities.
