AFFLATUS ORIGINAL ANALYSIS

The scarce resource is a finished task.

A subscription purchases access to a changing pool of compute. The useful question is how much of that access becomes work you can accept. We separate the reported allowance, the fraction you can use, and the quality you verify.

Evidence boundary: we read the publicly accessible SemiAnalysis article. Its paid Tokenomics Dashboard and the locked third-party-plan section were not available. The 5 October results remain attributed; we did not retest subscription limits.

01 / The denominator changes the story

An API dollar is a reference price.

API-equivalent value multiplies usable tokens by the API list price. If that price halves while token allowance stays fixed, the reported dollar value halves too. Access has not changed. Read token volume and task acceptance alongside the headline ratio; an expensive API can inflate the apparent subsidy.

Source ↗

02 / Rhythm is part of the product

An allowance must be reachable.

A large weekly allowance can still be a poor fit for a compressed deadline. Model-specific caps, reset windows and bursty work affect utilization. A fair comparison should record the fraction actually consumed during your working hours, rather than assume every buyer exhausts the plan.

At a 5× reference ratio, the utilization break-even is Claude utilization = one fifth of OpenAI utilization. That is algebra under the reported premise, not a purchasing verdict.

Make the assumption visible

03 / Haiku changes the division of labor

Buy precision where it matters.

Our architecture thesis: let a small model extract, classify and summarize; let a stronger model plan, resolve ambiguity and review. Escalation needs an explicit trigger such as missing evidence or a failed check. Savings survive only if verification and retries cost less than the work delegated.

Measure cost per accepted result = total model, tool, retry and review cost ÷ accepted results. The AA index helps select candidates; your own acceptance tests decide deployment.

05 / A bridge from subscribers to builders

The next moat may be a workflow.

Anthropic announced monthly API credits for Max and Team alongside this release. Our inference is that a subscription can become a route into API applications: the user who learns to compose and verify a workflow may later pay for sustained usage. Credits invite experimentation; durable margins still depend on retention, utilization and the full cost to serve.

This is a testable business thesis, not a revenue forecast. Watch accepted-task cost, repeat API use after credits, escalation rate and paid retention. Keep the October 5 subscription tests separate from the October 7 product changes.
