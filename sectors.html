Read the board by workload

Professional work
GDPval reports professional-work performance; it is separate from an overall index and does not measure an entire product.
Agent coding
Terminal and scientific-coding tasks test different work. Tool execution, verification, retries and human review affect the completed job.
Long context
A declared token limit is capacity metadata. Long-context evaluation tests use of that context; the two are not interchangeable.
Cost
The chart uses a cross-suite AA task-cost proxy. API token rates, cache pricing and total production-job cost have different denominators.
Deployment & access
Check configuration, endpoint, region, quotas, license and hardware separately. Open weights do not establish local performance or unrestricted access.

      08 · THESES & EVIDENCE

      Every thesis needs a way to be wrong.

      Keep published measurements, company disclosures, derived calculations and editorial hypotheses visibly separate. Preserve source dates, missing data and contrary evidence. The page should make a thesis easier to inspect, not make uncertainty disappear.

      Source-reported measurement
      Preserve the benchmark version, configuration, unit and retrieval date.
      Company disclosure
      Distinguish announced plans from delivered capacity and retain the disclosure date.
      Derived calculation
      Name inputs, units and assumptions; a calculation is not a new measurement.
      Editorial hypothesis
      State uncertainty and the evidence that would invalidate the claim. Unknown is not zero.
