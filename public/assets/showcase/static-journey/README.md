# Static journey frames

These three AVIF images are the art-directed no-WebGL equivalent of the homepage flight:

- `bow-approach.avif`
- `parallel-drift.avif`
- `engine-departure.avif`

They were generated with built-in Image Gen in reference-image mode using `../signature-vanguard.jpg` for carrier identity. Art direction kept the subject to the right of the text-safe zone, removed HUD/typography, used restrained cyan practical lighting and reserved bloom for the engine frame. Full prompt summaries and accessibility policy are recorded in `docs/refactor/m16-cross-device-accessibility.md`.
